# シンママbot 構想

記録日: 2026-09-16 / 出典: 音声メモ（第3回）

---

## 1. なぜbotなのか — 「深夜にひとり」という時間帯

### 利用シーン（これが設計の全て）

> **子供が寝た後、ひとりでスマホを見ている。**
> でもリテラシーがないし、お金もない。だからまず**無料でできること**を考える。
> ── その瞬間に使ってもらう。

この時間帯の特性:

| 特性 | botが効く理由 |
| --- | --- |
| **深夜（22時〜2時）** | 有人の相談窓口はほぼ閉まっている。botは24時間いる |
| **ひとり** | 誰にも知られずに聞ける。人に相談する恥ずかしさ・後ろめたさがない |
| **リテラシーが低い** | 検索しても情報がバラバラで、どれが自分に関係あるか分からない。botなら**選ぶだけ**で進める |
| **お金がない** | 有料サービスは論外。まず「無料でできること」から入る必要がある |
| **時間が細切れ** | 子供が起きたら中断する。**1問1答で進み、途中から再開できる**形式が合う |

### 提供価値の核

**「あなたが今すぐ・無料でできることは、これです」を1分で出す。**

## 2. コンテンツ設計

### 入口コンテンツ（無料・即効性のあるものから）

| # | 内容 | なぜ刺さるか |
| --- | --- | --- |
| 1 | **手当・制度の診断**（3〜5問で「受け取れる可能性のあるもの」を表示） | お金に直結、無料、その場で結果が出る。**最優先で作る** |
| 2 | 今すぐできる無料アクションのリスト | 「何から手をつければ」に答える |
| 3 | 無料で使える公的窓口・支援団体の一覧 | リテラシーの壁を下げる |
| 4 | 離婚準備の基礎知識（公正証書とは何か 等の一般情報） | シンママ予備軍の入口 |
| 5 | 在宅でできる副業の入口（スマホでできること） | メイン事業への接続 |

> 診断は**「あなたは◯◯がもらえます」と断定しない**。自治体差・個別事情があるため
> 「受け取れる**可能性**があります → 確認先はここ」の形にする。

### トーンの原則

- 専門用語を使わない（「寡婦控除」→「税金が安くなる制度」から入る）
- 説教しない、励ましすぎない
- 1メッセージを短く。深夜にスマホで読める長さ
- 選択肢を出す。自由入力を強制しない

## 3. 出口設計（導線）

botはゴールではなく**入口**。3つの出口に分岐させる。

```
                    [シンママbot]
                          │
      ┌───────────┬───────┴───────┬──────────────┐
      ▼           ▼               ▼              ▼
 🚨 緊急      A. 今すぐ相談    B. つながりたい   C. 学びたい
  公的窓口     → 個別連絡       → オープンチャット  → メイン事業
  （即案内）   （有人対応）      （コミュニティ）    （講座・副業）
```

### A. 「今すぐ相談したい人へ個別連絡」

**最重要導線。** リッチメニューに常時「今すぐ相談する」を置く。

#### 設計のポイント

1. **申し込みのハードルを最小に**
   - 本名不要（ニックネーム可）
   - 状況は**選択式**（離婚を考えている / 離婚手続き中 / すでにひとり親 / お金のこと / その他）
   - 自由記述は任意、1行でもOK
   - 返信を受け取りたい時間帯を選べる（※子供が寝た後しか無理な人が多い）

2. **深夜に届いても「返せない」ことを正直に設計する**
   - 自動応答で必ず即レス: **「受け取りました。◯時までにお返事します」**
   - 既読スルーに見える状態を作らない。深夜に相談を送る人にとって、無反応は一番こたえる
   - 対応可能時間を最初に明示する（誠実さが信頼になる）

3. **できること / できないことを先に伝える**
   - ⭕ 情報提供、制度の案内、専門家への橋渡し、話を聴く
   - ❌ 法律相談・個別の法的判断（→ 提携専門家へ）
   - ※ 非弁行為の線引き。[05-スポンサー型モデル.md](05-スポンサー型モデル.md) 参照

4. **一次対応のテンプレートを用意**
   - 相談者が増えたとき、質を落とさず回すために必須
   - 「聴く」「整理する」「繋ぐ」の3ステップで型を作る

### B. オープンチャット（コミュニティ）

- 匿名で参加できるのが強み（LINEのオプチャは本アカウントと切り離せる）
- 深夜に「起きている人がいる」こと自体が価値
- **要: 運営ルールと見守り体制**。荒れると孤立を深める逆効果になる
- 勧誘・マルチの温床にしないための禁止事項を明文化

### C. メイン事業への接続

- 診断や情報提供で信頼を作ってから、副業・講座の案内へ
- **原則: 相談の場では売り込まない**（[05](05-スポンサー型モデル.md) と同じ原則）

## 4. 🚨 危機対応（最優先で設計すること）

深夜・孤独・追い詰められた状態の人が来る前提で作る。**ここを設計せずにローンチしない。**

### 原則

- **botに判断させない。窓口に繋ぐ。**
- DV・自傷・虐待に関わるキーワードを検知したら、シナリオを中断して**必ず公的窓口を提示**
- 「大丈夫ですか？」で終わらせない。具体的な電話番号を出す

### 案内先（24時間対応があるもの）

| 窓口 | 連絡先 | 対応時間 |
| --- | --- | --- |
| **DV相談＋（プラス）**（内閣府） | 0120-279-889（つなぐ・はやく） | 電話 **24時間365日** / メール24時間受付 / SNS・チャット相談は12:00〜22:00 |
| **DV相談ナビ** | #8008（はれれば） | 最寄りの相談機関に繋がる |
| **よりそいホットライン** | 0120-279-338 | 暮らし・DV・性暴力など。多言語対応あり |

> ※ 番号・対応時間は変わりうるため、**実装前に各公式サイトで再確認**し、定期的に見直すこと。

### 追加で必要な配慮

- **DV事案では、居場所が加害者に知られない配慮**が要る（トーク履歴が見られる可能性）
- 「履歴を消す方法」を案内するコンテンツも検討
- 相談を受ける側（自分）の消耗を防ぐルールも決めておく（対応時間を区切る）

## 5. 実装

### Phase 1: LINE公式アカウント + シナリオ型（AIなし）← 推奨スタート

**まずはAIを入れない。** リッチメニューと選択肢分岐だけで、診断も情報提供も成立する。

理由:
- 無料枠で始められる
- **応答が予測可能＝非弁行為・誤情報のリスクを完全に制御できる**
- 何が求められているかのデータが取れてから、AI化を判断できる

#### LINE公式アカウントの料金（2026年時点）

| プラン | 月額 | 無料メッセージ |
| --- | --- | --- |
| コミュニケーション | 0円 | 200通 |
| ライト | 5,000円（税別） | 5,000通 |
| スタンダード | 15,000円（税別） | 30,000通（追加メッセージ可） |

- **2026年10月1日に追加メッセージの料金改定**あり（20万通を境にした2段階へ移行）。月5万通を超える規模になったら要確認
- 一斉配信（プッシュ）が通数を消費する設計。**bot中心＝ユーザー発話への応答主体なら、配信より低コストで回せる**（※応答メッセージの課金扱いは最新仕様を要確認）
- リッチメニュー・メッセージ配信・セグメント配信は無料プランでも使える

### Phase 2: AI応答の追加（必要になったら）

シナリオで拾えない自由入力に対応したくなった段階で検討。

- Claude API を利用（デフォルトは `claude-opus-5`。コストを優先するなら Haiku 4.5 という選択肢もあるが、**回答の質が信頼に直結する領域なので安易に下げない**）
- **必須のガードレール**:
  - 法的助言を生成させない（システムプロンプトで明確に禁止 + 窓口への誘導を指示）
  - 危機ワード検知は**AIの判断に任せず、ルールベースで前段に置く**
  - 手当の金額など、変動する数値を生成させない（固定コンテンツを返す）
- 実装時に改めて設計する

### 運用コスト（初期）

- LINE公式アカウント: 0円（コミュニケーションプラン）
- 個別相談の対応: 自分の時間（ここが一番の制約）
- → **まず無料で始められる。スポンサー獲得前でも動かせる**のがこの施策の強み

## 6. 測る指標

| 指標 | 見る理由 |
| --- | --- |
| 友だち追加数 | 入口の広さ |
| **深夜帯（22-2時）の利用率** | 仮説が正しいかの検証 |
| 診断の完了率 | 途中離脱していないか |
| **個別相談の申込数** | 一番深い接点 |
| 個別相談への初回返信までの時間 | 信頼の生命線 |
| オープンチャット参加率・発言率 | コミュニティの生存 |
| メイン事業への転換率 | 事業としての成立 |

## 7. 法務チェック（他ドキュメントと連動）

- [ ] **非弁行為**: botの自動応答が個別の法的助言にならないこと → [05](05-スポンサー型モデル.md)
- [ ] **個人情報**: LINEのトーク履歴に機微情報（DV・離婚・子ども）が残る。取扱規程が必要
- [ ] **誇大広告**: 副業導線で「稼げる」訴求をしない → [02](02-法務リスク.md)
- [ ] **ステマ規制**: 商品・サービスを紹介する場合はPR表記 → [02](02-法務リスク.md)
- [ ] オープンチャット内での勧誘・マルチ行為の禁止を規約化
