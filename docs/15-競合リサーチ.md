## 0. このアカウントのゴール

**楽天アフィリエイト（発信）アカウントのゴール：月10〜30万円稼ぎたい人向けの個別コンサルへの導線。**

- [08-ターゲット設計.md](08-ターゲット設計.md) の2層でいうと、この規模感（月10〜30万）は
  **B層（挑戦したが続かなかった／伸び悩んでいる層）のさらに先**にあたる。
  月5万円は「0→1」または初期のコンテンツ販売のゴールだったのに対し、
  ここは**すでに月数千〜数万円は稼げている人を、次の金額帯に引き上げる**個別コンサル。
- [09-収益モデル.md](09-収益モデル.md) の「B層＝コンテンツ販売（自分の時間を使わない）」の型とは異なり、
  **個別コンサルは伴走型＝自分の時間を使う商品**。位置づけとしては、
  コンテンツ販売よりさらに単価が高い**バックエンド商品**になる。
- したがって発信（楽天アフィリエイトの実践知見の共有）は、
  「月5万円レベルの実践者」に向けて**「その先（月10〜30万円）を目指すなら」という伸びしろ**を見せる訴求になる。
- 個別コンサルである以上、**人数に上限がある**（[08](08-ターゲット設計.md) の「個別対応は時間を食う」と同じ論点）。
  一斉型のコンテンツ販売や無料企画とは違い、**単価と人数のバランス設計**が必要。

- [ ] 🟡 月10〜30万円という金額帯の根拠（このリサーチの実例では月5万円到達までが中心。
      月10〜30万円の実例・単価感は別途リサーチが必要）
- [ ] 🟡 個別コンサルの提供人数上限・単価・期間を決める（[10-価格設計.md](10-価格設計.md)と連携）
- [ ] 🟡 コンテンツ販売（B層）→ 個別コンサルへの導線設計（誰にどう案内するか）

## 2. 共通する成功パターン

1. **「自分ごと」を売る** — シンママ・主婦自身が実際に使って良かった商品だけを紹介（誇張しない・売れそうなものを何でも紹介しない）
2. **スキマ時間運用** — 朝5分投稿→昼投稿→夜軽くチェック、程度の低負荷ルーティン
3. **楽天ROOM＋アフィリエイトの併用** — スマホ完結で始めやすく、ブログより参入障壁が低い
4. **セール時期の活用** — 楽天スーパーセール／お買い物マラソンで報酬が伸びやすい
5. **月5万円は「頑張れば届く」ライン** — 月5,000円〜数万円が多数派、月5万円到達は「継続1年前後」が目安として語られている

## 4. 所感（mamapuestのシンママ向けコンテンツ企画への示唆）

- 「シンママ×在宅×月5万」という切り口は**実際に多数の発信者が扱っている競合の多いテーマ**。
- 差別化は「誇張しない実体験ベース」「スキマ時間での再現性の高い運用フロー」の提示が鍵になりそう。
