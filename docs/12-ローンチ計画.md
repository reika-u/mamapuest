## 1. ⚠️ まず整合性の確認：コンサルは誰に売るのか

ここまでの設計では、収益は **B層＝コンサル販売 / A層＝チャレンジ**でした（[09](09-収益モデル.md)）。
コンサルをゴールに置くなら、**対象を先に決める必要があります。**

| 対象候補 | 売れるか | 備考 |
| --- | --- | --- |
| **A層**（始める前に挫けている） | ✕ | お金がない層。高単価コンサルは売れないし、売ってはいけない |
| **B層**（挑戦したが続かなかった） | ⭕ | 課題が明確で、投資判断ができる。**本命** |
| **0→1達成者**（チャレンジ完走者） | ⭕ | 稼いだ実感があり、次に進みたい。[10](10-価格設計.md) の原則に完全に合致 |

> **結論: コンサルの対象は「B層」＋「チャレンジ完走者」。**
> A層への導線は無料チャレンジのまま。ここを混ぜない。

### 価格の整合性（[10-価格設計.md](10-価格設計.md)）

コンサルは通常高単価です。一方この事業には「生活費を削らせない」原則があります。
**衝突を避ける設計:**

- 価格は**その人の副収入または現在の収入に対する比率**で判断する
- **借入をして払わせない**（[11](11-審査制.md) のヒアリングをそのまま流用）
- 分割を用意するなら、割賦販売法の論点を弁護士に確認
- 「これを買えば稼げる」と言わない（誇大広告・不実証広告規制）

### 時間の整合性（[07-チーム設計.md](07-チーム設計.md)）

**コンサルは自分の時間を直接使います。** 売れるほど時間がなくなる。

- **何人まで持てるかを先に決める**（例: 月◯名まで）
- 定員を決めることが、そのまま募集設計になる
- 個別コンサル／グループコンサルのどちらかを決める
  → グループなら時間効率が上がり、参加者同士の繋がりも生まれる（孤立させない理念とも合う）

## 2. 🔴 新たな法務論点：業務提供誘引販売取引

副業を教えるコンサルを売る場合、**特商法の「業務提供誘引販売取引」（内職商法）**に
該当しないかを確認する必要があります。連鎖販売取引とは別の規制です。

### 該当する典型

「内職をしませんか」「収入が得られます」と勧誘し、
**その仕事をするために必要だからと、講座・教材・コンサルを契約させる**取引。

### 該当の分かれ目

調べた結果、鍵は **「仕事の斡旋・紹介を行うことを前提とした勧誘かどうか」**です。

| | 判断 |
| --- | --- |
| **こちらが仕事を紹介・斡旋する**と言って、コンサルを売る | ❌ 該当しうる |
| 受講生が**自分でASPに登録し、自分で案件を取る**（こちらは教えるだけ） | ⭕ 該当しない可能性が高い |

該当すると、**書面交付義務、広告規制、クーリング・オフ20日間**などが課されます。

### この事業での設計原則

> **「仕事を紹介します」「案件をお渡しします」と言わない。**
> 教えるのは方法であって、仕事の斡旋はしない。

- [ ] 🔴 販売ページ・セールストークに「仕事を紹介」の要素がないか点検
- [ ] 🔴 **弁護士への質問リストに追加**（連鎖販売取引の確認と同時に聞く）

※ 連鎖販売取引（[02](02-法務リスク.md)）とセットで確認すると効率的です。

**ゴールから逆算すると、事例づくりが最大の制約**になります。
コンサルを売るには実績が要る → チャレンジ第1期を11月中に終わらせる必要がある。

| **W5** | 10/23-10/29 | チャレンジの中身を作る（7日分の配信を全部書く）／審査フォーム作成／🔴 **決済・LP基盤を決める**（MyASP or UTAGE → [14](14-アフィリエイト設計.md)） |

2. **特商法表記の住所**（自宅を出さないなら契約手続きに時間が要る）
3. **チャレンジ第1期の完了**（W8までに事例が取れないと、コンサルの説得力が出ない）

## 5. ⚠️ 日付を固定することのリスクと、逃げ道

12/16 という日付は、モチベーションとしても発信の軸としても強く機能します。
ただし**日付に間に合わせるために法務を飛ばすのは絶対にやらない。**

> 特商法表記も規約もないまま販売を開始するのは**違法**です。
> ここだけは、日付より優先してください。

### 間に合わない場合の逃げ道（日付は活かす）

12/16 を「販売開始」以外の使い方にすれば、日付の縁起は活かしたまま安全に着地できます。

| 案 | 内容 |
| --- | --- |
| A | **12/16 = コンサルの募集開始**（当初案） |
| B | 12/16 = **説明会・無料相談会の開催日**（販売はその後） |
| C | 12/16 = **チャレンジ第2期のスタート日**（コンサルは年明け） |
| D | 12/16 = **事業の正式スタート宣言**（Instagram・LINEの本格始動） |

**W9〜W10（11月末）の時点で、どれにするかを判断する。**
その時点で法務基盤と事例が揃っていればA、揃っていなければB〜Dに切り替える。
