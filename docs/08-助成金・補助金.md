# 助成金・補助金リサーチ

調査日: 2026-09-16 / 調査範囲: 公開情報（Web）

> ⚠️ 本書は一般的な情報の整理であり、税務・法務の助言ではありません。
> 金額・要件・締切は必ず**各制度の公募要領（最新版）**で確認すること。自治体制度は居住地によって全く異なります。

---

## 0. 結論（先に読む）

**「シングルマザー事業で使える助成金」は、3つの財布に分けて考える必要がある。**

| # | 財布 | 誰が受け取るか | 今の状態（個人事業主・法人格なし）で狙えるか |
| --- | --- | --- | --- |
| **A** | 事業者向けの補助金 | 事業者としての自分 | ⭕ **今すぐ狙える。ここが本命。** |
| **B** | 支援事業向けの助成金 | 支援団体（社団/NPO/任意団体） | △ 法人格・活動実績が要件のものが多い。準備してから |
| **C** | 個人向けの給付・貸付 | 本人 or 受講生 | ⭕ 本人が該当すれば使える。**コンテンツ化の価値が高い** |

### いちばん現実的な順番

```
①【今すぐ】小規模事業者持続化補助金（12/15締切）でLP・撮影・広告の初期費用を取りに行く
②【並行】デジタル化・AI導入補助金 でLINE bot / 顧客管理 / 会計の仕組みを作る
③【3〜6ヶ月】任意団体として実績を1年積む → 法人格を検討 → Bの助成金へ
④【常時】Cの制度は「手当診断bot」と金融教育フェーズのコンテンツそのものになる
```

**Bの助成金を最初の資金源として当てにしないこと。** 法人格・活動実績1年以上・理事2名以上といった要件が並び、
採択されても入金は翌年度、報告書の事務負担も重い（→ [05-スポンサー型モデル.md](05-スポンサー型モデル.md) の注意点と同じ）。

## A. 事業者としての自分が使う補助金（★最優先）

### A-1. 小規模事業者持続化補助金 【★本命・締切が近い】

| 項目 | 内容 |
| --- | --- |
| 第20回 受付 | **2026年11月5日（木）〜 12月15日（火）17:00** |
| 対象 | 常時使用する従業員 20人以下（商業・サービス業は5人以下）。**個人事業主OK** |
| 補助上限 | 基本 **50万円** / インボイス特例 100万円 / 賃上げ特例 200万円 / 両方 250万円 |
| 補助率 | **2/3** |
| 必須手続 | ① GビズIDプライム取得（発行に2〜3週間かかる）② 商工会・商工会議所の**事業支援計画書（様式4）**の発行 |

**この事業で使える経費の例**

- ブランドサイト／LPの制作 … ウェブサイト関連費（第20回から**税込30万円が上限**、単独申請は不可）
- Instagram広告・SNS広告・チラシ … 第20回から**広報費**に移動（ウェブ関連費の枠とは別）
- 撮影・デザイン（ブランディング）、展示会・イベント出展費
- オフ会（年4回想定）の会場費・什器

**動くべきこと（10月中）**

1. GビズIDプライムを申請する ← **これが一番時間がかかる。最初にやる**
2. 管轄の商工会／商工会議所に連絡し、様式4の発行を依頼（**締切直前は混むので11月上旬までに相談**）
3. 経営計画書を書く（ターゲット・提供価値は [01-構想メモ.md](01-構想メモ.md) がほぼそのまま素材になる）

> ⚠️ 補助金は**後払い**。採択 → 交付決定 → 自腹で支出 → 実績報告 → 入金、の順。手元資金がないと動かせない。
> ⚠️ **交付決定前に発注・支払いした経費は対象外**。フライング厳禁。

### A-2. デジタル化・AI導入補助金2026（旧・IT導入補助金）

| 項目 | 内容 |
| --- | --- |
| 対象 | 中小企業・**個人事業主**（小規模事業者を正式に含む） |
| 補助率 | 小規模事業者は**最大4/5** |
| 補助上限 | 通常枠 最大450万円 ／ インボイス対応類型 最大50万〜350万円 |
| 注意 | **IT導入支援事業者が登録済みのツール**しか対象にならない。自作・フリーツールは不可 |

**使いどころ**: シンママbot（[06-シンママbot.md](06-シンママbot.md)）の基盤、顧客管理（受講生名簿）、会計ソフト、オンライン講座プラットフォーム。
ただし LINE公式アカウント＋無料枠で始められるものに補助金を使う意味は薄い。**有料ツールを本格導入する段階で検討**。

### A-2b. 「AI導入・bot開発に補助金は使えるか」への答え

**結論: 使える。ただし「自分でゼロから作ったbot」には出ない。** ルートは3つあり、段階で使い分ける。

| ルート | 何に出るか | 上限 | シンママbotに使えるか |
| --- | --- | --- | --- |
| **デジタル化・AI導入補助金2026** | **事務局に登録済みのITツール**の導入費・クラウド利用費（最大2年分）・導入サポート費 | 最大450万円（小規模は補助率最大4/5） | ❌ 自作botは対象外 ⭕ 既成のAIチャットボットSaaS・顧客管理・会計なら対象 |
| **小規模事業者持続化補助金（ウェブサイト関連費）** | 販路開拓のためのウェブサイト・ECサイト・**システム（オフライン含む）等の開発・構築・更新・改修・運用** | **税込30万円**（第20回から。この費目単独での申請は不可） | ⭕ **オーダーメイドのbot開発でも入りうる。現実的な本命** |
| **ものづくり補助金**（2026年度に中小企業新事業進出補助金と統合） | 革新的な製品・サービスの開発。生成AI活用SaaSや業界特化プラットフォーム向き | 最大2,500万円 | △ **他社にも提供するプロダクト**に育てる段階なら射程。「革新性」と付加価値額向上を数字で示す計画が要る |

#### ⚠️ デジタル化・AI導入補助金の最大の落とし穴

> 生成AIを活用したシステムも2026年度から補助対象として明確化された。**しかし、生成AIツールなら自動的に対象になるわけではない。**
> **IT導入支援事業者が「AI機能を有するツール」として登録・申請したもの**だけが対象で、公式サイトの「ITツール検索」に載っていないものは対象外。単純な静的ホームページ制作も対象外。

つまり **「Claude APIを使って自分でLINE botを組む」は、この補助金では1円も出ない。**
出るのは「登録済みのAI搭載SaaSを契約する」場合。ここを取り違えると申請が丸ごと無駄になる。

#### 段階別の現実解

```
今      : LINE公式アカウント無料枠 + シナリオ型で自作     → 補助金なし・コスト0
次      : 持続化補助金のウェブ関連費30万円でbot開発を外注 → LP制作と抱き合わせで申請
その先  : 登録済みAI搭載SaaSを本格導入                   → デジタル化・AI導入補助金
さらに先: botを他社提供のプロダクト化                    → ものづくり補助金
```

> ⚠️ 補助金が出るのは基本「**導入費用**」。Claude API の従量課金のような**運用費は継続的には出ない**
> （クラウド利用費は登録ツールに限り最大2年分まで）。ランニングコストは自力で回せる設計にしておくこと。

### A-3. 自治体の創業助成金（★居住地次第で最大の金額）

例：**東京都・創業助成事業（令和8年度）**

| 項目 | 内容 |
| --- | --- |
| 助成限度額 | **400万円**（下限100万円）、助成率 **2/3** |
| 対象 | 都内創業予定者、または創業5年未満 |
| 申請要件 | TOKYO創業ステーションの「プランコンサルティング」など**指定23事業のいずれかの利用実績**が必須 |
| 令和8年度 第1回 | 申請受付 **2026年9月29日（火）10:00 〜 10月8日（木）23:59** |
| 採択率 | 令和7年度は 1,225件中201件（**約16.4%**） |
| 女性の扱い | 女性・若者・シニアは重点支援対象として加点あり |

> 📌 **要確認**: 申請要件2（指定支援事業の利用実績）は積み上げに時間がかかるため、第1回（10/8締切）に間に合うかは要問い合わせ。
> 間に合わなければ次回回し。東京都以外の場合は「**〇〇市 創業 助成金**」「**〇〇県 起業 補助金**」で必ず検索すること。
> 自治体の創業助成金は**金額が大きく競合も少ない**ため、national な補助金より費用対効果が高いことが多い。

### A-4. 人を雇うときの助成金（将来／理念との相性が良い）

**特定求職者雇用開発助成金（特定就職困難者コース）**

- **母子家庭の母**を雇い入れた中小企業に、週30時間以上で **1人あたり60万円**（30万円×2期）
- 短時間労働者（週20〜30時間）は減額
- 雇入れ時に65歳未満であること
- ⚠️ **ハローワーク等の紹介経由での採用が必須**。自社の独自採用（SNS募集・知人の紹介）では対象外

> この事業が成長してスタッフを雇う段階になったとき、**支援対象であるシングルマザーを雇うこと自体が助成対象になる**。
> 「支援される側 → 支える側」の導線を作れるので、事業の物語としても強い。募集する前にハローワークに求人を出す運用にしておくこと。

### A-5. 融資（助成金ではないが資金調達の選択肢）

**日本政策金融公庫「新規開業・スタートアップ支援資金（女性、若者／シニア起業家支援関連）」**

- 対象: **全年齢の女性**、30歳未満、55歳以上のいずれかで、新規開業 or 開業後7年以内
- 融資限度額 7,200万円（うち運転資金4,800万円以内）
- 基準利率より **0.4%低い特別利率A** が適用（令和8年2月時点の基準利率は無担保でおおむね3.20〜4.90%）

> 返済義務がある。補助金の「後払い」問題を埋めるつなぎ資金としては有効だが、
> 収益モデルが未確定（→ [04-タスクリスト.md](04-タスクリスト.md) Phase 0）の段階で借りるのは危険。

### Bを取りに行く前に必要な準備（＝Bの本当の要件）

- [ ] 団体名・規約・役員（理事2名以上）・銀行口座 … **任意団体でも「団体の体裁」は必須**
- [ ] **活動実績**（「1年以上」を要件にする助成が多い）→ 今すぐ小さく始めて記録を残すことが最短ルート
- [ ] 会計の分離（支援事業と収益事業の帳簿を分ける）→ 税理士に相談すべき論点
- [ ] 事業報告書・決算書を出せる状態

> ⚠️ **助成金で「有料講座の集客」をしてはいけない。**
> 支援事業として受けた助成金の使途は、報告義務を伴って厳格に紐づく。
> 「無料相談（助成金原資）」と「有料講座（BtoC課金）」の会計・導線・説明を分離しておくこと。
> ここが曖昧だと、助成元の信頼も受益者の信頼も一度で失う。

## C. 本人・受講生が個人で受け取れる制度

**これは資金調達ではなく、この事業の「提供価値そのもの」になる。**
シンママbotの手当診断（[06-シンママbot.md](06-シンママbot.md)）とフェーズ2の金融教育（[04-タスクリスト.md](04-タスクリスト.md)）の中身に直結する。

| 制度 | 内容 |
| --- | --- |
| **母子父子寡婦福祉資金貸付金** | 20歳未満の子を扶養するひとり親向け。**無利子〜年1.0%**。**事業開始資金・事業継続資金**の区分があり、「シンママが起業する」ときの元手に使える。総額の目安は最大326万円程度だが**区分・限度額は自治体ごとに異なる**ため要確認 |
| **高等職業訓練促進給付金** | **月最大14万円 × 最長4年**、修了時に最大5万円。看護師・保育士・介護福祉士・調理師などの国家資格に加え、**シスコ認定・LPI認定などデジタル分野の民間資格**も対象 |
| **自立支援教育訓練給付金** | 雇用保険の教育訓練給付の指定講座等を受講した際の費用の一部を支給 |
| 児童扶養手当 ほか | 所得制限あり。**フェーズ2で扱う「ひとり親控除・寡婦控除・児童扶養手当の所得基準」と直結**（税理士監修必須） |

> 💡 **事業上の重要な示唆**
> 「副業で月◯万稼ぐ」と「児童扶養手当の所得制限」は**真正面からぶつかる**。
> 稼ぎ始めた受講生が手当を失って手取りが減る、という事故が起きうる。
> ここを最初から正直に設計・説明できることが、この事業の最大の差別化になる。→ タスクリスト Phase 2 に反映済み

## E. 用語と落とし穴

| 用語 | 意味 |
| --- | --- |
| **補助金** | 経産省・自治体系。**予算枠があり審査で落ちる**。採択率が数割〜16%程度のものも |
| **助成金** | 厚労省系（雇用関係）は**要件を満たせば原則もらえる**。民間財団のものは審査あり |
| **交付決定** | ここより**前**に発注・契約・支払いをした経費は**対象外**。フライング厳禁 |
| **精算払い** | 原則は後払い。自腹で立て替える運転資金が要る |
| **実績報告** | 領収書・成果物・写真の提出。**記帳と証憑管理が必須**（→ `keiri` エージェントの出番） |
| **返還リスク** | 目的外使用・虚偽申請は返還＋加算金。「取れたら何に使ってもいい金」ではない |

### この事業モデル特有の注意

- **アフィリエイト講座の販売**は、公的な福祉系助成の目的とは馴染まない。**Aの事業者向け補助金で取りに行く**のが筋
- 「無料相談で集めて有料講座を売る」構造は、助成元・行政から見ると最も嫌われるパターン。**分離と透明性**（→ [05-スポンサー型モデル.md](05-スポンサー型モデル.md) §2）
- 申請書に書いた収益モデルは、**特商法・連鎖販売取引の論点**（→ [02-法務リスク.md](02-法務リスク.md)）と矛盾しないこと。書類は残る
