## 1. 年間スケジュール（講座生の募集サイクル）

| 時期 | 内容 |
| --- | --- |
| **12/16** | 1期生 募集 |
| 3月 | 2期生 募集 |
| 6月 | 3期生 募集 |
| 9月 | 4期生 募集 |
| 12月 | 5期生 募集 |

> 四半期ごと（3ヶ月おき）の募集サイクル。12/16 は [12-ローンチ計画.md](12-ローンチ計画.md) の
> ローンチ日と同日であり、そこでの論点（法務基盤の完了・事例の有無）が
> そのまま1期生募集の前提になる。

### ⚠️ 要確認：「1期生」と「チャレンジ第1期」の関係

[12-ローンチ計画.md](12-ローンチ計画.md) では 11月中に「チャレンジ第1期」（無料0→1企画、
[08](08-ターゲット設計.md)）を終え、12/16 に**コンサル販売**をローンチする設計になっている。
本ドキュメントの「1期生」が、

- (a) 12/16 に募集する**有料講座**の1期生（コンサルとは別の枠）なのか、
- (b) [12](12-ローンチ計画.md) でいう**コンサル販売の1期**そのものを指すのか

を明確にしておく必要がある。曖昧なまま両方の文書が走ると、募集人数・価格の
整合性が取れなくなる。

- [ ] 🔴 「1期生」＝コンサル1期 or 独立した講座枠、どちらかを確定する

## 3. 目標数値（売上目標）

| 期 | 対象人数 | 価格・条件 | 備考 |
| --- | --- | --- | --- |
| 1期 | 20人 | 3ヶ月30万円 **または** 6ヶ月50万円 | 2つのプランのどちらかを選べる想定 |
| 来年6月 | VIP 3名限定 | 100万円 | 少人数・高単価枠 |
| 来年12月 | VVIP 5名 | （金額未定） | VIPよりさらに上位の枠 |

### ⚠️ 価格設計との整合性チェック（[10-価格設計.md](10-価格設計.md)）

[10](10-価格設計.md) では以下を原則として置いている。

- 継続課金は「**副収入の5〜10%以内**」が目安
- 「**借入をして参加費を払わせない**」
- 「稼げていない人に上位商品を案内しない」
- 高額一括の押し売りをしない

VIP（100万円・3名）／VVIP（5名）は、この原則における**段階3〜4（金融教育／ビジネス）**の
価格帯に相当すると考えられる。原則上は「**0→1を達成し、副収入が積み上がった人**」向けの
オファーとして設計する必要があり、新規・未達成者への訴求とは切り分けるべき。

- [ ] 🔴 VIP/VVIP の対象を「収入実績のある人」に限定する設計にする
- [ ] 🔴 分割払いを用意する場合、割賦販売法の論点を弁護士に確認（[12](12-ローンチ計画.md) と同じ論点）
- [ ] 🟡 1期の「3ヶ月30万 or 6ヶ月50万」も、対象を [12](12-ローンチ計画.md) の
      「B層＋チャレンジ完走者」に合わせられているか確認する
