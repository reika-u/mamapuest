### 🆕 オフライン施策（2027-09-26 更新）

基本はオンライン運営。年間のオフ会（[04-タスクリスト.md](04-タスクリスト.md)「オフ会の年間4回の開催計画」）は
**大規模2回＋小規模2回**の構成に確定。

| 規模 | 内容 | 時期 |
| --- | --- | --- |
| **大規模（1回目）** | 事業の進捗報告＋セミナー＋交流会を**1日で実施** | **2027年6月**（確定） |
| 大規模（2回目） | 同上 | 未定 |
| 小規模（1回目） | 交流中心・軽量 | 未定 |
| 小規模（2回目） | 交流中心・軽量 | 未定 |

> ⚠️ **2027年6月は3期生募集・VIP募集・大規模オフラインイベントが同月に重なる。**
> ひとりで回す体制（[07-チーム設計.md](07-チーム設計.md)「自分の時間が事業の上限」）である以上、
> 同月に3つの施策が集中すると負荷が高い。優先順位か時期分散を検討する。

- [ ] 🟡 大規模イベント2回目・小規模2回の時期を決める（四半期の募集サイクルとずらすか検討）
- [ ] 🟡 大規模イベントの内容（進捗報告・セミナー・交流会）を1日の中でどう構成するか設計
- [ ] 🟡 リアル交流会の対象を決める（全講座生対象／VIP以上限定／希望者のみ 等）
- [ ] 🟡 開催地・規模・予算を決める（大規模／小規模で分けて試算）
- [ ] 🟡 参加規約・保険を検討（[07](07-チーム設計.md) の既存タスクを流用）
- [ ] 🟡 2027年6月の3施策（3期生募集・VIP募集・大規模オフラインイベント）の負荷を分散できないか検討する

### ✅ 確定：「1期生」＝コンサル1期（2026-09-25 決定）

「1期生」は [12-ローンチ計画.md](12-ローンチ計画.md) でいう**コンサル販売の1期**と同一の枠。
独立した講座枠ではない。したがって [12](12-ローンチ計画.md) の設計（対象＝B層＋チャレンジ完走者、
11月中にチャレンジ第1期を終えて事例を作る、12/16にコンサル募集開始）が、
そのまま本ドキュメントの「1期20人・3ヶ月30万 or 6ヶ月50万」の前提になる。

### ⚠️ 価格設計との整合性チェック（[10-価格設計.md](10-価格設計.md)）

[10](10-価格設計.md) では以下を原則として置いている。

- 継続課金は「**副収入の5〜10%以内**」が目安
- 「**借入をして参加費を払わせない**」
- 「稼げていない人に上位商品を案内しない」
- 高額一括の押し売りをしない

VIP（100万円・3名）／VVIP（5名）は、この原則における**段階3〜4（金融教育／ビジネス）**の
価格帯に相当すると考えられる。原則上は「**0→1を達成し、副収入が積み上がった人**」向けの
オファーとして設計する必要があり、新規・未達成者への訴求とは切り分けるべき。
旅行招待・チーム加入という**非金銭的な特典**が含まれるため、景表法上の表示（提供条件の明示）も
別途確認する。

- [ ] 🔴 VIP/VVIP の対象を「収入実績のある人」に限定する設計にする
- [ ] 🔴 分割払いを用意する場合、割賦販売法の論点を弁護士に確認（[12](12-ローンチ計画.md) と同じ論点）
- [ ] 🟡 旅行招待の提供条件（人数・時期・費用負担）を明文化する
- [ ] 🟡 1期の「3ヶ月30万 or 6ヶ月50万」も、対象を [12](12-ローンチ計画.md) の
      「B層＋チャレンジ完走者」に合わせられているか確認する
