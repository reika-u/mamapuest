# 価格設計 — 顧客の財布を大きくしてから売る

記録日: 2026-09-18 / 出典: 音声メモ（第6回）

---

## 1. この事業の価格設計は、普通と逆になる

### 通常のビジネス

顧客の可処分所得は**固定**。だから価格設計は「限られた財布のどれだけを取るか」の勝負になる。

### この事業

**顧客の可処分所得そのものを増やすのが商品。**

```
無料で 0→1 を作る
      ▼
顧客に副収入が生まれる（月5万 → 10万 → 20万）
      ▼
払える額が増える
      ▼
次の商品を、生活費ではなく「増えた分」から買える
      ▼
環境に残り続ける
```

つまり **「今払える額」ではなく「3ヶ月後に払える額」で設計できる。**
これは他の事業にはない、この事業だけの構造的な強みです。

### ただし諸刃

**顧客が稼げなければ、次は売れない。**
商品が実際に機能することが、収益の前提条件になる。
これは制約ではなく、**健全な緊張関係**として設計に組み込むべきものです。

> 顧客が稼げないのに売れてしまう仕組みは、この事業では作らない。

## 2. 中心原則：生活費を削らせない。ただしコミットメントは取る

### ⚠️ 懸念：初期投資をしない人は続かない

> 「初期投資をしない人は、その後続かない・頑張らない印象が多い」（2026-09-18 メモ）

**この観察は正しい。** 無料企画の完走率が低いのは業界共通の現象です。
ただし原因を切り分けると、対策が変わります。

### 原因は2つあり、性質が違う

| 効果 | 中身 | 価格の役割 |
| --- | --- | --- |
| **選別効果** | 払う人はもともと本気度が高い | 価格は本気度を**測っている**（ふるい） |
| **コミットメント効果** | 払ったから続ける（一貫性・損したくない） | 価格が本気度を**作っている** |

ここが重要な区別です。
**選別効果において、価格は「本気度を作る装置」ではなく「本気度を測る装置」。**

つまり——

> **無料が招く問題は、価格がゼロだからではなく、コミットメントがゼロだから。**

価格はコミットメントを生む手段の**ひとつ**であって、唯一の手段ではありません。

### コミットメントを作る手段（価格以外も含む）

| 手段 | 効果 | シンママ適性 |
| --- | --- | --- |
| **少額デポジット**（完走で返金 or 次回充当） | 強い | ◎ 戻るので生活を削らない |
| 応募課題・事前ワーク（時間の投資） | 中〜強 | ◯ ただし重すぎると脱落 |
| **公開宣言**（オプチャで目標を宣言する） | 中 | ◎ 孤立防止にもなる |
| 定員制・選考制（誰でも入れない） | 中 | ◯ 特別感が生まれる |
| 申込の手間（フォームを少し丁寧に） | 弱〜中 | ◯ 無料でも冷やかしが減る |
| 高額の初期投資 | 強 | ✕ **理念と衝突。やらない** |

### 推奨：少額デポジット型

**チャレンジ参加時に少額を預かり、完走したら返金または次の商品に充当する。**

- コミットメントが生まれる（払った以上やる）
- 本気の人だけが残る（選別効果も働く）
- **結局手元に戻るので、生活費を削らせない**
- 完走者は「次の商品の割引」として使えるので、自然に次へ繋がる

仮の設計:

| 項目 | 内容（仮） |
| --- | --- |
| 金額 | 3,000円程度（生活を圧迫しない額） |
| 返金条件 | 7日間の課題をすべて提出したら全額返金 |
| 返金方法 | 現金返金、または次の商品への充当を選べる |

> ⚠️ **返金保証には景表法の表示ルールがあります。** 条件を明示せずに
> 「全額返金」と書くと有利誤認になります。詳細は下の法務セクション参照。

### 修正した原則

前提として置いていた「稼ぐ前に払わせない」の**目的は、生活費や手当を削らせないこと**でした。
3,000円のデポジット（しかも戻る）は、その目的を損ないません。

**原則を次のように修正します。**

- ❌ 「無料にする」
- ⭕ **「生活費を削らせない。ただしコミットメントは取る」**
- ⭕ 本格的な課金（月額・講座）は、引き続き **0→1達成後**に置く

### 検証の仕方

どちらが正しいかは、**やってみれば数字で分かります。**

1. 第1期：無料 or デポジットのどちらかで回す
2. 第2期：もう一方で回す
3. **完走率・0→1到達率・その後の購入率**を比較する

第1期を小さく回す方針（[08](08-ターゲット設計.md)）なので、この比較は現実的にできます。
印象ではなく数字で決められる論点です。

## 3. 価格の決め方：収入比率で考える

シンママ対象で「いくらが妥当か」は、金額の絶対値では決まりません。
**その人の副収入に対して何%か**で考えると、続くかどうかが判断できます。

| 副収入 | 月額◯円なら続くか |
| --- | --- |
| 月3万円 | 月3,000円 = 10%。やや重い |
| 月5万円 | 月3,000円 = 6%。続く |
| 月10万円 | 月5,000円 = 5%。続く |
| 月5万円 | 月1万円 = 20%。**重い。離脱する** |

> **目安: 継続課金は「その人の副収入の5〜10%以内」。**
> 一時的な商品は「その月の副収入を超えない」。

この原則は、**値上げの判断基準**にもなります。
顧客の収入が上がっていないのに値上げするなら、それは理念に反します。

## 4. 価格ラダー（たたき台 ※金額は仮）

| 段階 | 内容 | 価格の考え方 | 仮の金額 |
| --- | --- | --- | --- |
| **0. 無料** | bot、手当診断、チャレンジ、オプチャ | リスト取りと信頼 | 0円 |
| **1. 入口** | B層向けコンテンツ（課題別・単発） | **迷わず出せる額**。外食1回分の感覚 | 1,000〜3,000円 |
| **2. 継続** | 月額コミュニティ（環境そのもの） | **副収入の5〜10%**。長く続く額 | 月2,000〜3,000円 |
| **3. 金融教育** | お金を守る・増やす講座 | 増えた収入から払える額 | 1万円前後 |
| **4. ビジネス** | 起業・自分の商品づくり（[01](01-構想メモ.md) フェーズ4） | **事業への投資**として判断できる額 | 別途設計 |

### 段階を上げる条件を「収入」に紐づける

**稼げていない人を上の段階に上げない。**

- 段階2→3は「月◯万円を達成した人へ」と案内する
- 達成していない人には、**上の商品ではなく、今の段階のサポートを出す**
- これは誠実さであると同時に、**返金・不満・離脱を防ぐ実務**でもある

## 5. 継続課金（月額）の設計 — 事業の本命

「この環境を使い続けてもらう」は、実質的に**月額コミュニティ**のこと。
ここが安定収益の柱になります。

### 設計方針

- **低額 × 長期。** 高い月額で3ヶ月より、低い月額で2年
- 家計に乗る額にする。シンママの月次支出として無理がないこと
- 入っている理由が毎月わかること（何もない月を作らない）

### 🔑 休会制度を作る

**子供の病気、収入の変動、心が折れた月 — 必ず来ます。**

- そのとき「退会」しかないと、**戻ってこない**
- 「休会」があれば、落ち着いたときに戻れる
- 離脱防止の実務としても、理念としても正しい

### 解約は簡単にする

- 引き止めない。解約導線を隠さない
- **法的にも必須**（後述）
- 気持ちよく辞められた人は、戻ってくるし人に勧める

## 6. ⚠️ この事業で絶対にやらないこと

シンママを対象にする以上、これらは**事業を終わらせる**レベルのリスクです。

| やらないこと | 理由 |
| --- | --- |
| **借金・分割払いを勧めて高額商品を売る** | 情報商材の最悪パターン。シンママ相手では致命的 |
| 手当・生活費を切り崩させる訴求 | 「投資だと思って」は使わない |
| 高額一括の押し売り | 払えない人に払わせる構造を作らない |
| 解約しづらい設計 | 法令違反であり、信頼を一度で失う |
| アップセルの圧力 | 断れない関係性を作らない |
| 稼げていない人への上位商品の案内 | 最も不誠実な売り方 |

> 迷ったら「**この人の子供の生活を削らせていないか**」で判断する。

## 7. 🔴 法務（月額・サブスクを始める前に必読）

### 定期購入・サブスクの「最終確認画面」表示義務（改正特商法・2022年6月施行）

申込みの**最終確認画面**で、以下を表示する義務があります。

1. 分量（**解約を申し出るまで続く無期限の契約なら、その旨を明確に表示**）
2. 販売価格・対価（定期の場合、**各回の代金と、支払うことになる総額**）
3. 支払いの時期・方法
4. 引渡し・提供の時期
5. 申込みの撤回・解除に関する事項
   → **解約方法に限定がある場合、リンク任せにせず最終確認画面で明確に表示する**
6. 申込期間の定めがある場合はその内容

> 定期購入規制は運用が厳格化しており、**業務停止命令の事例**も出ています。
> 月額を始めるなら、決済ツール任せにせず、確認画面の表示を自分で点検してください。

- [ ] 🔴 最終確認画面の6項目を点検する
- [ ] 🔴 解約方法を最終確認画面に明記する（リンクだけにしない）
- [ ] 🔴 「解約を申し出るまで継続する契約である」旨を明示する
- [ ] 🔴 返品特約・特商法表記の整備（[09-収益モデル.md](09-収益モデル.md)）

### 返金保証・デポジットを使う場合（景表法）

デポジット型を採用するなら、**返金条件の表示**が必須です。

- **返金の条件を書かずに「全額返金」と表示すると、有利誤認表示**になります
- 条件がある場合は、その条件も広告に明記する
- 期間限定でないのに「期間限定全額返金」と書かない
- **実際の運用と表示を一致させる**
  （「全額返金保証」と謳いながら、実際には承認が必要だった事例が指摘を受けています）
- 景表法違反には**課徴金制度**があります

- [ ] 🔴 返金条件を明文化し、申込ページに明記する
- [ ] 🔴 表示と実際の運用が一致しているか点検する
- [ ] 🟡 返金の手間・決済手数料を試算する（少額返金は手数料負けしやすい）

### 価格表示まわり

- 二重価格（「通常◯円が今だけ」）は実績がなければ**有利誤認** → [09](09-収益モデル.md)
- 「月◯万円稼げるようになります」を価格の根拠にしない（誇大広告）
- 分割・後払いを提供する場合、割賦販売法の論点が発生する → **弁護士確認事項**

## 8. 測る指標

| 指標 | 見る理由 |
| --- | --- |
| **継続率（月次）** | 月額モデルの生命線 |
| 平均継続月数 | LTVの実態 |
| **顧客の副収入の推移** | この事業では、これが伸びないと価格も上げられない |
| 段階2→3の移行率 | ラダーが機能しているか |
| 休会 → 復帰率 | 休会制度が効いているか |
| 解約理由の内訳 | 価格が理由なのか、内容が理由なのか |
| **「生活費を削って払っている人」がいないか** | 定性的に必ず確認する |
| 無料期 vs デポジット期の**完走率の差** | 初期投資が継続に効くかの実測 |
