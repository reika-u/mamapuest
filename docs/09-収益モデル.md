# 収益モデル — 2層に2つの売り方

記録日: 2026-09-18 / 出典: 音声メモ（第5回）

前提: ターゲットは2層に分かれる（[08-ターゲット設計.md](08-ターゲット設計.md)）。

---

## 1. 構造

| 層 | 売り方 | 役割 |
| --- | --- | --- |
| **A層**（始める前に挫けている） | **チャレンジローンチ** | 未来の資産をつくる（リスト・事例・信頼） |
| **B層**（挑戦したが続かなかった） | **コンテンツ販売** | 今の収益をつくる |

### なぜこの組み合わせが噛み合うか

**時間軸が違う。だから両輪になる。**

```
B層 × コンテンツ販売  →  今月のお金（自分の時間を使わない／在庫がない）
        │
        │ ここで得た収益が、A層への無料投資を支える
        ▼
A層 × チャレンジローンチ →  リスト・事例・信頼（数ヶ月後に効く）
        │
        └─▶ 0→1 を体験した人が、次の商品の顧客になる
```

- **B層向けコンテンツ販売は「自分の時間を消費しない」**。一度作れば売れ続ける。
  ひとりで回す事業にとって、これが唯一スケールする形
- **A層向けチャレンジは時間を食う**が、事例と信頼という買えない資産が残る
- つまり **B層の売上がA層の無料企画を養う**。スポンサー・助成金（[05](05-スポンサー型モデル.md)）が
  入るまでの間、事業を自走させられる

---

## 2. ⚠️ 最大の論点：入口は1つ、ターゲットは2つ

[08](08-ターゲット設計.md) で「Instagram の発信はA層に振り切る」と決めた。
では**B層にはどこで出会うのか**。ここを設計しないと、コンテンツ販売が売れない。

### 推奨：入口は共通、LINE登録後にセグメント分岐

```
Instagram（A層の言葉で発信）
        ▼
LINE公式アカウント登録  ← リスト取りはここで共通化
        ▼
   登録直後にアンケート1問
   「副業をやってみたことはありますか？」
        │
   ┌────┴────┐
   ▼         ▼
 ない        ある
  A層        B層
   │         │
   ▼         ▼
チャレンジ   コンテンツ販売
ローンチ     （課題別に出し分け）
```

**なぜこれが一番きれいか**

- 発信の言葉を1つに保てる（混ぜると誰にも刺さらない）
- リスト取りは共通なので、集客の労力が分散しない
- **B層はA層の発信にも反応する。**「始められない人向け」の投稿を、
  挫折した人が見て「自分もそこからだった」と刺さることがある
- チャレンジ参加者の中にB層が混ざっていてもいい。**登録後に分ければいい**

### 分岐の設計メモ

- 質問は**1問だけ**。増やすと離脱する
- 「ある」と答えた人には、続けて「どこで止まりましたか？」（選択式）
  → これがそのままコンテンツ販売の**商品設計データ**になる
- 分岐後もオープンチャットは共通でよい（層が混ざることが価値になる）

## 3. A層 × チャレンジローンチ

7日間コホートの骨子は [08](08-ターゲット設計.md) に記載済み。ここでは**オファー設計**を扱う。

### ⚠️ この事業でそのままやってはいけないこと

一般的なチャレンジローンチは、**最後に高額商品のオファーを置く**形式。
しかしA層は「お金がない」層であり、この事業の理念は経済的自立の支援。
**高額バックエンドをそのまま乗せると、理念と衝突する。**

### 設計方針

| 一般的なやり方 | この事業での置き換え |
| --- | --- |
| 最後に高額商品を提示 | **低価格 or 段階的な次のステップ**を提示 |
| 「残り◯席」で煽る | 煽らない（後述の法務リスクもある） |
| 稼げる実績を前面に | **0→1の体験**を前面に |
| 期間限定の値引き | 定価で、いつでも入れる形も残す |

- チャレンジの目的は**販売ではなく、リストと事例の獲得**と割り切る
- 完走しなかった人を追いかけない。リストに残ればそれでいい
- 次のステップは「金融教育」など、**お金を増やす前に守る話**から入ると理念と合う

## 4. B層 × コンテンツ販売

### なぜB層に合うか

- **すでに自分の課題が言語化できている**。だから商品を選べる（A層は選べない）
- 「教えてほしい」ではなく「これが欲しい」で買う → 伴走が要らない
- 単価が低くても、**自分の時間を使わないので利益が残る**

### 商品設計の考え方

B層の詰まりポイントは3つ（[08](08-ターゲット設計.md)）。**課題別に分けて作る。**

| 詰まりポイント | 商品の方向性 |
| --- | --- |
| 自分に合うやり方が見つけられない | **診断＋型の選び直し**（合わなかった理由の特定） |
| 時間がない | **時間設計**（何をやめるか、細切れ時間での回し方） |
| うまくいかなかった | 前回止まった地点の突破に特化した個別テーマ |

- **1つの大きな商品より、小さく複数**。B層は「全部入り」を求めていない
- 価格は低めから始めて、売れ方を見て決める（最初から高く設定しない）→ [10-価格設計.md](10-価格設計.md)
- セグメント分岐のアンケート結果が、そのまま何を作るべきかを教えてくれる

## 5. 🔴 法務（コンテンツ販売を始める前に必読）

調べた結果、**見落としやすい重大な点**がありました。

### ① 返品特約を書かないと、8日間は返品されてしまう

- **通信販売にはクーリング・オフ制度がない。** ここまでは有利
- ただし**広告に返品について何も書いていない場合、商品を受け取った日から8日間は
  申込みの撤回・契約の解除ができる**
- 逆に、広告にあらかじめ「返品不可」等の特約を記載していれば、原則として解除できない

> **デジタルコンテンツは、渡した瞬間に取り返せない。**
> 返品特約の表示は、販売開始前に必ず整備すること。消費者庁が媒体ごとの
> 表示ガイドラインを出しているので、それに沿った表示方法にする。

- [ ] 🔴 返品特約を作成し、販売ページ・申込画面に表示する
- [ ] 🔴 特商法に基づく表記を整備（事業者名・住所・連絡先・価格・支払方法 等）

### ② 景品表示法 — チャレンジローンチで特に危ない表現

処分事例として、**「実在しない価格」（二重価格）、「虚偽の解除条件」、「ナンバーワン表示」**が
挙がっています。ローンチ形式は、まさにこれらをやりがちな型です。

- ❌ 「通常◯万円が今だけ◯円」← その通常価格で売った実績がないなら**有利誤認**
- ❌ 「残り◯席」「今日まで」← 実際には制限していないなら虚偽
- ❌ 「参加者の90%が達成」← **根拠を示せないとアウト**（不実証広告規制）
- ❌ 「業界No.1」「一番わかりやすい」← 客観的根拠が要る

> **不実証広告規制**: 効果・性能の表示について、消費者庁から根拠資料の提出を求められ、
> 出せなければ不当表示とみなされます。「実績を出すなら、記録を残しておく」が原則。

### ③ その他（既出）

- ステマ規制（PR表記）、薬機法 → [02-法務リスク.md](02-法務リスク.md)
- 「稼げる」訴求をしない → 同上
- 連鎖販売取引にしない（紹介報酬をつけない） → 同上

---

> **価格の考え方は [10-価格設計.md](10-価格設計.md) に分離。**
> 顧客の副収入を増やしてから売る、という構造がこの事業の価格設計の中心。

## 6. 進める順番

収益を早く立てたい気持ちと、資産を作る動きは**両立できる**。ただし順番がある。

1. **LINE登録 → 1問アンケートの分岐**を作る（両方の前提になる）
2. **返品特約・特商法表記を整備**する（コンテンツ販売の前提。これがないと売れない）
3. **B層向けの小さいコンテンツを1つ作って売ってみる**（収益の検証）
4. 並行して**A層向けチャレンジの第1期**を小さく回す（型づくり）
5. 両方の数字を見て、次に厚くする方を決める

> 3と4は同時に走らせない方がいい。**どちらも第1回は必ず想定外が起きる。**
> 先にB層のコンテンツ販売（自分の時間を使わない方）を回して、
> 手が空いた状態でチャレンジを回すのが安全。

## 7. 測る指標

| 指標 | 見る理由 |
| --- | --- |
| LINE登録後のアンケート回答率 | 分岐が機能しているか |
| **A層 / B層の比率** | どちらに寄せるべきかの判断材料 |
| コンテンツの購入率・単価・返品率 | 収益エンジンの健全性 |
| コンテンツ1本あたりの制作時間 | 利益が残っているかの実態 |
| チャレンジの完走率・0→1到達率 | [08](08-ターゲット設計.md) と同じ |
| **チャレンジ完走者のその後の購入率** | 資産が収益に変わっているか |
