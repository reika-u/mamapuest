# 稼ぐことと手当の両立 — 所得制限・経費・家事按分

調査日: 2026-09-16 / 関連: [04-タスクリスト.md](04-タスクリスト.md) Phase 2（金融教育）、[02-法務リスク.md](02-法務リスク.md)、[07-チーム設計.md](07-チーム設計.md)

> ⚠️ 一般的な制度の整理であり、**税務相談ではありません**。個別の判断は必ず税理士に確認してください。
> 税務相談・税務書類の作成・税務代理は**税理士の独占業務**です（[07-チーム設計.md](07-チーム設計.md) §2）。

---

## 0. 結論

**「経費と家事按分で所得を圧縮する」という発想は、制度上は正しい。**
児童扶養手当の判定は「収入」ではなく「**所得**」で、事業所得なら必要経費を引いた後の数字が使われるため、
同じ売上でも所得は変わり、手当の崖は緩められる。

**ただし、これを事業として「教える」となると、話が変わる。**
踏み込みすぎると ①税理士法 ②税務否認 ③手当の過払い返還 の3つに同時に触れる。

> **教えていいのは「正しく按分し、根拠を残す方法」まで。**
> **「按分率を上げれば手当が守れる」は、教えた瞬間に受講生を危険に晒す。**

## 1. 制度の事実関係

### 児童扶養手当の所得の計算

```
所得 ＝ 年間収入 － 必要経費 ＋ 養育費の8割 － 8万円（社会保険料相当額） － 諸控除
```

この「所得」を、扶養親族の数に応じた**所得制限限度額**と比較して、全部支給／一部支給／不支給が決まる。

### 事業所得で特に重要な3点

| # | 事実 | 意味 |
| --- | --- | --- |
| 1 | 事業所得は「**収入 － 必要経費**」で計算される | 経費を正しく計上すれば所得は下がる。**ユーザーの認識は正しい** |
| 2 | **給与所得・公的年金所得がある場合は10万円の控除があるが、事業所得のみの場合は適用されない** | パート＋副業と、専業で副業のみでは、**同じ手取りでも手当の判定が変わる** |
| 3 | 事業所得の計算には**青色申告特別控除**が含まれる（自治体の案内による） | 青色申告の有無が手当にも波及しうる ※**扱いは自治体確認が必要** |
| 4 | **養育費は8割が所得に加算される** | 公正証書で養育費を確保することと、手当の額はトレードオフの関係にある |

> 📌 ③と④は自治体によって運用の説明が異なるため、**「お住まいの市区町村で確認」を必ず添えること**。
> [06-シンママbot.md](06-シンママbot.md) の「断定しない」原則がここでも効く。

### 家事按分（自宅を事業に使う場合）

- 対象になりうるもの: **家賃・水道光熱費・通信費・車両費**
- 按分の基準: **面積・時間・数量・距離**など**合理的な基準**
  - 面積の例: 100㎡のうち20㎡を業務に使用 → 家賃の20%
  - 時間の例: 1日のうち8時間を業務に使用 → 約1/3
- **根拠資料を残すことが本体**: 業務スペースの間取り図、使用状況の写真、使用記録、走行距離の記録
  → 税務調査で按分率の妥当性を説明できる状態にしておく

## 2. 🚨 事業として教えるときの4つの危険

### 危険① 税理士法の壁（🔴 最重要）

**「あなたはこの経費を◯%按分できます」は言えない。** 個別の税務相談は税理士の独占業務。

| ⭕ できること | ❌ できないこと |
| --- | --- |
| 「家事按分という制度があり、合理的な基準で按分する」という一般解説 | 「あなたの場合、家賃の40%を経費にできます」 |
| 「按分基準には面積・時間などがある」の説明 | 受講生の帳簿を見て按分率を決めてあげる |
| 開業届・青色申告承認申請の**手続きの流れ**の解説 | 確定申告書を代わりに作成する |
| 記帳の考え方・証憑の残し方 | 「この支出は経費で落ちます」の個別判断 |
| **税理士に繋ぐ** | — |

### 危険② 「所得を下げる指導」は受講生を危険に晒す（🔴）

実態のない按分・水増し経費は**否認され、修正申告・加算税**になる。
さらに、**児童扶養手当の過払い返還**にまで波及しうる。
手当を守るつもりの助言が、追徴と返還のダブルパンチを生む。

> 教える上限は「**実態に合わせて正しく按分し、根拠を残す**」まで。
> 「按分率を上げれば手当が守れる」という発想を、教材にも面談にも絶対に持ち込まない。
> ここは事業の存続に直結する。「シンママに脱税を教えている」と言われた瞬間に終わる。

### 危険③ 所得を下げることのトレードオフ（🟡）

所得の圧縮は、無条件に得ではない。

| 影響先 | 所得が下がると |
| --- | --- |
| 児童扶養手当・保育料・各種助成 | ⭕ 有利に働く |
| 賃貸契約・住宅ローンの審査 | ❌ 通りにくくなる |
| 将来の年金額（国民年金＋付加・iDeCo等の余力） | ❌ 積み上がらない |
| 借入（公庫の創業融資など） | ❌ 返済能力の評価が下がる |

**「手当を守る」最適化が、2〜3年後の選択肢を狭めることがある。**
これは [01-構想メモ.md](01-構想メモ.md) の「**選択肢が増えている状態を目指す**」という事業理念と正面から衝突する論点。
だから「節税テクニック」としてではなく、**人生の選択として提示する**必要がある。

### 危険④ 給与と事業の非対称性（🟡）

事業所得のみだと10万円控除がない。
「パートを減らして副業一本に」という選択が、手当の判定では不利に働きうる。
**受講生に副業専念を勧める前に、この非対称性を説明する義務がある。**

## 3. 事業への落とし込み

### これはフェーズ2（金融教育）の目玉になる

「稼ぎ方」を教える講座は山ほどある。
**「稼いだ結果、手当と税金がどうなるか」まで面倒を見るものはほとんどない。**
ここが [01-構想メモ.md](01-構想メモ.md) §3 で言う「怪しく見られやすい領域を突き抜ける」差別化そのもの。

### 作るもの: 「手取りの崖」シミュレータ

```
売上 → 経費（家事按分含む） → 事業所得 → 児童扶養手当の増減 → 社会保険料・税 → 実際の手取り
```

- 形式: スプレッドシート、またはbotの診断コンテンツ（→ [06-シンママbot.md](06-シンママbot.md) の手当診断の発展形）
- ⚠️ **税額を計算・断定しない。**「目安」であることと「確認先は市区町村窓口と税理士」を必ず表示
- ⚠️ 限度額は自治体・年度で変わる。**数値は必ず外部データとして持ち、ベタ書きしない**

### 教える順番

```
① 開業届 → ② 青色申告承認申請 → ③ 帳簿をつける → ④ 経費の考え方
→ ⑤ 家事按分（根拠を残す） → ⑥ 確定申告 → ⑦ 児童扶養手当の現況届（毎年8月）
```

⑦を最後に置くのがポイント。**確定申告の結果が、翌年度の手当に反映される**という因果を体で理解させる。

### 🔴 正直に伝えるべきこと

**経費と按分で所得を下げる技術は、月5万〜10万の層には効く。月20万を超えると限界が来る。**

そこから先は「手当を守る」から「**手当を卒業する**」への戦略転換が必要になる。
両方の道を最初から示すのが誠実であり、
[01-構想メモ.md](01-構想メモ.md) のライト層（月5〜20万）／本気層（起業・独立）の2層設計とも整合する。

- ライト層 → 手当と両立させる設計。経費・按分を正しく使う
- 本気層 → 手当の卒業を前提に、所得を伸ばす設計。融資・信用も作りにいく

**どちらが正しいかではなく、「どちらを選ぶか」を本人が決められる状態にすることが、この事業の目的。**
