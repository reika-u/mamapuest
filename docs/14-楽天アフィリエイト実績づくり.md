## 1. これは何のためにやるのか

[12-SNSマーケティング部.md](12-SNSマーケティング部.md) の5アカウントとは性質が違う。
**発信ペルソナ用のアカウントではなく、代表自身がアフィリエイトで実際に収益を出すための実行アカウント。**

目的は2つ:

1. **「0→1」の再現性を自分で証明する**（[08-ターゲット設計.md](08-ターゲット設計.md) の0→1企画で
   参加者に体験させる前に、まず自分で「本当にできる」ことを実証する）
2. **教える前提の説得力を作る**（[04-タスクリスト.md](04-タスクリスト.md) Phase 1「自分自身の実績を作る／
   数値化する」を、具体的な手段（楽天アフィリエイト）に落とし込む）

[01-構想メモ.md](01-構想メモ.md) で「軸はアフィリエイト」と位置づけられている収益化手段の、最初の実践がこれにあたる。
後述の**楽天ROOM**はスマホ完結・ブログ不要のため、[01](01-構想メモ.md)が掲げる
「在宅副業（SNS/スマホ1台で完結）」のカリキュラム化にそのまま使える可能性がある。

## 2. 登録方法・条件

**分かったこと**:
- 楽天アフィリエイトの利用には**楽天会員登録（無料）**があれば足り、**審査はない**
- 楽天ROOM（room.rakuten.co.jp）は、別途ブログ・サイトを用意しなくても、投稿するだけでアフィリエイトリンクが自動生成される仕組み。Instagram等と組み合わせて使われることが多い
- 楽天アフィリエイト公式サイト（affiliate.rakuten.co.jp）から直接リンクを発行する方法と、楽天ROOM経由の2通りがある

## 3. 報酬の仕組み

**分かったこと**:

| 項目 | 内容 |
| --- | --- |
| 成果条件 | リンククリックから24時間以内にカート投入、かつ89日以内に購入完了 |
| 報酬料率 | ジャンルにより通常2〜4%。店舗によっては最大20%の高料率商品もある |
| 受け取り方法 | デフォルトは**楽天キャッシュ**（1円から受け取り可）。銀行振込も選択可 |
| 銀行振込の条件 | **直近3ヶ月の確定報酬が毎月3,001円以上、かつ審査に合格**する必要がある |
| 振込手数料 | 楽天銀行あて30円／楽天銀行以外あて250円（利用者負担） |
| 支払いサイクル | 成果発生の**翌々月に確定**、その月の10日に楽天キャッシュで支払い |

出典:
- [楽天アフィリエイトの成果報酬について｜楽天アフィリエイト公式](https://affiliate.rakuten.co.jp/guides/rank/)
- [楽天アフィリエイト報酬の受け取り方と料率（楽天アフィリエイト公式note）](https://note.com/rakutenaffiliate/n/n7fbdf72f8f60)
- [成果報酬の全額銀行振り込みについて｜楽天アフィリエイト公式](https://affiliate.rakuten.co.jp/revision/payment/)

**推測**: 「確定まで2ヶ月かかる」ため、**「早急に」始めても、最初の入金確認までには最低でも1〜2ヶ月かかる**前提で動く必要がある。「今すぐ実績が出る」を期待した設計にしないこと。

## 4. 🚨 最重要の禁止事項: 自己購入（自己アフィリエイト）は規約違反

**分かったこと**: 楽天アフィリエイトでは**自己購入（セルフアフィリエイト）は原則禁止**されている。
家族・知人との共謀による成果発生も認められない。誤って自分のリンク経由で購入した場合は
成果が「破棄」されるだけで即ペナルティにはならないが、**意図的な自己購入・継続的な違反はアカウント停止につながりうる**（パートナー規約第14条）。

出典:
- [禁止事項｜楽天アフィリエイトヘルプ](https://affiliate.faq.rakuten.net/category/prohibition/)
- [楽天アフィリエイトガイドライン｜楽天アフィリエイト公式](https://affiliate.rakuten.co.jp/guideline/rule/)
- [楽天アフィリエイトで自己購入した場合の対処法（ゆけむりブログ）](https://www.yukemuri-blog.com/rakuten-affiliate-purchased-myself/)

### ⚠️ [08-ターゲット設計.md](08-ターゲット設計.md) の「セルフバック」との混同注意

08で0→1到達手段の候補に挙げている**セルフバック（自己アフィリエイト）は、A8.netなど「セルフバックを公式に許可しているASP」の制度**を指しており、
**楽天アフィリエイトのセルフバックとは別物**。楽天アフィリエイトで同じ発想（自分で買って実績を作る）をやると規約違反になる。

→ **「再現性を出す」は、自分で買うのではなく、実在のフォロワー・閲覧者に商品を紹介して、その人が購入することで成立させる必要がある。**
この前提を運用に組み込むこと。

## 5. 広告表示義務（ステマ規制・景品表示法）

**分かったこと**:
- 2023年10月1日施行の改正景品表示法により、アフィリエイト広告を含め「一般消費者が広告と判別できない表示」は**ステルスマーケティング規制の対象**になった
- 対策は「広告を広告だとわかるように明示すること」。投稿内に**「広告」「PR」「プロモーション」等の文字を分かりやすい場所に表示**する
- 違反時は景品表示法に基づく**措置命令**の対象になり、公表される

出典:
- [ステマ規制とアフィリエイト広告の表記ルール（アフィリエイト大学）](https://www.accesstrade.ne.jp/study/affidai/detail/343)
- [ステルスマーケティングに関するQ&A｜消費者庁](https://www.caa.go.jp/policies/policy/representation/fair_labeling/faq/stealth_marketing/)
- [アフィリエイトのPR表記例（薬機法マーケティング）](https://yakujihou-marketing.net/archives/4835)

→ [02-法務リスク.md](02-法務リスク.md) のステマ規制の論点がそのまま適用される。**投稿には必ず「PR」「広告」等を明記すること。**

## 6. 今すぐ動ける実行ステップ

1. 楽天会員登録（未登録の場合）→ [楽天アフィリエイト公式](https://affiliate.rakuten.co.jp/) からアフィリエイト登録（審査なし・即日可）
2. 楽天ROOM（room.rakuten.co.jp）に登録し、プロフィールを整備
3. **紹介する商品ジャンルを決める**（管理栄養士としての専門性を活かせる「食品・キッチン・健康関連」等が候補。詳細な商品選定は`marketing`エージェントに相談すると良い）
4. 投稿を**まず10〜20個作る**（少なすぎると離脱されやすいという指摘あり。出典: [楽天ROOM アフィリエイトのやり方完全ガイド](https://note.com/dear_pico/n/na6a1f8618b59)）
5. 各投稿・プロフィールに**「PR」「広告」を明記**（5章参照）
6. Instagram等と連携する場合は、プロフィールのリンクやストーリーズ経由でROOMのリンクへ誘導
7. 銀行振込を希望する場合は、**月3,001円以上の確定報酬が3ヶ月続く**まではひとまず楽天キャッシュ受け取りのまま様子を見る

## 7. 収益が発生したら

- アフィリエイト報酬は所得税法上の申告対象になりうる。**帳簿付け・金額の記録は`keiri`エージェントに担当させる**（[07-チーム設計.md](07-チーム設計.md)。ただし税額計算・申告書作成は税理士のみ）
- 「自分自身の実績」として[04-タスクリスト.md](04-タスクリスト.md) Phase 1のタスクに反映し、数値が積み上がったら`bunseki`エージェントに月次の推移を追わせる
- 実績を対外的に発信・教材化する際は、[02-法務リスク.md](02-法務リスク.md)の「収入実績・体験談の表示ルール」（誇大広告の回避）を必ず守る
