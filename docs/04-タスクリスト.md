## Phase 0. 土台を固める（着手順）

### 事業設計
- [ ] 🔴 **報酬設計を1枚にまとめる**（誰が・誰から・何の対価で報酬を得るか）※弁護士相談の前提資料
- [ ] 🔴 サービス全体像を図にする（フェーズ1〜4の関係、課金ポイント）
- [ ] 🔴 収益モデルを決める（月額制 / 買い切り / 段階課金）
- [ ] 🟡 価格を仮決めする（ライト層向け / 本気層向けの2階層）
- [ ] 🟡 サービス名・ブランドコンセプトを決める
- [ ] 🟡 競合・類似サービスを3〜5件調査（何を提供し、いくらで、どこが弱いか）
- [ ] 🟢 提供プラットフォームを比較（自社サイト / 既存オンラインサロン基盤）

### 法務（→ [02-法務リスク.md](02-法務リスク.md)）
- [ ] 🔴 **連鎖販売取引に該当しない設計であることを弁護士に確認**
- [ ] 🔴 「講座紹介を報酬源にしない」を設計原則として明文化
- [ ] 🔴 利用規約・特商法表記・プライバシーポリシーの3点セットを整備
- [ ] 🔴 特商法表記の住所問題を解決（自宅以外の選択肢を検討）
- [ ] 🟡 収入実績・体験談の表示ルールを決める（誇大広告の回避）
- [ ] 🟡 受講生向け「広告表示ガイドライン」（ステマ規制対応）を作成
- [ ] 🟡 健康・美容を扱う際の薬機法NGワードリストを作成
- [ ] 🟡 離婚・養育費相談の切り分けルールを決める（非弁行為の回避 + 繋ぎ先確保）
- [ ] 🟢 オフ会の参加規約・保険を検討

### 専門家の確保（→ [03-専門家の探し方.md](03-専門家の探し方.md)）
- [ ] 🔴 ひまわりほっとダイヤル or 分野特化の弁護士にスポット相談を申し込む

- [ ] 🟡 税理士を1名決定 → 自社の会計体制を構築

- [ ] 🟢 受講生を繋げる先（法テラス・ひとり親支援NPO）をリスト化
