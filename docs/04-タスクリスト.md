## 助成金・補助金（→ [08-助成金・補助金.md](08-助成金・補助金.md)）

**法人格がなくても、個人事業主として今すぐ取りに行けるものがある。** ここが最初の資金源。

### A. 事業者として取る（最優先・締切が近い）
- [ ] 🔴 **GビズIDプライムを申請する**（発行に2〜3週間。すべての入口になるので最初にやる）
- [ ] 🔴 居住自治体の創業助成金を検索する（「〇〇市 創業 助成金」）※東京都なら最大400万円
- [ ] 🔴 管轄の商工会／商工会議所に相談予約（持続化補助金の**様式4**発行に必要。11月上旬までに）
- [ ] 🔴 **小規模事業者持続化補助金 第20回**に申請する（受付 2026/11/5〜12/15 17:00、上限50万円〜、補助率2/3）
- [ ] 🟡 経営計画書を書く（[01-構想メモ.md](01-構想メモ.md) のターゲット・提供価値を転用）
- [ ] 🟡 補助対象経費の候補を洗い出す（LP制作／撮影・デザイン／SNS広告／オフ会の会場費）
- [ ] 🟢 デジタル化・AI導入補助金（旧IT導入補助金）を検討 ※有料ツールを本格導入する段階で
- [ ] 🟢 スタッフを雇う段階で特定求職者雇用開発助成金を確認（母子家庭の母の雇入れで中小企業60万円／ハローワーク紹介が必須）

### B. 支援事業として取る（準備に時間がかかる）
- [ ] 🟡 任意団体としての体裁を整える（団体名・規約・**理事2名以上**・銀行口座）※WAM助成の要件
- [ ] 🔴 **活動実績の記録を今日から始める**（日付・対象人数・内容）※「1年以上の活動実績」を要件にする助成が多い
- [ ] 🟡 支援事業と収益事業の帳簿を分ける（税理士に相談すべき論点）
- [ ] 🟡 年間の公募カレンダーを作る（フローレンス再助成=6月上旬／スミセイ=7月／赤い羽根福祉基金=11〜12月頃）
- [ ] 🟢 こども家庭庁のひとり親支援事業を「自治体からの受託」として狙えないか調べる

### 事故を防ぐ
- [ ] 🔴 **交付決定前に発注・支払いをしない**を原則として徹底（フライング経費は全額対象外）
- [ ] 🔴 助成金（無料相談の原資）で有料講座の集客をしない設計を明文化する
- [ ] 🟡 立替払いの運転資金を確保する（補助金は原則あと払い）
- [ ] 🟡 実績報告に備えた証憑管理のルールを決める（→ `keiri` エージェント）

## 次にやる3つ（迷ったらここから）

1. **報酬設計を1枚にまとめる** — すべての法務相談の前提
2. **弁護士にスポット相談を申し込む** — 連鎖販売取引の該当性を潰す
3. **Instagram の発信コンセプトを決める** — 集客もファン化も自社商品もここが起点

なお、スポンサー型（Phase 5）を本気で走らせるなら、上記②の弁護士相談の際に
**非弁行為の線引き**も同時に聞いてしまうのが効率的。論点が地続きなので一度の相談でまとめられる。

**bot（Phase 6）は上記3つと並行して進められる。** 月0円で始められ、
講座もスポンサーも待たずに動かせるため、最初に手が動くのはここかもしれない。
ただし危機対応シナリオだけは先に完成させること。
