### 集客・導線

## Phase 9. 収益モデル（→ [09-収益モデル.md](09-収益モデル.md)）

**A層＝チャレンジローンチ（資産づくり） / B層＝コンテンツ販売（収益づくり）**

### 🔴 両方の前提（最初にやる）
- [ ] 🔴 LINE登録後の**1問アンケートによるセグメント分岐**を作る
      （「副業をやってみたことはありますか？」→ ある/ない でA層B層を分ける）
- [ ] 🔴 「ある」と答えた人への追加質問（どこで止まったか）を設計
      ※ この回答がそのままコンテンツの商品設計データになる

### 🔴 コンテンツ販売の前に必ず（これがないと売ってはいけない）
- [ ] 🔴 **返品特約を作成し、販売ページ・申込画面に表示する**
      ※通信販売にクーリングオフはないが、返品特約の記載がないと受取から8日間は解除可能
- [ ] 🔴 特商法に基づく表記を整備（事業者名・住所・連絡先・価格・支払方法 等）
- [ ] 🔴 消費者庁の「通信販売における返品特約の表示についてのガイドライン」に沿った表示方法を確認

### B層向けコンテンツ販売
- [ ] 🟡 **小さいコンテンツを1つ作って売ってみる**（収益の検証）
- [ ] 🟡 課題別に商品を分ける（合うやり方が見つからない / 時間がない / 前回の詰まり）
- [ ] 🟡 価格は低めから始め、売れ方を見て決める
- [ ] 🟢 決済手段の選定
- [ ] 🟢 コンテンツ1本あたりの制作時間を記録（利益が残っているかの実態把握）

### A層向けチャレンジローンチ
- [ ] 🔴 **オファー設計を理念に合わせる**（高額バックエンドを置かない。低価格 or 段階的）
- [ ] 🟡 「残り◯席」「今だけ」で煽らない設計にする ※法務リスクでもある
- [ ] 🟡 次のステップは金融教育（お金を守る話）から入る形を検討
- [ ] 🟡 完走しなかった人を追いかけない方針を明文化
- [ ] 詳細タスクは Phase 8 参照

### 🔴 景表法チェック（ローンチで特にやりがちな違反）
- [ ] 🔴 二重価格をしない（「通常◯万円が今だけ」← その価格で売った実績が必要）
- [ ] 🔴 「残り◯席」「今日まで」を実態なく使わない（虚偽の解除条件は処分事例あり）
- [ ] 🔴 達成率・実績を出すなら**根拠資料を残す**（不実証広告規制）
- [ ] 🟡 「No.1」「一番わかりやすい」等の最上級表現を使わない

### 進める順番
- [ ] 分岐 → 返品特約・特商法表記 → **B層コンテンツで収益検証** → A層チャレンジ第1期
- [ ] ※ B層とA層の第1回を同時に走らせない（どちらも必ず想定外が起きる）

## Phase 10. 価格設計（→ [10-価格設計.md](10-価格設計.md)）

**原則: 稼ぐ前に払わせない。顧客の副収入を増やしてから売る。**

### コミットメント設計（初期投資をしない人は続かない、への対策）
- [ ] 🔴 **デポジット型を採用するか決める**（参加時に少額を預かり、完走で返金 or 次回充当）
- [ ] 🔴 採用するなら**返金条件を明文化**し、申込ページに明記（条件なしの「全額返金」表示は有利誤認）
- [ ] 🔴 表示と実際の運用を一致させる（承認制にするなら、そう書く）
- [ ] 🟡 価格以外のコミットメント手段も入れる（公開宣言・事前ワーク・定員制）
- [ ] 🟡 少額返金の手数料・手間を試算する（手数料負けしやすい）
- [ ] 🟡 **第1期と第2期で無料/デポジットを入れ替えて完走率を比較する**（印象でなく数字で決める）

### 設計
- [ ] 🔴 **本格的な課金（月額・講座）は「0→1達成後」に置く**ことを設計に固定する
- [ ] 🟡 価格ラダーの金額を決める（入口 / 月額 / 金融教育 / ビジネス）
- [ ] 🟡 継続課金は「副収入の5〜10%以内」を目安に設定
- [ ] 🟡 段階を上げる条件を**収入に紐づける**（稼げていない人を上位に案内しない）
- [ ] 🟢 値上げの判断基準を決める（顧客の収入が上がっていないのに上げない）

### 月額コミュニティ
- [ ] 🟡 **休会制度**を作る（子供の病気・収入変動で「退会」させない）
- [ ] 🟡 解約導線を分かりやすく作る（引き止めない）
- [ ] 🟡 毎月「入っている理由」がある状態を設計（何もない月を作らない）
- [ ] 🟢 決済ツールの選定（休会機能があるか確認）

### 🔴 サブスクの法務（月額を始める前に必ず）
- [ ] 🔴 **最終確認画面の6項目**を点検（分量・価格・支払時期・提供時期・撤回解除・申込期間）
- [ ] 🔴 **解約方法を最終確認画面に明記**する（リンク任せにしない）
- [ ] 🔴 「解約を申し出るまで継続する契約」である旨を明示
- [ ] 🔴 定期の場合、各回の代金と**支払総額**を表示
- [ ] 🟡 分割・後払いを検討する場合、割賦販売法の論点を弁護士に確認
- [ ] 🟡 決済ツール任せにせず、確認画面を自分で点検する
      ※定期購入規制は運用が厳格化しており業務停止命令の事例もある

### ⚠️ やらないことの明文化
- [ ] 🔴 借金・分割を勧めて高額商品を売らない
- [ ] 🔴 手当・生活費を切り崩させる訴求をしない
- [ ] 🔴 稼げていない人に上位商品を案内しない
- [ ] 🟡 判断基準を1行で共有: 「この人の子供の生活を削らせていないか」

### 測る
- [ ] 🟡 継続率・平均継続月数
- [ ] 🟡 **顧客の副収入の推移** ※これが伸びないと価格も上げられない

## Phase 11. 審査制（→ [11-審査制.md](11-審査制.md)）

**決定: 無料でも有料でも審査制にする。**

### 🔴 除外基準の最終決定（→ [11-審査制.md](11-審査制.md) 2.5）
- [ ] 🔴 **生活保護**：除外するか、条件付き可（ケースワーカー相談＋申告義務の明示）にするか決める
      ※就労・副業は禁止されておらず、勤労控除で手元に残る。除外は理念・助成金審査と衝突しうる
- [ ] 🔴 **借金**：除外するか、同意事項に変換するか決める
      ※「借金がある人」は奨学金・ローン・分割を含み対象者がほぼいなくなる
- [ ] 🔴 除外基準を**募集要項に書くか、内部基準に留めるか**を決める
- [ ] 🟡 多重債務の兆候がある人の案内先を用意（法テラス・消費生活センター188）
- [ ] 🟡 「借入をして参加費を払わない」を同意事項に入れる

### 審査基準
- [ ] 🔴 **合否基準を先に文章化する**（毎回悩まないため）
- [ ] 🔴 審査するのは「能力」ではなく「今動ける状態か」（時間の確保・目的の言語化・ルール同意）
- [ ] 🟡 判断に迷う人は合格に寄せる方針を明記

### 🚨 トリアージ
- [ ] 🔴 応募フォームに**緊急性を拾う設問**を入れる（生活費・住まい・安全・心身）
- [ ] 🔴 該当者には選考結果とは別に**必ず公的窓口を案内**する（[06](06-シンママbot.md)）
- [ ] 🟡 「状況が落ち着いたら次期に優先案内」の文面を作る

### ⚠️ 落とし方

- [ ] 🔴 落選者にも**必ず何かを渡す**（bot・無料リソースへの案内）
