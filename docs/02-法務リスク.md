## 1. 連鎖販売取引（特定商取引法）— 最重要論点

「講座を紹介したら報酬」という設計は、条件次第で **連鎖販売取引**（いわゆるマルチ商法）に該当します。
連鎖販売取引そのものは違法ではありませんが、特商法上の厳しい規制対象になります。

### 該当の分かれ目

消費者庁・弁護士解説によると、連鎖販売取引の成立には次の2つが必要です。

| 要素 | 内容 |
| --- | --- |
| **特定利益** | 紹介・あっせんの対価（紹介料・販売マージン・ボーナス等） |
| **特定負担** | 入会金・商品購入費・研修費などの負担 |

多段階アフィリエイトについては、**報酬の原資がどこか**で判断が分かれるとされています。

- ❌ **紹介した人が支払った登録料・システム利用料から報酬を得る** → 特定利益に該当し、連鎖販売取引になりうる
- ⭕ **発生したアフィリエイト報酬の一部を得る** → 該当しないとされる

### 該当した場合の義務・罰則

該当すると、概要書面・契約書面の交付義務、広告規制、勧誘時の禁止行為規制、クーリング・オフ（20日間）、中途解約権などが課されます。
違反には **6月以下の拘禁刑または100万円以下の罰金（併科あり）**。

### この事業での方針

**「講座紹介を報酬源にしない」を設計原則として固定する。**
受講生の収入源は外部案件のアフィリエイト報酬に限定し、自社講座の紹介インセンティブは設けない（または設けるとしても事前に弁護士レビューを通す）。

- [ ] 報酬設計を文書化し、弁護士に「連鎖販売取引に該当しないか」を明示的に確認
- [ ] 「ネズミ講と疑われない」ための対外説明文（FAQ）を用意

## 2. ステマ規制（景品表示法）

2023年10月1日施行。「一般消費者が事業者の表示であることを判別困難な表示」が不当表示に指定されました。

### 実務上のポイント

- アフィリエイト記事・SNS投稿には **「広告」「PR」「宣伝」「プロモーション」** 等を、わかりやすい場所に明記
- **規制対象は商品を供給する広告主**。アフィリエイターが独断で誇張しても、原則として **広告主が責任を問われる**
  - → 自社商品を作ってアフィリエイターに紹介させる場合、**こちらが責任主体になる**
- 違反時は措置命令、課徴金（対象売上の3%）

### この事業での影響

- 受講生に教える内容として **表記ルールの教育が必須**（トラブル予防とブランド保護の両面）
- 将来自社商品を出す場合、アフィリエイター管理体制（表示チェック）が必要

- [ ] 受講生向け「広告表示ガイドライン」を作成
- [ ] 規約に表示ルール遵守義務を明記

## 3. 薬機法・健康増進法（健康・美容フェーズ）

フェーズ3（健康・美容）および自社商品を扱う場合の最大リスク。

- 化粧品・健康食品・サプリで **効能効果の標榜には厳格な制限**（「痩せる」「治る」「改善する」等はNG）
- 体験談・ビフォーアフター画像の扱いにも制限
- 管理栄養士という肩書きは信頼になる一方、**発信内容の説得力が増すぶん行政の見方も厳しくなりうる**

- [ ] 薬機法に詳しい専門家（薬機法・広告法務特化の弁護士、薬事法有識者）を確保
- [ ] 発信・LP のNGワードリストを整備
- [ ] 受講生が美容商材を扱う場合の表現ルールを教材化

## 4. その他の論点

| 論点 | 内容 | 優先度 |
| --- | --- | --- |
| **特商法の通信販売表示** | オンライン講座販売には特定商取引法に基づく表記が必須（事業者名・住所・連絡先等）。自宅住所の開示可否は要検討（バーチャルオフィス等） | 高 |
| **個人情報保護法** | 受講生名簿、子供に関する情報、DV等の機微情報を扱う可能性 | 高 |
| **利用規約・特商法表記・プライバシーポリシー** | ローンチ前に3点セットで整備 | 高 |
| **誇大広告** | 「誰でも稼げる」「月◯万円確実」はNG。収入実績の表示ルールを設計 | 高 |
| **副業と就業規則** | 受講生が会社員の場合の注意喚起 | 中 |
| **扶養・手当への影響** | 児童扶養手当や扶養控除は所得によって変動。副収入が出た際の影響を金融教育に組み込む（要・税理士監修） | 高 |
| **確定申告・開業届** | 受講生が稼ぎ始めた後に必ず発生。税理士連携の主目的の一つ | 高 |
| **オフ会での事故・トラブル** | リアルイベントの保険、参加規約 | 中 |
| **相談内容の越境** | 離婚・養育費の相談に無資格で応じると弁護士法72条（非弁行為）の問題。相談は弁護士に繋ぐ導線に限定 | 高 |
