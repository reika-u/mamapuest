## 2. 名誉毀損・プライバシー権（一般的な論点の整理）

> ここに書くのは**一般的な法的論点の解説**であり、特定のエピソードが違法かどうかの判断ではありません。

### 2.1 名誉毀損の基本

**分かったこと**（弁護士解説記事より）:

- 名誉毀損とは、**公然と、他人の社会的評価を下げる事実を示す行為**をいい、原則として不法行為（損害賠償の対象）となり、刑事罰の対象にもなりうるとされている
- 示した事実が**真実**であっても、それだけで責任を免れるわけではない。一般的には次の3つが揃ったときに違法性が否定される（「真実性の抗弁」）と説明されている

| 要件 | 意味（言い換え） |
| --- | --- |
| ① 公共性 | その事実が「公共の利害に関する事実」であること（社会全体にとって知る意味があるか） |
| ② 公益目的 | 主として公益を図る目的で発信したこと |
| ③ 真実性（または真実相当性） | 内容が真実であること、または真実と信じたことに相当な理由があること |

- **公共性はかなり厳密に絞られる**と解説されている。犯罪や不正に関わらない「ただの」一般人の私生活は、公共性が否定されうる。ただし最高裁は、私人の私生活上の行状でも、その人の社会的活動の性質や社会への影響力によっては公共の利害に関する事実にあたる場合がある、としている
- SNSでの告発では「公益のため」「公共性があるから」と言われがちだが、名誉毀損の文脈でいう公共性はそれほど広くない、と注意喚起されている

**この事業にとっての意味（推測）**: 離婚エピソードの多くは「一般人同士の私生活」であり、上記①②が認められにくい類型に入る可能性がある。
さらに、このアカウントは事業の集客導線でもあるため、「主として公益目的」と言えるかにも疑問が残る。
→ **分からないので、弁護士に聞くべき事項（6章 Q-07）。**

### 2.3 プライバシー侵害 — 「真実でも」成立しうる

**分かったこと**:

- 1964年の「宴のあと」事件（東京地裁）が、プライバシー権を「私生活をみだりに公開されない権利」として認めた代表的な判例とされる。そこで示された3つの要素は次の通り
  1. 私生活上の事実、または**事実らしく受け取られるおそれのある事柄**であること
  2. 一般的な感受性を基準にして、**公開してほしくないと考えられる**事柄であること
  3. 一般の人々に**まだ知られていない**事柄であること
- **プライバシー侵害は、名誉毀損と異なり、公開した事実が真実であっても違法性が否定されない**（不法行為が成立しうる）と解説されている

**この事業にとっての意味（推測）**: 離婚の経緯、相手の不貞・借金・家族関係・病気などは、上の3要素に当てはまりやすい内容だと考えられる。
**「本当にあったことだから」は、プライバシーの問題に対しては盾にならない可能性がある**という点は、代表と共有しておきたい。

### 2.4 「特定されるか」（同定可能性）の考え方

匿名化・仮名化でどこまでリスクを下げられるかの核心部分。**公開情報で分かったのは「判断の枠組み」までで、「ここまでぼかせば足りる」という線は見つからなかった。**

**分かったこと**:

- 名誉毀損では、原則として「一般読者の普通の注意と読み方」を基準に表現を読み取るとされる
- ただし「石に泳ぐ魚」事件（モデル小説をめぐる事件）の東京地裁判決（1999年）は、**社会一般の人ではなく、その人物と面識がある人、またはその人物の属性のいくつかを知る人**を基準に、特定できるかを判断すべきとしたと紹介されている。同事件は最高裁（2002年）で、出版差止めを含む原告側の請求が認められた事件として知られる
- 長良川事件の最高裁判決（2003年）でも、本人と面識がある人や経歴を知る人が、その知識を手がかりに本人の記事だと推知できるか、という観点が示されたと紹介されている
- **イニシャル・伏字・仮名でも、文脈（他の投稿内容や登場人物の関係性）から特定できれば、同定可能性が認められる傾向**がある、と解説されている
- 「閲覧者」は世間一般より狭い範囲、たとえば勤務先の同僚・地域住民・同級生などに限定して考えられる場合がある、とされる

**この事業にとっての意味（推測）**:

- 離婚エピソードは、**元配偶者の親族・友人・職場の人が読めば「あの家の話だ」と分かる**タイプの情報になりやすい
- 特に、**投稿者（代表）が誰かが分かっている場合、その元配偶者が誰かも連鎖的に分かる**。[12](12-SNSマーケティング部.md) のアカウント間導線で代表の顔・名前・資格とつながる設計にすると、この連鎖が強まる可能性がある
- 子どもの年齢・人数・学年・習い事、居住地域、職業、離婚時期、特徴的な出来事の組合せは、1つ1つは一般的でも**組み合わせると特定につながる**（推測）

→ **「どの程度匿名化・脚色すれば特定されないと言えるか」は6章 Q-01で弁護士に聞く。**

### 2.5 名誉感情侵害（侮辱）— 匿名でも問題になりうる論点

**分かったこと**:

- 名誉感情侵害は、**本人が「自分のことだ」と認識できれば成立しうる**とされ、名誉毀損のような「第三者から見て誰か分かるか」（同定可能性）までは不要とする考え方が紹介されている
- 成立するのは「社会通念上許される限度を超える侮辱」の場合で、その判断は一般人の感受性を基準に客観的に行われるとされる

**この事業にとっての意味（推測）**: 完全に匿名化して第三者には誰か分からなくしても、**元配偶者本人が読めば自分のことだと分かる**のが離婚ネタの性質。
AI漫画で元配偶者を「悪役」として誇張・嘲笑する描き方をすると、この論点が生じる可能性がある。
→ **描写のトーンの目安は6章 Q-03で弁護士に聞く。**

### 2.6 「実話をもとにした創作」「この物語はフィクションです」表示の効果

**分かったこと**:

- 「この物語はフィクションです」という注記は、現実との混同や名誉・プライバシーのトラブルを避けるために広まった慣行で、**法律上の決まりではない**と説明されている
- 一方で、フィクションであっても**通常の読者から見て事実と受け取られるおそれがあれば、名誉毀損・プライバシーの問題の対象になる**という理解が紹介されている（前述「宴のあと」の「事実らしく受け取られるおそれのある事柄」とも整合する）
- 「石に泳ぐ魚」事件は、まさに**小説（創作）の形をとったモデル作品**で、プライバシー・名誉の侵害が認められた事例として紹介されている

**この事業にとっての意味（推測）**:

- アカウントのコンセプト自体が「**実際の**離婚エピソード」である以上、読者は内容を事実として受け取る前提で読む。**「フィクションです」表示の効果は、一般的な創作漫画よりもさらに限定的になる可能性がある**
- 逆に、特定を避けるために**脚色（事実と違う要素）を加えると、元配偶者について「事実でないこと」を描くことになり、名誉毀損の場面で「真実性」を主張しにくくなる方向に働く可能性**もある（推測）。匿名化のための脚色と、名誉毀損リスクの関係は、**弁護士に必ず確認すべき事項**（6章 Q-02）

### 2.7 離婚特有の追加論点 — 口外禁止条項・調停の非公開

**分かったこと**:

- 離婚協議書や和解・示談書には、**「口外禁止条項」「守秘義務条項」**（離婚の経緯や金額などを第三者に言わない約束）が入ることがあり、SNS投稿の禁止や違約金を定める例も紹介されている。違反すると損害賠償を請求されうるとされる
- 家事調停は非公開で行われ、プライバシーに配慮した手続きとされる。調停の内容をSNSで公開する場合、相手方の名誉・プライバシーとの関係で慎重な検討が必要と解説されている

**この事業にとっての意味**: 名誉毀損・プライバシーとは別に、**「自分が過去に交わした約束（契約）に違反しないか」という論点**がある。
これは代表本人の離婚協議書・公正証書・調停調書の中身次第で、**完全に個別事案の領域**。`homu` は判断しない。
→ **代表自身の書面を弁護士に見せて確認する（6章 Q-04）。** 外部募集の場合も、投稿者側に同じ論点がある（6章 Q-09）。

## 3. 著作権・肖像権（AI漫画生成ツールを使う場合の一般的な論点）

> 一般的に指摘されている論点の紹介です。特定のツールや特定の作品が適法かどうかの判断ではありません。

### 3.1 生成した漫画に「自分の」著作権はあるか

**分かったこと**:

- 文化庁（文化審議会著作権分科会 法制度小委員会）は2024年3月15日に「AIと著作権に関する考え方について」を取りまとめている。AI生成物が著作物にあたるかは、**AI利用者の「創作意図」と「創作的寄与」の程度**で判断されるとされる
- 人が具体的な表現に創作的に関与せず、AIが自律的に生成したものは著作物にあたらない（著作権が発生しない）のが原則と解説されている。**簡単な指示（プロンプト）1回で生成したものは、独占的な権利を主張しにくい**とされる
- 2025年11月、千葉県警が、生成AIで作られた画像を無断で複製・使用したとして著作権法違反の疑いで男性を書類送検したと報じられた。報道によれば、画像の作成者が**2万回以上プロンプトを入力し修正を重ねたこと**などから、創作的寄与があると判断されたとされ、「全国初の摘発」と報じられている（刑事手続上の判断であり、裁判所の確定判断ではない点に注意）

**この事業にとっての意味（推測）**: 簡単な指示で量産したAI漫画は、**他人に無断転載されても著作権で対抗しにくい可能性がある**。
逆に、構図・コマ割り・セリフ・加筆修正に人の手を多く入れるほど、権利を主張できる可能性は上がると考えられる。→ 6章 Q-14。

### 3.2 生成した漫画が「他人の」著作権を侵害しないか

**分かったこと**:

- AI生成物が既存の著作物の権利を侵害するかは、通常の著作権侵害と同じく**「類似性」（似ているか）と「依拠性」（元の作品をもとにしたか）**で判断されるとされる
- 利用者が既存の作品を知っていて、生成AIでそれに似たものを生成させた場合は、依拠性が認められると考えられる、とされる
- **特定の作品やクリエイターの作風を意図的に再現しようとプロンプトを調整すること**は、侵害のリスクが高いと指摘されている

**この事業にとっての意味（推測）**: 「〇〇（有名漫画家）風で」「〇〇（既存キャラ）みたいな元夫」といった指示は避けるのが安全側。→ 7章チェックリスト。

### 3.3 学習データの問題

**分かったこと**:

- 著作権法30条の4は、著作物に表現された思想・感情の「享受」（鑑賞して楽しむこと）を目的としない利用（AIの学習など情報解析）を、原則として許諾なく行えるとしている
- ただし文化庁の考え方では、**享受目的が1つでも併存する場合は30条の4が適用されない**とされている
- 学習段階の問題は主にAI開発者側の論点だが、**利用者は「生成・利用段階」で侵害の責任を問われうる**（3.2）

**この事業にとっての意味（推測）**: 利用者として直接コントロールできるのは「どのツールを選ぶか」と「どう指示するか」。
学習データの出所や、権利侵害時の補償（インデムニティ）を明示しているツールかどうかは、ツール選定の判断材料になる。→ 6章 Q-15。

### 3.5 肖像権 — 実在の人物に似せたAI画像

**分かったこと**:

- 意図的に容貌を再現し、本人と同一視できる程度に酷似している場合は、肖像権侵害が認められうるとされる。一方、「どの程度似ていれば問題か」は客観的に明確な線引きができない、とも指摘されている

## 4. 体験談を外部募集する場合の同意・利用許諾（一般的な実務慣行の紹介）

> 他メディアの一般的な実務を紹介するものであり、このアカウントの規約として十分かどうかの判断ではありません。
> **規約・同意書の最終版は、弁護士のレビューを通すこと。**

### 4.1 他メディアで一般的に見られる仕組み

**分かったこと**:

- 育児系メディア（例: ベビーカレンダー）は、体験談・マンガの投稿コンテストを開催し、**応募時に応募規約への同意**を求める形で募集している
- UGC（ユーザー投稿コンテンツ）を扱うサービスの利用規約では、一般的に次のような条項が置かれていると解説されている

| 条項の種類 | 内容（一般的な例） | 言い換え |
| --- | --- | --- |
| 権利の帰属 | 著作権を「投稿者に残したうえで利用を許諾してもらう」か「運営側に譲渡してもらう」かを明記 | 誰のものになるかを先に決める |
| 利用許諾の範囲 | 「無償かつ非独占的に、本サービスの運営・広報の目的で利用できる」等。商業利用・第三者への再許諾（サブライセンス）を含める例も多い | 何に・どこまで使ってよいか |
| 著作者人格権の不行使 | 著作者人格権は譲渡できないため、「行使しない」と合意してもらう。「放棄」ではなく「不行使」とする、運営側が指定する第三者に対しても行使しない旨を入れる、などの実務上の注意が解説されている | 漫画化・脚色（改変）について後から「勝手に変えた」と言われないようにする |
| 第三者の権利非侵害の保証 | 「投稿内容が第三者の権利を侵害しないことを保証する」 | 投稿者に、他人の権利を侵害していないと約束してもらう |
| 氏名表示 | 投稿者名を出すか、匿名にするか | 誰の体験談として出すか |

**この事業に特有の注意点（推測。4.2へ）**: 一般的なUGC規約は「投稿者の作ったもの」を扱う前提。
このアカウントで扱うのは「**投稿者が、他人（元配偶者・子ども）について語った話**」であり、一般的なUGC規約の条項だけではカバーしきれない論点がある。

## 5. 子ども（未成年者）が話に登場する場合の配慮点（一般論）

**分かったこと**:

- **子どもの権利条約16条**は、子どもが私生活・家族・住居・通信に恣意的・不法に干渉されず、名誉・信用を不法に攻撃されない権利を定めている
- **こども基本法**（2022年6月成立、2023年4月施行）は、子どもの権利条約の精神にのっとり、子どもの意見の反映などを定めている
- 親が子どもの写真や私生活をSNSに公開することは**「シェアレンティング」**と呼ばれ、欧米では既に問題視されている。子どもの肖像権・プライバシー侵害、デジタルタトゥー（一度ネットに出た情報が消せないこと）、写真の悪用などのリスクが指摘されている。弁護士解説では、写真だけでなく**「エピソードだけ」の発信も慎重に**とされている
- 個人情報保護委員会のFAQでは、個人情報の取扱いに関する同意について、一般的に**12歳から15歳までの年齢以下の子ども**は法定代理人（通常は親）から同意を得る必要があると考えられる、とされている
- **2026年の個人情報保護法改正**（2026年7月10日成立、7月17日公布と解説されている）で、**16歳未満の子どもの個人情報**について、同意取得などに法定代理人の関与を求める規律が新設されたと解説されている。施行は段階的とされる（一部2027年、主要部分は2028年までの政令で定める日、との解説あり）。**施行日・具体的内容は個人情報保護委員会の公式発表で必ず確認すること**

**この事業にとっての意味（推測）**:

| 配慮点 | 理由（推測） |
| --- | --- |
| 子ども本人は同意を判断できないことが多い | 年齢的に、将来どうなるかを判断できない |
| **親が同意するだけでは足りない可能性** | 投稿する親は離婚の当事者であり、子どもの利益と親の発信したい気持ちがずれる場面がありうる。もう一方の親（元配偶者）も親権・監護の状況によっては関係しうる |
| 子どもは将来それを読む | 両親の離婚の経緯や、もう一方の親を悪く描いた内容を、成長した子ども本人や同級生が読む可能性がある |
| **子どもの特定は、元配偶者の特定にも直結する** | 子どもの年齢・学年・学校・習い事・特徴は、地域の人や保護者仲間には特定材料になる（2.4） |
| 学校・地域でのいじめ | 子どもが特定された場合の二次被害 |
| 虐待・DV・面会交流をめぐる内容 | 子どもにとって最も知られたくない情報になりうる |

→ 未成年が関わるエピソードの追加的な配慮事項は、**6章 Q-05で弁護士に聞く。**
`homu` としては、弁護士の回答を得るまでは「**子どもの具体的なエピソードは扱わない**」側に倒すことを推奨する（最終判断は代表）。

### 質問の詳細

#### Q-01【A】匿名化・脚色の程度と「特定されない」の判断基準

- **背景**: 代表本人や外部投稿者の離婚エピソードをAI漫画にする。公開情報では、同定可能性は「面識のある人・属性を知る人が特定できるか」で判断されうる（2.4）と分かったが、「どこまでぼかせば足りるか」の線は見つからなかった。また、代表が他アカウントで顔出し・実名・資格名で発信している（または今後する）場合、「代表の元夫」は代表を知る人には特定できてしまう
- **聞きたいこと**:
  1. 名前・地域・時期・職業・子どもの人数や年齢などのうち、特に特定につながりやすいとされる情報は何か。変更・削除の優先順位はあるか
  2. **投稿者（代表）自身が特定されている状態で、元配偶者の特定を避けることは現実的に可能か**。アカウントを代表の他アカウントとつなげない（相互リンクしない、代表の顔を出さない）ことで、リスクは意味のある程度下がるか
  3. 「元配偶者の知人や親族が読めば分かる」レベルでも問題になりうるのか
- **こちらの想定**: 完全に特定を防ぐのは難しく、「特定されにくくする工夫」と「描く内容を選ぶ（相手の私生活・悪評に踏み込まない）」を組み合わせる必要がある、と予想している。場合によっては「代表本人のネタは、代表の他アカウントと切り離さないと扱えない」という結論もありうると考えている

#### Q-02【A】「実話をもとにした創作」表示の効果と脚色の副作用

- **背景**: 「この物語はフィクションです」表示は法律上の決まりではなく、事実と受け取られるおそれがあれば名誉毀損・プライバシーの対象になりうると解説されている（2.6）。一方、アカウントのコンセプトは「実際の離婚エピソード」
- **聞きたいこと**:
  1. 「実話をもとにした創作です」「一部脚色しています」といった表示で、リスクはどの程度変わるか。表示の文言・位置で違いはあるか
  2. 特定を避けるために事実と違う要素を加えた場合、元配偶者について「事実でないこと」を描いたことになり、かえって不利になる場面はあるか
  3. 「実話」を売りにするアカウントであること自体が、判断にどう影響するか
- **こちらの想定**: 表示だけで責任が免れることはなく、補助的な効果にとどまると予想。脚色は「特定を避ける方向」（地域・時期・職業などの属性の変更）に限定し、「相手の行為をより悪く描く方向」には使わない、という線が考えられるが、確認したい

#### Q-03【A】名誉感情侵害と描写トーン

- **背景**: 名誉感情侵害（侮辱）は、第三者から誰か分からなくても、本人が自分のことと認識できれば成立しうるとされる（2.5）。離婚ネタでは、元配偶者は必ず「自分のことだ」と分かる
- **聞きたいこと**:
  1. 完全に匿名化しても、元配偶者本人が読んで自分のことだと分かる場合、どのような描き方が問題になりうるか
  2. 漫画特有の誇張表現（悪役顔、動物・モンスターに例える、「クズ夫」等の呼び方）は、どう評価されやすいか
  3. 「相手への評価や感情」ではなく「自分がどう感じ、どう乗り越えたか」を中心に描く構成は、リスク低減として意味があるか
- **こちらの想定**: 相手を嘲笑・侮辱する表現は避け、「自分の気持ち・行動・学び」を主語にする構成が安全側と予想。確認したい

#### Q-04【A】代表本人の離婚時の書面との関係（代表個人の個別相談）

- **背景**: 離婚協議書・和解・調停調書に口外禁止条項・守秘義務条項が入っている場合、SNS投稿が契約違反になりうると解説されている（2.7）。**これは代表本人の書面の中身次第の完全な個別事案で、`homu` は判断しない**
- **聞きたいこと**:
  1. （代表の離婚協議書・公正証書・調停調書を持参して）発信の制限につながる条項はあるか
  2. 調停の場で出た話（相手の発言など）を発信することについて、注意点はあるか
- **こちらの想定**: 事前に想定はしない。書面を持参して見てもらう
- **注意**: 相談時は、事業の相談（Q-01〜Q-17）と代表個人の相談を分けて依頼する方が、費用・利益相反の整理がしやすい可能性がある（推測。相談時に弁護士に確認）

#### Q-05【A】未成年が関わるエピソードの追加的な配慮

- **背景**: 子どもの権利条約16条、こども基本法、個人情報保護法（FAQでは12〜15歳以下は法定代理人の同意、2026年改正で16歳未満の規律新設と解説）などがある（5章）。子どもは同意を判断できず、同意する親は離婚の当事者
- **聞きたいこと**:
  1. 子どもが登場するエピソードを扱う場合に、特に配慮すべき点は何か。扱うべきでない類型（虐待、面会交流の具体的なやりとり、学校生活など）はあるか
  2. 親権者である投稿者（代表）の同意で足りるのか。もう一方の親の立場はどう考えるか
  3. 子どもの年齢・人数・性別などを変更すれば足りるのか。子どもを登場させないという選択まで必要か
  4. 2026年の個人情報保護法改正（16歳未満の規律）は、このアカウントのような発信に影響するか
- **こちらの想定**: 回答を得るまで、子どもの具体的なエピソードは扱わない方針を代表に推奨している

#### Q-06【A】元配偶者から削除要請・法的措置の予告があった場合の初動

- **背景**: 情報流通プラットフォーム対処法（2025年4月施行）で、大手SNSへの削除申出のルートが整備されている。発信者情報開示の意見照会は回答期限が7〜14日程度と短いとされる（2.9）
- **聞きたいこと**:
  1. DM・メール・内容証明などで削除要請や「訴える」という連絡が来た場合、最初の24〜48時間でやるべきこと・やってはいけないことは何か
  2. 投稿をすぐ削除・非公開にすべきか。削除することが「非を認めた」と扱われることはあるか。証拠として保存すべきものは何か
  3. 相手に直接返信してよいか。返信する場合に避けるべき内容は何か
  4. Instagramから削除通知やアカウント制限が来た場合の対応
  5. 意見照会書が届いた場合の対応
  6. 緊急時にすぐ連絡できる弁護士を確保しておくべきか（スポット相談契約の形）
- **こちらの想定**: 「一人で判断して相手に返信しない」「記録を保存する」「すぐ弁護士に連絡する」の3点を暫定の心構えにしたい（7.5）。具体的な手順は弁護士の回答で置き換える

#### Q-07【A】事業アカウントとして発信することの意味

- **背景**: このアカウントは個人の日記ではなく、LINE登録・シンママbot・講座への集客導線の一部（[12](12-SNSマーケティング部.md) 1.4）。名誉毀損の違法性阻却には「主として公益目的」が要件とされる（2.1）
- **聞きたいこと**:
  1. 集客目的の事業アカウントで発信すること自体が、公益目的の判断で不利に働くか
  2. 責任を問われる主体は誰になるか（代表個人、将来設立する法人など）。アカウント名義や運営者表示との関係
  3. 「シングルマザーの支援」「離婚で孤立する人を減らす」という事業の目的は、公共性・公益目的の判断で考慮されうるか
- **こちらの想定**: 集客目的は公益目的の主張を弱める方向に働く可能性があると予想（推測）。確認したい

#### Q-08【B】外部募集の同意書・利用規約

- **背景**: 他メディアでは応募規約への同意、権利帰属・利用範囲・著作者人格権の不行使・第三者権利の非侵害保証などが一般的（4.1）。4.3に項目の候補を作った
- **聞きたいこと**:
  1. 体験談募集に使える同意書・利用規約のひな形はあるか（弁護士側で持っているか、参考になる公開ひな形はあるか）
  2. 4.3の項目に過不足はあるか
  3. 投稿者が後から削除・撤回を求めた場合の扱いを、どう規約に書くべきか
  4. 投稿者が未成年だった場合の扱い
  5. 同意の取り方（フォームのチェックボックスで足りるか、書面・電子署名が必要か）
- **こちらの想定**: 4.3を叩き台として持参し、赤入れしてもらう

#### Q-09【B】投稿者の同意・保証と、第三者に対する事業者の責任

- **背景**: 投稿者の同意はとれても、登場する元配偶者・子どもの同意はとれない。保証条項は投稿者と事業者の間の約束（4.2 #1・#2・#8）
- **聞きたいこと**:
  1. 投稿者に「第三者の権利を侵害しない」と保証してもらっても、公開した事業者が元配偶者から責任を問われる可能性は残るか
  2. 残る場合、事業者側でできるリスク低減策は何か（掲載基準、編集方針、掲載前のチェック体制など）
  3. 投稿者側に口外禁止条項がある場合、それを知らずに掲載した事業者に影響はあるか。事前に確認する方法は
- **こちらの想定**: 保証条項だけで事業者の責任がなくなるわけではないと予想（推測）。掲載基準と編集体制がより重要になると考えている

#### Q-10【B】機微情報・個人情報保護法

- **背景**: 体験談にはDV・病歴・犯罪被害など機微な情報が含まれうる。個人情報保護法には報道・著述目的などの適用除外（57条）があるが、SNS漫画アカウントに当てはまるかは公開情報では分からなかった（4.2 #6・#7）。2026年改正法もある
- **聞きたいこと**:
  1. 体験談の受付・保管・編集で、個人情報保護法上どのような義務が生じるか
  2. このアカウントの活動が「著述」目的の適用除外に当たる可能性はあるか（集客導線であることの影響も含めて）
  3. 受け取った体験談を生成AIツールに入力することは、個人情報の第三者提供・委託に当たるか。どのような手当てが必要か
  4. 2026年改正（課徴金、16歳未満の規律など）で、このアカウントの運用上、施行までに準備すべきことはあるか
  5. プライバシーポリシーに書くべき内容
- **こちらの想定**: 適用除外に頼らず、通常の個人情報取扱事業者として扱う前提で設計する方が安全側と予想（推測）

#### Q-11【B】投稿者がDV被害者等である場合の安全配慮

- **背景**: DV等の被害者は住民票の閲覧制限などで居所を守っている場合がある。体験談の公開でその保護を崩してしまう危険がある（4.2 #5）
- **聞きたいこと**:
  1. DV・ストーカー等の事情がある投稿者の体験談を扱う場合、事業者として最低限確認・配慮すべきことは何か
  2. そうした体験談は、原則として扱わない方がよいか
  3. 加害者側から「これは自分のことだ」と連絡があった場合の対応
- **こちらの想定**: DV等の事情がある体験談は、弁護士の回答を得るまで扱わない方針を推奨する（最終判断は代表）

#### Q-12【B】謝礼を払う場合の契約上の注意

- **背景**: 体験談に謝礼（ギフト券など）を払う可能性がある（4.2 #10）
- **聞きたいこと**: 謝礼の有無で、同意書・規約に書くべき内容や、事業者の責任の考え方は変わるか
- **こちらの想定**: **税務（源泉徴収の要否、経費計上など）は税理士に聞く事項**なので、ここでは契約面のみ聞く（[07](07-チーム設計.md) 2章の税理士独占業務の線引き）

#### Q-13【B】事実確認できない投稿・報復目的の投稿

- **背景**: 外部投稿の内容が真実か確認できない。元配偶者への報復やなりすましに使われる可能性（4.2 #3・#4）
- **聞きたいこと**:
  1. 事業者が内容の真実性を確認できない場合、名誉毀損の「真実性・真実相当性」の場面で事業者はどう扱われるか
  2. 掲載しない基準（例: 相手の不貞・犯罪・借金などを具体的に告発する内容、相手の職業・勤務先に触れる内容）として、どのようなものを持つべきか
  3. 投稿者の本人確認はどこまで必要か
- **こちらの想定**: 「相手を告発・非難する内容」ではなく「投稿者自身の経験・気持ち・その後の生活」を中心にした体験談だけを採用する、という掲載基準が考えられる。確認したい

#### Q-14【C】AI漫画の著作物性と無断転載への対抗

- **背景**: AI生成物は、創作意図と創作的寄与がなければ著作物にならないとされる（3.1）
- **聞きたいこと**:
  1. このアカウントのAI漫画で、権利を主張できるようにするには、制作過程でどの程度人の手を入れ、何を記録しておくべきか
  2. 無断転載された場合に取れる手段
- **こちらの想定**: 制作過程（プロンプト、修正履歴、手描き加筆）を記録しておくことが有益と予想

#### Q-15【C】AIツール選定で法務的に見るべき点

- **背景**: ツールごとに商用利用・権利帰属・入力データの学習利用・補償の有無が異なる（3.3・3.4）
- **聞きたいこと**: 3.4の確認項目に過不足はあるか。特に注意すべき規約条項は何か
- **こちらの想定**: 候補ツールの規約を持参して見てもらう

#### Q-16【C】二次利用（書籍化・広告など）

- **背景**: 反響が大きい場合、書籍化・広告・他アカウントでの再利用がありうる
- **聞きたいこと**: 当初の同意の範囲を超えて使う場合の手続き。広告に使う場合、景品表示法（ステマ規制等、[02](02-法務リスク.md) 2章）との関係で注意すべき点
- **こちらの想定**: 当初の同意書に利用範囲を広めに書くか、都度追加同意をとるかの選択になると予想

#### Q-17【C】紛争に備えた保険・相談体制

- **背景**: 紛争が起きた場合、金額よりも対応の時間・負担・事業の信用への影響が大きい可能性（2.9）
- **聞きたいこと**: 個人事業主・小規模事業者がこの種のリスクに備える保険（賠償責任保険等）はあるか。顧問契約・スポット契約のどちらが向いているか
- **こちらの想定**: 公開情報では確認していない。弁護士・保険代理店に聞く事項

## 7. 運用ルール案（投稿前チェックリストのたたき台）

> **重要: このチェックリストは、代表と弁護士が最終確認するまでは運用しません。**
> チェックをすべて満たしても、その投稿が適法であることを意味しません。
> あくまで「弁護士に見てもらうための下書き」であり、6章の回答を受けて書き換える前提です。
> `homu` はこのチェックリストをもって「この投稿は大丈夫」と判断することはしません。

### 7.1 ネタ選定時

- [ ] そのエピソードの中心は「投稿者自身の気持ち・行動・その後」か（元配偶者を告発・非難することが中心になっていないか）
- [ ] 元配偶者の**不貞・犯罪・借金・病気・性に関すること・家族の事情**など、特に知られたくないとされる私生活の事実を扱っていないか
- [ ] **子どもの具体的なエピソード**が含まれていないか（Q-05の回答を得るまでは扱わない）
- [ ] DV・ストーカー等、投稿者の安全に関わる事情が含まれていないか（Q-11の回答を得るまでは扱わない）
- [ ] 代表本人のネタの場合、離婚協議書・調停調書等の口外禁止条項との関係を確認済みか（Q-04）
- [ ] 調停・裁判の場で相手が述べたことをそのまま描いていないか

### 7.2 制作時（AI漫画化）

- [ ] 実名・ニックネーム・イニシャルを使っていないか
- [ ] 地域（都道府県・市区町村・最寄り駅・特徴的な場所）、時期、職業・勤務先、学校、子どもの人数・年齢・性別など、**組み合わせで特定につながる情報**を変更・削除したか（どこまで変えるかはQ-01の回答で具体化）
- [ ] 元配偶者・子ども・家族の**写真をAIに読み込ませていないか**。キャラクターが実在の人物に似せられていないか
- [ ] 実際のLINE・メール・手紙の文面やスクリーンショットをそのまま使っていないか
- [ ] 元配偶者を侮辱・嘲笑するような表現（呼び名、外見の描き方、動物やモンスターへの例え）になっていないか（Q-03）
- [ ] 特定の漫画家・作品の作風やキャラクターを真似るプロンプトを使っていないか
- [ ] 使用しているAIツールの利用規約で、商用利用が許されているか（最新版を確認したか）
- [ ] 体験談の原文（個人情報を含むもの）をAIツールにそのまま入力していないか（[07](07-チーム設計.md) 6章の原則。入力前に名前・地域・具体的事実をマスクする）

### 7.3 投稿前の最終確認

- [ ] 「元配偶者の親族・友人・職場の人が読んだら、誰の話か分かるか」という目線で読み直したか
- [ ] 「元配偶者本人が読んだら、どう受け取るか」という目線で読み直したか
- [ ] 「子どもが10年後に読んだら、どう感じるか」という目線で読み直したか
- [ ] 「実話をもとに一部脚色しています」等の表示、AI生成である旨の表示を入れたか（効果の程度はQ-02で確認。表示があれば足りるわけではない）
- [ ] キャプションに「個別の相談には応じられない」「法律相談は弁護士へ」の旨を入れたか（DMで離婚の個別相談が来ることへの備え。[07](07-チーム設計.md) 2章の非弁行為の線引き）
- [ ] 投稿の最終判断を代表本人が行ったか（[12](12-SNSマーケティング部.md) 1.3、[07](07-チーム設計.md) 共通ルール）

### 7.4 外部募集の体験談を使う場合（追加）

> 6章の優先度Bの回答を得るまでは、外部募集自体を開始しない。

- [ ] 弁護士レビュー済みの同意書・規約に、投稿者が同意しているか（Q-08）
- [ ] 投稿者がそのエピソードの当事者本人であることを確認したか
- [ ] 投稿者側の口外禁止条項・守秘義務の有無を確認したか（Q-09）
- [ ] 掲載基準（Q-13）に照らして、告発・報復目的と疑われる内容でないか
- [ ] 投稿者が未成年でないことを確認したか
- [ ] 漫画化・脚色した完成版を、掲載前に投稿者に確認してもらったか（投稿者の身元が周囲に分からないかの確認も含む）
- [ ] 受け取った原文の保管場所・保管期間・廃棄方法が決まっているか

### 7.5 投稿後に削除要請・法的措置の予告が来た場合（暫定の心構え）

> 具体的な手順はQ-06の回答で置き換える。以下は、弁護士解説記事で一般的に言われていることをもとにした暫定の心構えにすぎない。

1. **一人で判断して相手に返信しない**（事実を認める・争う・謝罪するなどの内容を、弁護士に相談する前に送らない）
2. **記録を残す**（届いた連絡の全文・日時、該当投稿の内容・URL・投稿日時のスクリーンショット）
3. **すぐ弁護士に連絡する**（意見照会書などは回答期限が7〜14日程度と短いとされる）
4. `marketing` や `homu` に「この投稿は問題ないか」を判断させない（AIに「大丈夫です」と言わせない。[07](07-チーム設計.md) 6章）
