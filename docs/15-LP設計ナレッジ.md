## 2. 分析するときの観点（このプロジェクト用）

参考LPを見るとき、**真似する前に仕分ける**ための3分類。

| 分類 | 中身 |
| --- | --- |
| ⭕ **そのまま採る** | 構成の順番、情報の出し方、可読性の工夫、フォームの手前の設計 |
| △ **翻訳して採る** | 訴求の型は採るが、言葉は自分の層（A層／B層）に合わせて書き換える |
| ❌ **採らない** | 煽り、誇大表現、虚偽の限定、不安の商法 → [13-大義.md](13-大義.md) に反する |

> **この業界のLPは、うまい構成と危ない表現が混在しています。**
> 「売れているから正しい」ではなく、**構成は学び、表現は自分の基準で書く**。

## 3. 自分のLPに必ず入れるもの（法務要件）

参考LPに入っていなくても、**これは入れます。** 既存ドキュメントからの集約です。

### 🔴 必須表示

| 項目 | 根拠 |
| --- | --- |
| **特定商取引法に基づく表記**（事業者名・住所・連絡先・価格・支払方法・提供時期） | [09](09-収益モデル.md) |
| **返品特約**（デジタルコンテンツは返品不可を明示。書かないと受取から8日間は解除可能） | [09](09-収益モデル.md) |
| プライバシーポリシー／個人情報の利用目的 | [11](11-審査制.md) |
| 月額を置く場合、**最終確認画面の6項目**と解約方法の明記 | [10](10-価格設計.md) |

### 🔴 やらない表現

| ❌ | 根拠 |
| --- | --- |
| 「通常◯万円が今だけ◯円」（実績のない二重価格） | 有利誤認 → [09](09-収益モデル.md) |
| 「残り◯席」「今日まで」（実態のない限定） | 虚偽の限定。処分事例あり |
| 「◯%が達成」（根拠資料を出せない数値） | 不実証広告規制 |
| 「誰でも稼げる」「必ず月◯万」 | 誇大広告 |
| 「仕事を紹介します」「案件をお渡しします」 | 業務提供誘引販売取引に該当しうる → [02](02-法務リスク.md) |
| 効果効能の標榜（健康・美容） | 薬機法 → [02](02-法務リスク.md) |
| PR表記のないアフィリエイト・商品紹介 | ステマ規制 → [02](02-法務リスク.md) |

### 大義との整合チェック（[13-大義.md](13-大義.md)）

- [ ] 不安を煽って動かしていないか
- [ ] 「子供の生活を削らせる」訴求になっていないか
- [ ] 借入・分割を前提にしていないか
- [ ] 読んだ人が、買わなくても何かを持ち帰れるか
