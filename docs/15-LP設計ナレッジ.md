## 1.7 🔑 お客様の声の設計（ここが一番緻密）

5本のCaseは**ランダムに並べていません。ペルソナを網羅しています。**

| Case | 人物 | カバーしている層 | Before（数字で語る失敗） | After |
| --- | --- | --- | --- | --- |
| 01 | なぷさん | **中上級者で伸び止まり** | 一度伸びが止まったら再起は難しいと周りに言われ諦めかけていた | YouTube 2ヶ月で200→11,240人／Instagram 3ヶ月で2.6万→4.2万人 |
| 02 | ちゃいさん | **何をやってもダメだった挫折者** | 「アカウントを3〜4個作って、最大でも600フォロワー全部、挫折」「他の講座も受けていたけど…教材通りやってる"つもり"なのに成果に繋がらない」 | 2週間8投稿目で19万再生／1ヶ月5,000人・3ヶ月1万人／PR案件初月10万円超／売上100万円超 |
| 03 | 翔子さん | **40代フルタイム3児のワーママ＝時間がない層** | 「高額の講座に入って半年学んでいたけど…毎日投稿していても半年で増えたフォロワーは190人ほど」 | 3ヶ月で2万人以上／オンラインサロンをオープン |
| 04 | せなさん | **人生の岐路**（会社員を1年で退職、鬱と診断） | 「再生数は良くて1,000 フォロワーは2桁 もちろん収益は0」 | 18投稿で1.2万人 |
| 05 | みなみさん | **もう辞めようと思っていた層** | 「もうインスタ辞めよう」っていう気持ちでした | 1ヶ月・9投稿で万垢／3ヶ月目に本業の3ヶ月分の収益 |

> **読者が「自分に近い人」を必ず1人見つけられる設計。**
> あなたの場合、A層／B層／時間がない人／過去に失敗した人 を網羅する形になります。

### 声の「型」が統一されている

すべてのCaseが同じ順番で書かれています。**このテンプレートはそのまま使えます。**

```
① キャッチ（一言の変化）    「教科書がなかったら今の私はありません！」
② 属性ラベル               「40代フルタイム3児のワーママさんでも…」
③ Before（数字で語る失敗）  「3〜4個作って最大600フォロワー、全部挫折」
④ 転機                     「藁にもすがる思いで購入」「新垢をリアルタイムで伸ばすのを見て」
⑤ After（数字）            「2週間8投稿目で19万再生」
⑥ 感情の一言               「初めて腹落ちしました」「世界が変わりました」
⑦ アカウント名を公開        @chay_kotoba  ← 検証可能にしている
```

**🔑 効いているのは③の具体性です。**
「うまくいかなかった」ではなく「**600フォロワーで挫折**」「**半年で190人**」「**フォロワーは2桁、収益は0**」。
数字で失敗を語らせることで、読者が自分の現在地と比べられる。

→ **W8のヒアリングで、この7項目を聞く設計にしてください。**（[11-審査制.md](11-審査制.md) のヒアリングに組み込める）
   特に**参加前の状態を数字で**残しておかないと、後から書けません。

### ⭕ コミュニティの見せ方 — ここは大義と一致する

Case03 に、購入後の環境が列挙されています。

> ラジオを収録／月イチ質問会／添削LIVE／アーカイブ／「なるのつぶやき部屋」
> 「私たちのような**オカン業が忙しい人のために**タイムリーな有益な情報を！」

さらに「教科書のオフ会は学びと交流のバランスが絶妙」「**表彰者の個別zoom**もあって
『ちゃんと見てもらえてる』って実感できました」。

> **「買った後も置いていかれない」ことの証明**になっています。
> これは [13-大義.md](13-大義.md) の「孤立させない」と完全に一致します。
> **むしろあなたこそ、ここを強く出すべき部分。**

### ⭕ 原因を分解して見せる（21番）

「あなたが悪いのではなく、**原因がある**」という構造。
これは [08-ターゲット設計.md](08-ターゲット設計.md) の
**B層への立て直し（「やり方が合わなかっただけ」）と同じ構造**です。そのまま採れます。

## 1.8 ⚠️ お客様の声で、真似してはいけない3点

### ① 「高額講座より」という比較訴求

繰り返し出てきます。

> 「正直そこらへんの講座より"講座"でした笑」（Case01）
> 「高額講座に行く前に、まずこれ！」「そこらへんの高額講座より圧倒的に価値が高い」（Case05）

**他社を貶める比較優良誤認のリスク**があります。
しかも「お客様の声」の形を借りているため、**書かせた側の責任**が問われます。
（アフィリエイターの表現と同じ構造 → [14](14-アフィリエイト設計.md)）

→ **あなたは他社と比較しない。** 自分の提供物だけで語る。

### ② 「99%の発信者は」

出典のない数字です。**不実証広告規制**（[09](09-収益モデル.md)）。
根拠資料を求められて出せなければ不当表示になります。

→ 使うなら**自分で取ったアンケートの実数**（「チャレンジ参加者◯名中◯名が」）。

### ③ 🔴 依存を示す声を載せない ← 最重要

> 「**なるさんは私達の神様です！**」
> 「子供たちと伏見稲荷行ってたんですが、なるさんが**もっともっと幸せになりますように**って祈ってきました！！」（Case03）

売り手としては「効く」声です。しかし——

> **あなたの事業は自立を支援する事業です。**
> 「神様」と呼ばれる関係は、**孤立の反対ではなく依存**であり、
> [13-大義.md](13-大義.md) の「選択肢を増やす」と真逆の方向です。

集める声の性質が、事業の性質を決めます。

| ❌ 集めない声 | ⭕ 集めたい声 |
| --- | --- |
| 「◯◯さんのおかげです」「神様です」 | 「**自分で判断できるようになった**」 |
| 「ついていきます」 | 「**もう一人でやっていけそうです**」 |
| 主宰者への感謝が中心 | **自分の変化**が中心 |

Case01 に、まさに良い例があります。

> 「添削がなくても**自分で改善できる感覚が持てた**のが本当に大きいです」

**これがあなたの集めるべき声です。** ヒアリングでも、この方向に質問を向けてください。

## 1.5 この構成から学べること／学ばないこと

### ⭕ そのまま採れる（構成・型）

| 学ぶ点 | なぜ効くか |
| --- | --- |
| **悩みをチェックリストで言語化 → 「こう思っている人は多いはずです」** | 読者が「自分のことだ」と認識する。A層にそのまま使える |
| **「でも」で反転する** | 不安 → 希望の転換。構造として汎用 |
| **🔑 再現性の証明**（過去の権威を使わずゼロから検証） | **「あなただからできた」への先回り反論**。この構成が一番強い |
| **疑念の先回り**（「そう疑う気持ちはよくわかります」） | 否定せず受け止めてから開く。誠実に見える |
| **受講生の声をCase形式で** | 第三者の証言。アカウント公開で検証可能にしている |
| **背景色でセクションを区切る** | 縦長LPの可読性。実装コストも低い |
| **数字を極端に大きくする** | スマホの流し読み対策 |
| **CTAの繰り返し設置** | 読者が決めた瞬間に押せる |

### 🔑 最大の学び：「再現性の証明」をどう作るか

このLPで一番よくできているのは **13番のセクション**です。
「実績がすごい人の話は、自分には再現できない」——読者の最大の壁に対して、
**過去の権威を使わずゼロから作り直して見せる**ことで反論しています。

**あなたの場合、これに相当するのは自分の実績ではありません。**

> **チャレンジ参加者が0→1を達成した事実**が、あなたの「再現性の証明」です。

→ [12-ローンチ計画.md](12-ローンチ計画.md) の **W8（11/13-19）の事例づくりが決定的**。
ここが埋まるかどうかで、12/16のLPの説得力が決まります。

### △ 翻訳して使う

| 参考LP | あなたの場合 |
| --- | --- |
| 悩み＝「もう遅い」「伸びない」 | A層＝「何から始めればいいか分からない」「情報を判断できない」 |
| 信頼＝**収益実績の列挙** | 信頼＝**大義＋管理栄養士の専門性＋当事者性**（[13-大義.md](13-大義.md)） |
| 「教科書生のリアルな声」 | チャレンジ完走者の声（W8で取得） |
| 「案件獲得の全てを凝縮」 | 「仕事の紹介」と読まれない表現に（業務提供誘引販売取引 → [02](02-法務リスク.md)） |

### ❌ 採らない（法務・理念の両方に反する）

| 要素 | 理由 |
| --- | --- |
| **「3日後に完全に削除します」＋カウントダウン** | 実際に削除しないなら**虚偽の限定**。消費者庁の処分事例にある型（[09](09-収益モデル.md)）。**再アクセスできてしまう運用なら完全にアウト** |
| **「この動画は3日間で完全に消去されます」** | 同上 |
| **収益実績の列挙**（8,000万円、月平均400万円、20万円収益化） | **不実証広告規制**。根拠資料を出せないと不当表示。「あなたも同じに」の含意があれば誇大広告 |
| 「もう遅い？」で不安を煽ってから反転する型 | [13-大義.md](13-大義.md)「不安で動かさない」に反する |
| **20大特典** | 数の多さで押す訴求。景品規制の論点にもなりうる（商品の一部か景品かで扱いが変わる。要確認） |
| スタイリッシュな人物ビジュアル | **深夜に疲れているシンママには「自分とは違う人」に見える**リスク。後述 |

## 1.6 💡 むしろ「逆を行く」ことが差別化になる

このLPは**情報商材の王道**です。だからこそ、A層（[08](08-ターゲット設計.md)）には別の効き方を考えるべきです。

| 王道LP | あなたが取れる逆張り |
| --- | --- |
| 煽る・急がせる | **急がせない。**「今じゃなくていい」と言える強さ |
| 実績の大きさで信頼を作る | **同じ立場であることで信頼を作る** |
| キレイな人物写真 | **生活感のあるリアルさ**（子供が寝た後の机、とか） |
| 「たったこれだけで」 | **「簡単ではないけど、順番はある」** |
| 高額の一括購入 | 無料チャレンジ → 0→1 → その報酬から次へ（[10](10-価格設計.md)） |

**この層は「うまい話」を一度は見てきています。**
洗練された煽りLPは、むしろ警戒心を呼びます。
[01-構想メモ.md](01-構想メモ.md) の「怪しさを突き抜ける」は、**王道をうまくやることではなく、
王道をやらないこと**で達成できる可能性があります。

### 実装上の注意：文字を画像にしない

参考LPは見出しがほぼ画像です。デザインは自由になりますが——

- **修正のたびに画像を作り直す**（12週間で回すには重い）
- 表示が重い／文字が読めない環境がある
- MyASP・UTAGE のテンプレートで**HTMLテキスト中心に作る方が速い**

→ 画像は**ファーストビューと要所だけ**。本文はテキストで組む。

## 2. 分析するときの観点（このプロジェクト用）

参考LPを見るとき、**真似する前に仕分ける**ための3分類。

| 分類 | 中身 |
| --- | --- |
| ⭕ **そのまま採る** | 構成の順番、情報の出し方、可読性の工夫、フォームの手前の設計 |
| △ **翻訳して採る** | 訴求の型は採るが、言葉は自分の層（A層／B層）に合わせて書き換える |
| ❌ **採らない** | 煽り、誇大表現、虚偽の限定、不安の商法 → [13-大義.md](13-大義.md) に反する |

> **この業界のLPは、うまい構成と危ない表現が混在しています。**
> 「売れているから正しい」ではなく、**構成は学び、表現は自分の基準で書く**。

## 3. 自分のLPに必ず入れるもの（法務要件）

参考LPに入っていなくても、**これは入れます。** 既存ドキュメントからの集約です。

### 🔴 必須表示

| 項目 | 根拠 |
| --- | --- |
| **特定商取引法に基づく表記**（事業者名・住所・連絡先・価格・支払方法・提供時期） | [09](09-収益モデル.md) |

### 🔴 やらない表現

| ❌ | 根拠 |
