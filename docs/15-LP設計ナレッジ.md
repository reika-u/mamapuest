## 1.12 ⚠️ 価格提示前の手法で、採らないもの

| 要素 | 実際の文言 | 理由 |
| --- | --- | --- |
| **価値の見積もらせ** | 「あなたは…**いったいいくらの価値があると思いますか？**」 | 高く見積もらせてから実売価格を出すアンカリング。この後に参考価格を出すなら**二重価格の予兆**（[09](09-収益モデル.md)）。誠実路線と相性が悪い |
| **機会損失の煽り** | 「もしこのノウハウ＆環境がなければ…**かなり遠回りになります**」 | 買わない選択への不安づけ。[13-大義.md](13-大義.md)「不安で動かさない」に反する |
| **効果の断定** | 「バズらさずを得ない**必勝**メソッド」 | 誇大広告。「必勝」は根拠を示せない |
| **過度な期待** | 「たった1本のショート動画で、**人生が変わる**ことを知ってください」 | 同上。特に経済的に追い詰められた層に向けては危険 |
| **収益を章タイトルにする** | 第9章「手取り16万円→**年4200万円**を達成した収益化全公開」／第11章「**年8桁**を達成するための思考フロー」 | 目次そのものが収益訴求になっている。不実証広告規制 |

### 💡 あなたの価格提示はどうするか

このLPは**価値を積み上げてから価格を出す**（バリュースタッキング）構成です。
構成自体は合理的ですが、あなたの場合は前提が違います。

| 参考LP | あなた（[10-価格設計.md](10-価格設計.md)） |
| --- | --- |
| 価値を大きく見せて、価格を相対的に安く感じさせる | **その人が払える額かどうか**で設計する |
| 「いくらの価値があると思いますか？」 | **「これは、あなたの収入の何%ですか？」** |
| 買わないと遠回りする、と不安づけ | **「今じゃなくていい」と言える** |

> 価格の正当化を「価値の大きさ」でやると、どうしても盛る方向に行きます。
> あなたは**「生活を壊さない額かどうか」**で正当化できる。そこが強みです。

## 1.13 🔑 価格セクションの完全分解（最重要）

### 価格提示は7段階で積み上げられている

```
① 他の選択肢の相場を出す      スクール80〜150万／講座30〜50万／独学=数100時間
② 自分の「本来の価格」を出す   25万〜30万円相当での提供を考えました
③ 値下げの理由を語る          手取り16万円だった過去 → 出せない人に諦めてほしくない
④ 通常価格を出す              79,800円
⑤ 期間限定で割引              3日間限定 -10,000円 → 69,800円
⑥ 分割で小さく見せる          24回分割 → 月2,900円
⑦ 日割りでさらに小さく        1日191円 →「コンビニのコーヒー1杯より安い」
```

**80万→30万→8万→2,900円→191円。** 読者の頭の中で金額が10分の1以下に縮んでいきます。
これが価格心理の王道の型です。

### ⭕ 採れるもの

| 学ぶ点 | なぜ効くか |
| --- | --- |
| **感情的ベネフィットを金銭的ベネフィットと並べる**（36番） | 「数字に振り回されない」「発信が楽しくなる」「**投稿が怖くなくなる**」。**お金以外の変化を言語化している**。これは [01-構想メモ.md](01-構想メモ.md) の「お金だけ満たされても本当の豊かさではない」と完全に一致。**強く採るべき** |
| **価格の理由を説明する**（39番） | 「なぜこの価格なのか」を語る。値段に納得の根拠を与えている |
| **創業ストーリーを価格の直前に置く**（40番） | 「なぜ作ったか」→「だからこの価格」の順番。流れが自然 |
| **未来を具体的に想像させる**（36番） | 抽象的な「稼げます」ではなく、生活の変化として描く |

### 🔴 ここが最大の学び：言葉と設計が一致していない

このLPには、**あなたの大義とほぼ同じ言葉**が書かれています。

> 「最初からそこまでの金額を出せずに**諦めてしまう人が多い**のではないかと思いました」
> 「挑戦しようとしている人を**誰一人として置いていきたくありません**」

言葉としては、極めて正しい。**しかし実際の設計がそれを裏切っています。**

| 掲げた言葉 | 実際の設計 |
| --- | --- |
| 「出せない人に諦めてほしくない」 | **24回分割を勧める**（＝分割手数料を払わせる） |
| 「誰一人置いていきたくない」 | **3日で締め切る**（＝間に合わなかった人は置いていく） |
| 「後悔してほしくない」 | **後悔を予告して急がせる**（「気づいたら終わってた」） |

## 1.14 🔴 価格セクションの法務リスク（ここは絶対に真似しない）

## 1.15 💡 あなたの価格提示は、どう組むか

参考LPの7段階に対して、あなたが取れる組み立て。

| 参考LP | あなた |
| --- | --- |
| ① 他社相場でアンカリング | **使わない**（出典を出せない） |
| ② 「本来はもっと高い」 | **使わない**（架空の参考価格） |
| ③ 値下げの理由を語る | ⭕ **使う。ただし本当の理由を**（「生活を壊さない額にしたい」） |
| ④ 通常価格 | ⭕ **一本価格。割引を前提にしない** |
| ⑤ 期間限定割引 | **使わない**（実態がなければ虚偽） |
| ⑥ 分割 | **原則使わない**。使うなら総額と手数料を明示 |
| ⑦ 日割り換算 | △ 使えるが、**小さく見せる目的では使わない** |

### 代わりに使える、あなただけの正当化

> **「これは、あなたの副収入の◯%です」**
> **「生活費からは出さないでください。0→1で得た報酬の中から払える額にしています」**

**価格の正当化を「価値の大きさ」ではなく「あなたの家計に対する比率」でやる。**
これは他社には真似できません。なぜなら、**顧客に先に稼がせていないとできない**からです。

### 価格帯の参考情報

## 1.16 🔑 ストーリーセクション（価格の「後」に置く理由）

### 構造上の要点：価格提示の直後に自己開示を置いている

```
価格 69,800円 ──▶ ⚡読者の抵抗が最大になる瞬間
                    │
                    ▼
            「少しだけ私の過去をお話しさせてください」
                    │
            ┌───────┴────────┐
            ▼                ▼
      取引の話から      売り手と買い手 → 同じ道を歩く人
      物語の話へ        というフレームに変わる
```

**価格は読者が一番身構える瞬間です。** そこに人間の物語を置いて、
「買うか買わないか」から「一歩踏み出すかどうか」へフレームを移している。構成として合理的です。

### ⭕ 採れるもの（あなたが一番強くなれる部分）

#### ① 動機が「極めて私的」である（52番）

> 「両親への恩返し」「**恩返しには必ず期限がある**からこそ、元気なうちに」
> 「今でもこれが私が頑張る1番の理由です」

抽象的な社会貢献ではなく、**具体的で個人的な理由**。だから強い。
[13-大義.md](13-大義.md) の問い①「**なぜ『あなた』がやるのか**」への実例です。

#### ② 実績で信頼を作り、物語で距離を縮める（56番）

> 「自分には本当に何もない／経験もない／何をしてきた人生なんだ、と本気で思っていました」
> → **「だからスタートラインはみんな一緒です」「違うのは1歩踏み出したかどうかだけ」**

前半で実績を積み上げたLPが、最後に「私も何もなかった」で距離を詰める。**二段構え**です。

> 🔑 **あなたには前半（実績の誇示）がありません。だから後半だけで勝負できます。**
> これは弱みではなく、**むしろ一貫性になる**。

#### ③ 失敗した試行を具体的に開示する（55番）

> カフェアカウント／お金に詳しくない中で**お金アカウント**／料理好きじゃないけど**料理アカウント**

うまくいかなかった過程を名指しで出している。**これが「凡人だった」の証拠**になります。
成功談より、失敗の具体性の方が距離を縮めます。

#### ④ 読者を「持たざる者」として肯定する（54番）

> 「強みもなく何者でもないあなたが唯一持っている最強の武器は…」

A層（[08](08-ターゲット設計.md)）にそのまま効く構造。**ただし中身は変える必要があります**（後述）。

## 1.8 ⚠️ お客様の声で、真似してはいけない3点

### ① 「高額講座より」という比較訴求

繰り返し出てきます。

> 「正直そこらへんの講座より"講座"でした笑」（Case01）
> 「高額講座に行く前に、まずこれ！」「そこらへんの高額講座より圧倒的に価値が高い」（Case05）

**他社を貶める比較優良誤認のリスク**があります。
しかも「お客様の声」の形を借りているため、**書かせた側の責任**が問われます。
（アフィリエイターの表現と同じ構造 → [14](14-アフィリエイト設計.md)）

→ **あなたは他社と比較しない。** 自分の提供物だけで語る。

### ② 「99%の発信者は」

出典のない数字です。**不実証広告規制**（[09](09-収益モデル.md)）。
根拠資料を求められて出せなければ不当表示になります。

→ 使うなら**自分で取ったアンケートの実数**（「チャレンジ参加者◯名中◯名が」）。

### ③ 🔴 依存を示す声を載せない ← 最重要

> 「**なるさんは私達の神様です！**」
> 「子供たちと伏見稲荷行ってたんですが、なるさんが**もっともっと幸せになりますように**って祈ってきました！！」（Case03）

売り手としては「効く」声です。しかし——

> **あなたの事業は自立を支援する事業です。**
> 「神様」と呼ばれる関係は、**孤立の反対ではなく依存**であり、
> [13-大義.md](13-大義.md) の「選択肢を増やす」と真逆の方向です。

集める声の性質が、事業の性質を決めます。

| ❌ 集めない声 | ⭕ 集めたい声 |
| --- | --- |
| 「◯◯さんのおかげです」「神様です」 | 「**自分で判断できるようになった**」 |
| 「ついていきます」 | 「**もう一人でやっていけそうです**」 |
| 主宰者への感謝が中心 | **自分の変化**が中心 |

Case01 に、まさに良い例があります。

> 「添削がなくても**自分で改善できる感覚が持てた**のが本当に大きいです」

**これがあなたの集めるべき声です。** ヒアリングでも、この方向に質問を向けてください。

## 1.5 この構成から学べること／学ばないこと

### ⭕ そのまま採れる（構成・型）

| 学ぶ点 | なぜ効くか |
| --- | --- |
| **悩みをチェックリストで言語化 → 「こう思っている人は多いはずです」** | 読者が「自分のことだ」と認識する。A層にそのまま使える |
| **「でも」で反転する** | 不安 → 希望の転換。構造として汎用 |
| **🔑 再現性の証明**（過去の権威を使わずゼロから検証） | **「あなただからできた」への先回り反論**。この構成が一番強い |
| **疑念の先回り**（「そう疑う気持ちはよくわかります」） | 否定せず受け止めてから開く。誠実に見える |
| **受講生の声をCase形式で** | 第三者の証言。アカウント公開で検証可能にしている |
| **背景色でセクションを区切る** | 縦長LPの可読性。実装コストも低い |
| **数字を極端に大きくする** | スマホの流し読み対策 |
| **CTAの繰り返し設置** | 読者が決めた瞬間に押せる |

### 🔑 最大の学び：「再現性の証明」をどう作るか

このLPで一番よくできているのは **13番のセクション**です。
「実績がすごい人の話は、自分には再現できない」——読者の最大の壁に対して、
**過去の権威を使わずゼロから作り直して見せる**ことで反論しています。

**あなたの場合、これに相当するのは自分の実績ではありません。**

> **チャレンジ参加者が0→1を達成した事実**が、あなたの「再現性の証明」です。

→ [12-ローンチ計画.md](12-ローンチ計画.md) の **W8（11/13-19）の事例づくりが決定的**。
ここが埋まるかどうかで、12/16のLPの説得力が決まります。

### △ 翻訳して使う

| 参考LP | あなたの場合 |
| --- | --- |
| 悩み＝「もう遅い」「伸びない」 | A層＝「何から始めればいいか分からない」「情報を判断できない」 |

### ❌ 採らない（法務・理念の両方に反する）

| 要素 | 理由 |
| --- | --- |
| **「3日後に完全に削除します」＋カウントダウン** | 実際に削除しないなら**虚偽の限定**。消費者庁の処分事例にある型（[09](09-収益モデル.md)）。**再アクセスできてしまう運用なら完全にアウト** |
| **「この動画は3日間で完全に消去されます」** | 同上 |
| **収益実績の列挙**（8,000万円、月平均400万円、20万円収益化） | **不実証広告規制**。根拠資料を出せないと不当表示。「あなたも同じに」の含意があれば誇大広告 |
| 「もう遅い？」で不安を煽ってから反転する型 | [13-大義.md](13-大義.md)「不安で動かさない」に反する |
| **20大特典** | 数の多さで押す訴求。景品規制の論点にもなりうる（商品の一部か景品かで扱いが変わる。要確認） |
| スタイリッシュな人物ビジュアル | **深夜に疲れているシンママには「自分とは違う人」に見える**リスク。後述 |

## 1.6 💡 むしろ「逆を行く」ことが差別化になる

このLPは**情報商材の王道**です。だからこそ、A層（[08](08-ターゲット設計.md)）には別の効き方を考えるべきです。

| 王道LP | あなたが取れる逆張り |
| --- | --- |
| 煽る・急がせる | **急がせない。**「今じゃなくていい」と言える強さ |
| 実績の大きさで信頼を作る | **同じ立場であることで信頼を作る** |
| キレイな人物写真 | **生活感のあるリアルさ**（子供が寝た後の机、とか） |
| 「たったこれだけで」 | **「簡単ではないけど、順番はある」** |
| 高額の一括購入 | 無料チャレンジ → 0→1 → その報酬から次へ（[10](10-価格設計.md)） |

**この層は「うまい話」を一度は見てきています。**
洗練された煽りLPは、むしろ警戒心を呼びます。
[01-構想メモ.md](01-構想メモ.md) の「怪しさを突き抜ける」は、**王道をうまくやることではなく、
王道をやらないこと**で達成できる可能性があります。

### 実装上の注意：文字を画像にしない

参考LPは見出しがほぼ画像です。デザインは自由になりますが——

- **修正のたびに画像を作り直す**（12週間で回すには重い）
- 表示が重い／文字が読めない環境がある
- MyASP・UTAGE のテンプレートで**HTMLテキスト中心に作る方が速い**

→ 画像は**ファーストビューと要所だけ**。本文はテキストで組む。

## 2. 分析するときの観点（このプロジェクト用）

参考LPを見るとき、**真似する前に仕分ける**ための3分類。

| 分類 | 中身 |
| --- | --- |
| ⭕ **そのまま採る** | 構成の順番、情報の出し方、可読性の工夫、フォームの手前の設計 |
| △ **翻訳して採る** | 訴求の型は採るが、言葉は自分の層（A層／B層）に合わせて書き換える |
| ❌ **採らない** | 煽り、誇大表現、虚偽の限定、不安の商法 → [13-大義.md](13-大義.md) に反する |

> **この業界のLPは、うまい構成と危ない表現が混在しています。**
> 「売れているから正しい」ではなく、**構成は学び、表現は自分の基準で書く**。

## 3. 自分のLPに必ず入れるもの（法務要件）

参考LPに入っていなくても、**これは入れます。** 既存ドキュメントからの集約です。

### 🔴 必須表示

| 項目 | 根拠 |
| --- | --- |
| **特定商取引法に基づく表記**（事業者名・住所・連絡先・価格・支払方法・提供時期） | [09](09-収益モデル.md) |
| **返品特約**（デジタルコンテンツは返品不可を明示。書かないと受取から8日間は解除可能） | [09](09-収益モデル.md) |
| プライバシーポリシー／個人情報の利用目的 | [11](11-審査制.md) |
| 月額を置く場合、**最終確認画面の6項目**と解約方法の明記 | [10](10-価格設計.md) |

### 🔴 やらない表現

| ❌ | 根拠 |
| --- | --- |
| 「通常◯万円が今だけ◯円」（実績のない二重価格） | 有利誤認 → [09](09-収益モデル.md) |
| 「残り◯席」「今日まで」（実態のない限定） | 虚偽の限定。処分事例あり |
| 「◯%が達成」（根拠資料を出せない数値） | 不実証広告規制 |
| 「誰でも稼げる」「必ず月◯万」 | 誇大広告 |
| 「仕事を紹介します」「案件をお渡しします」 | 業務提供誘引販売取引に該当しうる → [02](02-法務リスク.md) |
| 効果効能の標榜（健康・美容） | 薬機法 → [02](02-法務リスク.md) |
| PR表記のないアフィリエイト・商品紹介 | ステマ規制 → [02](02-法務リスク.md) |

- [ ] 不安を煽って動かしていないか
