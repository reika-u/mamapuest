# コミュニティ文化 — ギバー・感謝を「教える」のではなく「仕組む」

記録日: 2026-09-26 / 出典: 壁打ち

前提: マインド（[01-構想メモ.md](01-構想メモ.md) フェーズ3）を独立講座にせず、
**参加時から敷くコミュニティ全体の行動規範**として設計する方針で確定。

---

## 1. なぜ「講座」ではなく「文化」か

| 講座として教える場合のリスク | 文化として敷く場合 |
| --- | --- |
| [08-ターゲット設計.md](08-ターゲット設計.md) の「A層への逆効果な言葉＝『がんばりましょう』」と同じ危険性がある（余裕がない人に感謝を説くと逆効果） | 講座を待たず、**参加した瞬間から**全員に効く |
| 「感謝すると豊かになる」は引き寄せ系に寄りやすく、[02-法務リスク.md](02-法務リスク.md) が警戒する「ネットワークビジネスあるある」に見られるリスク | 行動レベルのルールとして扱えば、精神論に寄らずに済む |
| 座学だと本人の中に留まる | コミュニティ内の**関係性**として現れるので、孤立させない理念（[01](01-構想メモ.md)）に直接効く |

> **結論**: ギバー・感謝は「教える内容」ではなく「参加のルール」として設計する。

---

## 2. 行動規範（たたき台・3〜4個に絞る）

多いと形骸化するので、少数に絞って徹底する。

| 規範 | 中身 | 効かせ方 |
| --- | --- | --- |
| **恩送り** | 助けてもらったら、次に困っている人を助ける | 0→1達成者・チャレンジ完走者を次期の伴走役に起用する（[08](08-ターゲット設計.md)の完走者活用と同じ発想） |
| **感謝を言葉にする** | 小さなことでも「ありがとう」を可視化する | オプチャで固定フォーマットの投稿を習慣化（例: 「今日ありがとうだったこと」） |
| **新規を迎える** | 新しく入った人に最初に声をかけるのは古参の役目 | 入会直後の体験として設計（下記4章） |
| **テイカー行動の線引き** | 愚痴だけ・マウント・個人的な勧誘は不可 | 既存の「勧誘・マルチ行為の禁止」（[06-シンママbot.md](06-シンママbot.md)）と統合して1つの規範にする |

### ギバーの伝え方（トーンの決定）

精神論（「人に優しくしましょう」）ではなく、**長期的に一番得をするのはギバーだという実利ベース**で伝える。この事業の「稼ぐ」路線（[01](01-構想メモ.md) フェーズ1）と矛盾しない伝え方にする。

- ❌「感謝すれば豊かになります」（根拠のない精神論・引き寄せ系に見える）
- ⭕「与え合うコミュニティの方が、結果的に孤立せず・続く・稼げる人が多い」（行動と結果を結ぶ）

---

## 3. 恩送りの仕組み化（運営負荷を増やさない設計）

**自分の時間が事業の上限**という制約（[07-チーム設計.md](07-チーム設計.md)）がある以上、
「見守りを強化する」ではなく「**参加者同士が見守り合う構造を作る**」方向で設計する。

```
チャレンジ完走者・0→1達成者
        │
        ▼
  次期の「恩送り役」として招く（任意）
        │
   ├─ 新規参加者への声かけ
   ├─ よくある詰まりポイントのシェア（運営が作ったFAQの補完）
   └─ オプチャでの「ありがとう」投稿の起点になる
        │
        ▼
  次の期にまた完走者が生まれる → 循環する
```

- **強制にしない。** 恩送り役は立候補制または運営からの声かけにする（義務化すると「無償労働の強制」に見えるリスク）
- 恩送り役自身にも意味がある設計にする（「教えることが一番の復習になる」「次のステップ＝コンサル・ビジネスコースへの布石」）
- 運営（本人）がまず体現する。LINE配信・bot応答のトーンにこの文化を反映させる（[07](07-チーム設計.md)）

---

## 4. 刷り込みの設計（同意事項だけでは形骸化する）

[11-審査制.md](11-審査制.md) の「ルール同意」に文言を入れるだけでは効かない。**入会直後の体験**で刷り込む。

- 入会後、最初の投稿には運営（または恩送り役）が必ずリアクションする
- オンボーディングメッセージに「ここは与え合う場です」を明文化する
- 感謝投稿のフォーマットを最初から提示する（自由記述だと定着しない）

## 6. 戦略的な効能（差別化・法務）

- [02-法務リスク.md](02-法務リスク.md) が警戒する「紹介報酬で稼ぐ場に見える」問題への対抗策になる。
  **「ここは紹介で稼ぐ場ではなく、与え合う場」**という発信は、連鎖販売取引でないことの
  説明としてもそのまま使える
- 差別化文脈：美容・健康分野の「ネットワークビジネスあるある」を突き抜ける（[01](01-構想メモ.md) 3章）ための
  核になりうる。怪しさの対極にある文化として機能する

---

## 7. 気をつける点

- **タイミング**: 余裕がない0→1達成前の人に「感謝しましょう」と押し付けない。行動規範（恩送り・ありがとう投稿）として淡々と敷き、精神論として説教しない
- **引き寄せ系の言葉を避ける**: 「感謝すると豊かになる」のような根拠のない表現は使わない。行動と結果を具体的に結ぶ
- **恩送りの任意性**: 強制すると無償労働の強制に見える。立候補制を基本にする
- **運営自身が体現する**: 文化は説明するものではなく、最初にやってみせるもの

## 10. 測る指標

| 指標 | 見る理由 |
| --- | --- |
| 恩送り役への就任率（完走者のうち何人が引き受けるか） | 文化が機能しているかの直接指標 |
| ありがとう投稿の数・継続率 | 定着しているか |
| オプチャの荒れ発生率 | 自浄作用が働いているか（[07](07-チーム設計.md)） |
| 新規参加者の初回投稿までの時間 | 迎え入れる文化が機能しているか |
| 恩送り役経験者のその後の継続率・上位商品への移行率 | 事業側のメリットが出ているか |
