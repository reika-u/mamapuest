# ターゲット設計 — 2つの層とアプローチの違い

記録日: 2026-09-18 / 出典: 音声メモ（第4回）

---

## 1. 層が2つある

同じ「副業をしたいシングルマザー」でも、**手前で止まっている理由がまったく違う**。
ここを混ぜると、どちらにも刺さらない発信になる。

### A層：始める前に挫けている

- 何か始める前に挫けている
- **何からしたらいいか分からない**
- **情報を判断できない**（調べるほど分からなくなる）

### B層：やってみたが続かなかった

- 副業に挑戦したけど、うまくいかなかった
- **自分に合うやり方が見つけられない**
- **時間がない**で止まっている

---

> **売り方の結論**: A層は**チャレンジローンチ**、B層は**コンテンツ販売**。
> 収益構造と法務は [09-収益モデル.md](09-収益モデル.md) にまとめた。

## 2. アプローチが変わる

| | **A層**（未着手） | **B層**（挫折経験あり） |
| --- | --- | --- |
| 止まっている理由 | 情報が多すぎて選べない | やり方が合わなかった／時間がない |
| 必要なもの | **決めてあげること**（選択肢を減らす） | **診断**（何が合わないのかの特定） |
| 効く言葉 | 「これだけやればいい」 | 「あなたに合わないやり方だっただけ」 |
| 逆効果な言葉 | 「選択肢はいろいろあります」 | 「がんばりましょう」「まずは基礎から」 |
| 提供の形 | **手順を1本に絞って伴走** | 棚卸し → 自分の条件に合う型を選び直す |
| 最初のゴール | **0→1（初めての報酬を受け取る）** | 前回止まった地点の突破 |
| 警戒すること | 情報を足しすぎて再び固まる | 「また同じか」と思われた瞬間に離れる |

### 決定的な違い

**A層には「教える」が効く。B層には「教える」が効かない。**

B層はすでに情報を持っている。足りないのは情報ではなく、
**自分の条件（時間・体力・性格）に合う型を選び直すこと**。
だからB層には診断から入る。ここを間違えると「知ってる話だった」で終わる。

## 3. まずA層から — 無料で集めて0→1を一緒に作る

### なぜA層が先か

1. **打ち消すべき思い込みがない。** B層は「前に失敗した」という経験を持っているぶん、
   信頼を得るまでの距離が長い
2. **0→1の体験は本人にとって大きい。** 初めて自分で稼いだ体験は忘れられない。
   そこに立ち会った相手への信頼は、あとから買えない
3. **最初の実績者になってくれる。** 事業側に事例がない段階では、ここが唯一の証明になる
4. **リスト取りを兼ねられる。** 無料企画への参加＝LINE登録なので、集客と育成が同時に進む

### 0→1 の定義（ここを間違えない）

> **ゴールは「月5万」ではなく「初めての報酬を受け取る」。**

理由:
- 金額ではなく**「自分でお金を生めた」という体験**が自己効力感を作る
- 到達までが短いほど脱落しない。A層は長い道のりに耐えられない
- 「稼げる」訴求にならず、法的にも安全（[02-法務リスク.md](02-法務リスク.md)）

到達手段の候補（要検討）:
- セルフバック（自己アフィリエイト）… 確実に振込を体験できる。※ASP規約と、
  「これは継続収入ではない」ことを正直に伝えるのが前提
- 低単価でも成約しやすい案件
- 自分のできることを1つ売ってみる

### 企画の骨子（たたき台）

| 項目 | 内容 |
| --- | --- |
| 期間 | **7日間**（長いと脱落する。A層は特に） |
| 1日の負荷 | **15分以内**。子供が寝た後に終わる量 |
| 形式 | **一斉型（コホート）**。同じ日に同じことをやる |
| ゴール | 期間内に「初めての報酬を受け取る」 |
| 伴走 | オープンチャットで進捗共有。個別対応はしない |
| 参加費 | 無料 |

### ⚠️ 設計上の最大のリスク：自分の時間

「一緒に作ってあげる」は時間を食う。**個別対応にすると10人で限界が来る。**

- 一斉型にして、同じ質問には全体に答える
- 毎日の配信は**あらかじめ作っておく**（リアルタイムで書かない）
- よくある詰まりポイントを先回りしてFAQ化する
- **1期を小さく回して型を作る。** 最初から人数を集めない

## 4. リスト取りの導線

```
Instagram（発信）
   │  「何から始めればいいか分からない人へ」
   ▼
LINE公式アカウント登録 ＝ リスト取得
   │
   ├─▶ シンママbot（手当診断・無料情報）  ← 06
   │
   ▼
無料0→1企画（7日間コホート）
   │
   ├─ 完走者 ─▶ 事例・声を得る ─▶ 次期の集客素材に
   │
   └─▶ 次のステップの案内（金融教育 → 講座）
```

- 企画の告知そのものが、**A層の言葉で書かれた集客コンテンツ**になる
- 完走者の声が、次期の信頼材料になる（※実績の表示ルールは [02](02-法務リスク.md) を守る）
- 完走しなかった人も**リストには残る**。ここが無料企画の本質的な価値

---

## 5. B層への展開（コンテンツ販売）

B層には **コンテンツ販売**が合う（[09-収益モデル.md](09-収益モデル.md)）。
すでに課題が言語化できている層なので、伴走なしで売れる＝**自分の時間を使わずに収益化できる**。
むしろ収益を早く立てるなら、**B層の方が先**になる可能性がある。

- 入口は「教える」ではなく**診断**
  - 前回どこで止まったか／1日に使える時間／向き不向き
- 「あなたが悪かったのではなく、やり方が合わなかった」という立て直し
- **時間がない層には、時間設計そのものを提供する**（何をやめるか、を含む）
- A層向けの企画にB層が混ざってもいい。ただし**発信の言葉はA層に寄せる**

## 6. 法務チェック

- [ ] 無料企画でも「稼げる」「必ず◯円」の訴求はしない（景表法）
- [ ] 完走者の実績・体験談を出す場合の表示ルールを守る（[02](02-法務リスク.md)）
- [ ] セルフバックを扱う場合、ASP規約と「継続収入ではない」ことの説明
- [ ] 無料 → 有料の導線があるため、特商法表記・利用規約を整備しておく
- [ ] 参加者の個人情報の取扱い

## 7. 測る指標

| 指標 | 見る理由 |
| --- | --- |
| Instagram → LINE登録の転換率 | 入口の言葉がA層に届いているか |
| 企画への参加率（登録者のうち何人が参加したか） | 企画の見せ方 |
| **完走率** | 設計が重すぎないか。A層は脱落しやすい |
| **0→1到達率** | 企画の成否そのもの |
| 完走者の声の獲得数 | 次期の集客素材 |
| 1期あたりに使った自分の時間 | **持続可能か。ここが事業の上限を決める** |
| その後の有料転換率 | リスト取りとして機能したか |
