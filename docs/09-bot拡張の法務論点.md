# bot拡張の法務論点 — 保険見直しbot / 離婚準備bot

調査日: 2026-09-16 / 前提: [06-シンママbot.md](06-シンママbot.md)、[02-法務リスク.md](02-法務リスク.md)、[05-スポンサー型モデル.md](05-スポンサー型モデル.md)

> ⚠️ 一般的な情報の整理であり、法的助言ではありません。実装前に必ず弁護士に確認してください。

---

## 0. 結論

| bot | 規制 | 難易度 | 判定 |
| --- | --- | --- | --- |
| 手当診断bot（既存構想） | — | 低 | ⭕ **まずこれを完成させる** |
| **離婚準備bot** | 弁護士法72条（非弁行為） | 中 | 🟡 **「整理」に徹すれば作れる。「診断」にすると事故る** |
| **保険bot** | 保険業法（保険募集）／金融サービス仲介業 | **高** | 🟡 **売らないなら作れる。商品名に触れず「制度・考え方・観点」に徹する。募集人資格はむしろ取らない** |

### 全体を貫く設計原則

> **「診断」ではなく「整理」。答えを出さず、持ち物を揃えて、正しい窓口に送る。**

この一行を守れば3つとも成立し、破れば3つとも規制に触れる。
そして**この原則は規制回避のためだけではない** — 深夜にひとりでスマホを見ている人にとって、
断定された答えより「何を持って、どこに行けばいいか」が分かることの方が実際に役に立つ。

### ⚠️ 順番について

**3つ同時に作らないこと。** ドメインが増えるほど、bot1つあたりの品質と法務コストが上がる。
手当診断botを完成させ、[06-シンママbot.md](06-シンママbot.md) の指標（深夜帯の利用率・診断完了率・相談申込数）を見てから次を決める。
拡張の順番は **手当 → 離婚準備 → 保険** が妥当（規制の重さの逆順）。

## 1. 保険bot 🔴

### 前提の確認（2026-09-16 追記）

**方針: 保険商品は売らない。「見極め方」と「保険の考え方」を伝えるだけ。**

この前提なら結論はシンプルになる。

> **募集人資格は取らないほうがいい。売らないなら不要で、取ると発信の自由を失う。**

---

### 1-1. 「募集人資格を持てばbotでも売れるか」への答え

売る場合の話として整理しておく（将来の判断材料として残す）。答えは **「資格だけでは何もできない」**。

| 段階 | 内容 |
| --- | --- |
| ① 資格試験 | **無所属では受験も研修受講もできない。** 保険会社か代理店に所属して初めて受けられる。「資格だけ先に取っておく」は制度上できない |
| ② 登録・届出 | 生保募集人は**内閣総理大臣への登録**が必要。損保は代理店として登録、または使用人として届出 |
| ③ 独立してやるなら | **保険代理店の登録**（財務局）。代理店研修 → 試験 → 保険会社の承認 → 代理店契約 → 登録、という順 |
| ④ 「見直し・比較」をやるなら | 1社専属では比較できない。**乗合代理店**になる必要がある |

### 1-2. 🚨 資格を取ると失うもの — 発信の自由

**これが、売らないなら資格を取るべきでない最大の理由。**

> 大手生保・損保では、**募集人の広告・SNS投稿が「募集文書」として審査対象**になる。
> 募集文書には所属保険会社の商号や募集人の氏名の記載義務があり、投稿ごとの事前審査・承認が要る運用になっている
> （「型承認」で個別審査を簡略化する仕組みはあるが、審査の枠外にはならない）。

[01-構想メモ.md](01-構想メモ.md) では **Instagramでのファン化が事業全体の起点**になっている。
募集人登録をすると、そこに**他社のコンプライアンス審査が入る**。
保険の話だけでなく、発信全体が所属先の管理下に置かれうる。

さらに、募集人になった時点で「中立の情報提供者」を名乗れなくなる。
無料相談窓口の運営者が保険で手数料を得る立場になれば、相談の中立性は構造的に失われる。
これは [05-スポンサー型モデル.md](05-スポンサー型モデル.md) の「相談の場で講座を売らない」原則と同じ理由で成立しない。

> **資格を取ると、できることが増えるのではなく、言えることが減る。**

### 1-3. ✅ 無資格でできる範囲は、思っているより広い

**送客しなければ、そもそも「募集関連行為」にすら当たらない。**
（募集関連行為の典型は、商品の推奨や説明をせずに**見込客の情報を保険会社・募集人に提供する**行為）

一般的な制度解説・考え方の提示は、保険募集にも募集関連行為にも当たらない。

| ⭕ 無登録でできる | ❌ 越えてはいけない線 |
| --- | --- |
| 保険の種類と仕組みの一般解説 | **特定の商品名・保険会社の比較、ランキング、評価** |
| **公的保障の解説**（遺族基礎年金・遺族厚生年金・障害年金・傷病手当金・高額療養費・ひとり親医療費助成） | 「この保険に入るべき」「この特約は不要」の推奨 |
| 「保険に入る前に確認すること」チェックリスト | 個別の契約内容を入力させて評価を返す |
| 「見極めの観点」（何を基準に考えるか） | 保険会社・代理店への送客と紹介料の受領 |
| 「相談窓口に行く前に揃える持ち物・質問リスト」 | 保険会社をスポンサーに付けた状態での保険コンテンツ |

### 1-4. 実用的な判定基準

> **「商品」に触れたら危ない。「制度」「考え方」「観点」に留まれば安全。**

| 例 | 判定 |
| --- | --- |
| 「医療保険を考える前に、高額療養費制度で自己負担の上限がいくらになるか確認する」 | ⭕ 制度の話 |
| 「保障は〈公的保障 → 貯蓄 → 民間保険〉の順に、引き算で考える」 | ⭕ 考え方の話 |
| 「ひとり親が保険を見直すときのチェック項目」 | ⭕ 観点の話 |
| 「終身保険より掛け捨てのほうがいい」 | ⚠️ 商品類型の断定。「それぞれの向き不向き」に言い換える |
| 「◯◯生命の△△プランは割高」 | ❌ 特定商品の評価。監督指針で比較サイトの監視項目 |

### 1-5. 資格を取るなら、募集人ではなくFP技能士

| 資格 | この事業との相性 |
| --- | --- |
| **FP技能士2級** | ⭕ **本命。** 所属先が不要＝**発信の自由を失わない**。保険・年金・税・社会保険・相続を横断的に扱えるので、[08-助成金・補助金.md](08-助成金・補助金.md) の手当、[10-所得制限と経費設計.md](10-所得制限と経費設計.md) の所得設計と地続きになる |
| 社会保険労務士 | △ 公的保障の権威付けとしては最強だが、合格率が低く時間がかかる |
| 保険募集人 | ❌ 売らないなら不要。取ると発信が所属先の審査対象になる |

- **FP技能士は名称独占資格**。無資格で「FP技能士」「ファイナンシャル・プランニング技能士」を名乗るのは不可
- ただし**職種名としての「ファイナンシャルプランナー」自体は誰でも名乗れる**し、一般的な情報提供も違法ではない
- ⚠️ FPを取っても越えられない線は残る: **税務の個別相談は税理士、社会保険の手続き代行は社労士**の独占業務
  （[07-チーム設計.md](07-チーム設計.md) §2 の線引きと同じ）
- 💡 **管理栄養士 × FP** という組み合わせは、「体とお金の両方を整える」という事業の骨子（[01-構想メモ.md](01-構想メモ.md)）にそのまま乗る

### 1-6. 「公的保障を先に知る」が本命である理由

民間保険の比較をやめても、価値は減らない。**むしろ増える。**

公的保障を知らないまま保険に入りすぎている人は多い。
「あなたには遺族基礎年金がこれくらいある。だから必要な保障はここから引き算」を伝えるだけで、
毎月数千円〜1万円の固定費が浮くことがある。

**これは「稼ぐ」より即効性のあるキャッシュ改善**で、フェーズ1（稼ぐ）の前に置ける価値であり、
フェーズ2（金融教育）と地続き。しかも無登録・無資格でできる。

- [ ] 公的保障の解説は**社会保険労務士・FPの監修**を入れる（税理士・弁護士とは別の専門家）
- [ ] 金額の断定はしない（「目安」「確認先は年金事務所・市区町村窓口」）
- [ ] 特定商品への言及を禁止事項として明文化し、投稿・bot応答のチェックに入れる

### 1-7. 参考: 規制は今まさに締まる方向に動いている（売る選択をする場合の判断材料）

- **2024年11月1日施行**: 金融サービス提供法の改正で「**顧客等の最善の利益を勘案した誠実公正義務**」が新設。従来「顧客本位の業務運営に関する原則」だったものが**法律上の義務**に格上げ
- **2026年 保険業法改正**: 比較推奨販売の「**ハ方式」が廃止され「ロ方式」に一本化**（金融庁のパブコメ結果は2026年8月28日発表、経過措置は1年6か月）
  - **イ方式** = 複数商品を客観的に比較説明する
  - **ロ方式** = 顧客の意向に沿って選別し、特定の契約を提案する
  - **ハ方式** = 意向に沿った選別をせず、自社独自の基準で特定の契約を提案する ← **廃止**
  - 背景: 手数料の高い商品を優先的に販売するなど、代理店都合の推奨の抜け穴になっていたという問題意識（2024年12月 金融庁WG報告書）
  - 今後は**顧客ごとの意向と比較根拠を明確にし、推奨理由を説明することが必須**
- 非対面募集（電話・郵便・インターネット）でも、**対面と同等の水準**の情報提供・説明ができる体制が必要。意向把握も創意工夫した方法で正確に行う必要がある
  - → **botが自動で推奨を出す形で、この水準を満たすのは極めて困難。** 結局は人が個別に意向把握して説明することになる
  - → それは「botで保険を売る」ではなく「**botで見込み客を集めて対面で売る**」であり、実質は保険代理店の集客チャネル。シンママ支援事業ではなくなる

**結論: 売る側に回る判断は、今しなくていい。規制改正の真っ最中で、本体事業も未ローンチ。**
やるとしても、本体事業が立ってから、**別事業・別名義として完全に分離する**形でしか成立しない。

## 2. 離婚準備bot 🟡

### 規制の構造

**弁護士法72条（非弁行為）** — [05-スポンサー型モデル.md](05-スポンサー型モデル.md) §5 で整理済みの論点がそのまま当てはまる。

さらに **AI特有の論点**が動いている領域であることに注意。

- 法務省は2023年8月に「AI等を用いた契約書等関連業務支援サービスの提供と弁護士法第72条との関係について」のガイドラインを公表
- **2026年1月9日**、規制改革推進会議のワーキンググループに法務省が「弁護士法72条とAIリーガルテックサービス」の資料を提出 → **議論が現在進行形で動いている**

#### 判断枠組み（法務省ガイドライン）

① **報酬を得る目的** / ② **事件性**（訴訟事件その他一般の法律事件） / ③ **法律事務該当性**
に加え、④弁護士が自ら精査・修正して使用する場合の違法性阻却。

原則として整理されているのは：
> **「AIが補助し、最終判断は人（専門家・当事者）が行う」運用であれば、原則として72条に違反しない。**

### 🚨 ただし「契約書レビューは大丈夫だから離婚も大丈夫」ではない

AI契約書レビューが許容されやすいと議論されている根拠のひとつは、
**企業法務の契約書関連業務の多くは紛争性がない**（＝②の事件性を欠く）という点。

**離婚は典型的に紛争性がある。** 前提がまるで違うので、契約書レビューの議論をそのまま持ち込むのは危険。

### ✅ 安全側の設計

| ⭕ できること | ❌ やってはいけないこと |
| --- | --- |
| 「離婚までに決めること」チェックリスト（親権・養育費・面会交流・財産分与・年金分割） | 「あなたのケースなら養育費は◯万円請求できます」 |
| 公正証書とは何か・どこで作るか・費用の目安の一般解説 | 「その条件は不利です」「その離婚届は出さないで」 |
| 準備しておく書類のリスト（源泉徴収票・通帳・不動産・保険） | **入力された事情に応じて個別の法的評価を返すAI応答** |
| 相談先の一覧（法テラス・弁護士会・行政書士・配偶者暴力相談支援センター） | 代理人としての交渉、相手方への連絡 |
| **弁護士の初回相談を最大効率にするための持ち物・質問リスト生成** | 無料相談を入口に有料講座を売り込むこと |

> 💡 **最大の価値は「弁護士に行く前の準備」に徹すること。**
> 初回相談30分で何も決まらずに終わる人は多い。
> 持ち物と質問が揃った状態で弁護士の前に座れることには、実際に金額に換算できる価値がある。
> そして**この価値は、法的助言に踏み込まないからこそ提供できる**。

### 実装上の線引き

- **Phase 1はシナリオ型（選択式）で作る。** 自由入力 → AI応答は、個別助言に踏み込む事故が起きやすい
  → [06-シンママbot.md](06-シンママbot.md) の「Phase 1 はシナリオ型で作る（AIは入れない）」方針と一致
- AI応答を入れる段になったら、**出力側に禁止事項のガードを必ず入れる**
  （金額の断定、有利／不利の評価、「〜すべき」の指示を出させない）
- 🚨 **DV・虐待・自傷のキーワード検知 → 公的窓口の即提示**は、離婚準備botでは手当診断bot以上に必須
  （離婚を考えている人の中に、最も緊急性の高い層がいる）

### 前提条件

- [ ] 🔴 **提携弁護士・行政書士を先に確保してから公開する**（04のタスクリストに記載済み）
- [ ] 🔴 規約・bot冒頭に「法律相談には該当しない」「できること／できないこと」を明記
- [ ] 🟡 機微情報（DV・離婚・子ども）のログ保存方針を決める。**居所が推定できる情報は残さない**

## 3. 共通のチェックリスト（新しいbotを足す前に必ず通す）

- [ ] この応答は「整理」か「診断」か。**断定していないか**
- [ ] その分野に**登録・資格が必要な行為**が混ざっていないか（保険業法・弁護士法・税理士法・薬機法）
- [ ] 監修者は誰か（保険＝社労士/FP、離婚＝弁護士、税＝税理士、健康＝薬機法の専門家）
- [ ] 収益の受け取り方が規制に触れないか（**紹介料・送客手数料は要注意**）
- [ ] スポンサーとの**利益相反**が発生しないか
- [ ] 緊急ケース（DV・自傷・虐待）の検知と窓口提示が入っているか
- [ ] 「最新・個別の話は公式窓口で確認」の注記があるか
- [ ] 無料相談を入口に有料講座を売り込む構造になっていないか
