# スクール名とカルチャー（たたき台）

記録日: 2026-09-27 / 出典: 対話メモ

---

> ## 🎉 スクール名決定: **Amber**
> 「柔らかい樹液が、時間をかけて固まり、価値のある宝石になる」＝**柔らかさ→強さ→豊かさ**を一語で表す。
> 経緯は下記G節。ロゴ・後ろに付ける語（School / Circle / Academy等）・商標確認は次のステップ（4節）。

> **前提**: [13-大義.md](13-大義.md) の大義・やらないことリストから逆算する。
> 名前もカルチャーも「大義を体現しているか」で選ぶ。ゼロから発想しない。

## 1. 名前を決める前に：軸の確認

[13-大義.md](13-大義.md) の2本柱をもう一度置く。

```
① 孤立させない  ×  ② 選択肢を増やす
```

名前の方向性は、どちらの柱を強く出すかで変わる。

| 方向 | 出てくる語感 | 向いている場面 |
| --- | --- | --- |
| ①孤立させない寄り | 集う・輪・仲間・味方・灯 | Instagram・bot・当事者向け |
| ②選択肢を増やす寄り | 選ぶ・一歩・種・道・扉 | スポンサー・審査制の説明 |
| 両方の中間 | 陽だまり・実る・芽・凪 | スクール名（一番使う場面が広い） |

**まず決めたいのはここ**: スクール名は①②どちらに寄せるか、それとも中間か。

## 2. 名前の候補（方向別・たたき台）

すべて仮。語感だけ出して、あとで削る・混ぜる前提。

### A. 「孤立させない」寄り

- ハレノヒ会 / ハレノヒスクール
- ミカタ（味方）
- ワの学校（輪）
- ヨリドコロ

### B. 「選択肢を増やす」寄り

- イチカラ（一から / 1→10ではなく1から選べる）
- ミライノタネ
- テマエ（自分の手前＝自分で選ぶ、の意）

### C. 中間（母親・自分の状態の変化を示す）

- ヒダマリ（陽だまり）
- ソダテル / ソダチバ
- ミノル（実る）
- カゼトツキ 系（雰囲気重視、意味は薄め）

> ⚠️ 商標・既存サービス名との重複は候補を3つ程度に絞った段階で必ず確認する。
> シンママ・ひとり親向けサービスは既に多いので、検索して衝突を避ける。

### D. 追加キーワードから（2026-09-27 追記）

出てきたキーワード: **女性の自立・軸・美しい・強い・芯 / 感謝・尊敬・心・信じる・許す・器・包む・大事・愛・豊かさ**

> 「豊かさ」は [01-構想メモ.md](01-構想メモ.md) の原点にある言葉そのもの
> （「お金だけ満たされても、それは本当の豊かさとは言えない」）。
> お金の話ではなく、**経済的自立の先にある精神的な満ち足りた状態**を指している。

前半（軸・美しい・強い・芯）は**内側の強さ**、後半（感謝・尊敬・心・信じる・許す・器・包む・大事・愛）は**人との関わり方**を表している。
これはA/B/C（孤立させない／選択肢を増やす）と矛盾せず、その**内面の土台**にあたる。「芯」と「関わり方の器」の両方を持つ、という軸で名前を作ると次のような方向になる。

| 候補 | 由来 | 語感 |
| --- | --- | --- |
| 芯（SHIN） | 軸・強い・芯 | 一文字で強さと静かな美しさ。ロゴ映えする |
| 凛（RIN） | 美しい・強い | 「凛とした女性」という言い方があるほど、強さと美しさを両立する語 |
| 器（UTSUWA） | 器・包む・大事 | スキルより「人としての器を育てる」という精神的自立の比喩に合う |
| 心根（KOKONE） | 心・大事・信じる | 「根」＝土台。表面のテクニックでなく心の根を扱う場、というニュアンス |
| 信愛（SHINAI） | 信じる・愛 | 実在の熟語（信頼と愛情）。関係性の文化をそのまま名前にできる |
| 芯華（SHINKA） | 芯＋美しい（花） | 強さ（芯）と美しさ（華）を一語に。造語だが読みやすい |

**すすめ方**: この6つから「音の響き」と「ロゴにしたときの見え方」で2〜3個に絞り、
商標検索にかける。意味の強さだけでなく、**発信のたびに何百回も打つ／言う名前**なので、
言いやすさ・打ちやすさも同じ重みで見る。

### E. 英語名にする（2026-09-27 追記：方向確定）

**スクール名は英語にする方針。** D群（芯・凛・器…）は日本語の意味の参考として残し、
名前自体は英語ワードから選ぶ。選ぶ基準は3つ:

1. 今回のキーワード（軸・美しい・強い・芯 ／ 感謝・信じる・許す・器・包む・愛 ／ 孤立させない・選択肢を増やす）に意味が合うこと
2. **カタカナにしても読みやすい・発音しやすいこと**（日本語話者が主対象）
3. 短い（3音節以内が目安）・既存の有名ブランドと被らないこと

| 候補 | 英語の意味 | どのキーワードに合うか |
| --- | --- | --- |
| **Anchor**（アンカー） | 錨・支え | 軸・芯。孤立せず「繋がって支え合う」意味も持てる |
| **Grace**（グレース） | 優雅さ、しかし芯のある美しさ（"grace under pressure"） | 美しい・強い・芯。人名的で親しみやすい |
| **Haven**（ヘイヴン） | 避難場所、拠り所 | 包む・許す・孤立させない |
| **Compass**（コンパス） | 方位磁針 | 選択肢を増やす（自分で方向を選べる）・軸 |
| **Bloom**（ブルーム） | 花開く | 美しい・精神的自立（内側から咲く比喩）。日本語話者にも馴染みやすい単語 |
| **Root**（ルート） | 根・土台 | 芯・軸。ただし「ルート」は「route（道）」と紛れやすいのが弱点 |
| **Iris**（アイリス） | 花名。花言葉は信頼・希望・知恵 | 信じる・美しい・強い。ギリシャ神話では虹の女神＝繋ぐ役割（孤立させない）も持つ |

**現時点のおすすめ**: **Anchor** と **Grace** の2つ。
Anchorは①孤立させない（支え合う）と③芯の強さの両方に効き、Graceは③（美しさ×強さ）に一番ダイレクトに合う。
どちらも発音が簡単で、"Anchor School" "Grace School" のように後ろに単語をつけやすい。

> ⚠️ 英語名でも商標・既存サービス名の確認は必須。特に "Grace" は使用例が多いので要注意。

### F. 「見た目は柔らかいけど、芯は強い」に絞る（2026-09-27 追記）

方向がさらに明確になった。**音（聞こえ方）は柔らかく、意味（裏側）は強い**という2層構造の言葉が最も合う。
Anchorは意味は合うが**音が硬い**ため、この基準では後退する。代わりに上位に上がるのが以下。

| 候補 | 音の印象 | 裏にある強さ |
| --- | --- | --- |
| **Willow**（ウィロー） | 柔らかい・流れるような響き | 柳は風にしなっても折れない木。**「しなやかだが折れない」を最も直接表す語** |
| **Iris**（アイリス） | 花の名前で柔らかい | 花言葉が信頼・希望・知恵。ギリシャ神話では虹の女神＝繋ぐ存在 |
| **Bloom**（ブルーム） | 柔らかく前向き | 開花＝内側からの力で咲く。外からの強制ではない自立の比喩 |
| **Grace**（グレース） | 柔らかく上品 | "grace under pressure"＝重圧下でも崩れない美しさ |
| **Sage**（セイジ） | 静かで柔らかい | ハーブ＋「賢者」の意。落ち着いた強さ・信じる力 |

**一番のおすすめは Willow。**
「見た目は柔らかいけど、内面や芯、軸は強い」という今回の言葉を、
比喩なしで一語にできるのはこれだけ（柳＝しなる＝折れない）。
次点は Iris（信じる・美しい・強いの3語をまとめて持つ）。

Anchor / Compass / Haven / Root は「意味の強さ」寄りの語なので、
音の柔らかさを優先するなら候補から外し、Willow・Iris・Bloom・Grace・Sage の5つに絞るのが良さそう。

### G. 「豊かさ」を加える（2026-09-27 追記）

「豊かさ」が入ると、単なる「強さ」だけでなく**満ち足りている・実っている**という質感が加わる。
Willow・Iris系（しなやかさ・強さ）に加えて、下記も候補に上げられる。

| 候補 | 音の印象 | 豊かさとの結びつき |
| --- | --- | --- |
| **Amber**（アンバー） | 柔らかく温かい響き | 琥珀＝樹液（柔らかいもの）が長い時間をかけて固まった宝石。**柔らかさ→強さ→価値（豊かさ）**を1語で表せる |
| **Marigold**（マリーゴールド） | 花の名前で柔らかい | 花言葉が「豊かさ・変わらぬ愛」。色も金＝豊かさの象徴 |
| **Bloom**（ブルーム・既出） | 柔らかく前向き | 開花＝内側の豊かさが外に表れる状態そのもの |

この中では **Bloom** が既存候補と地続きで一番使いやすく、**Amber** は「豊かさ」を最も強く持つ新候補。
Willow（しなやかな強さ）と Amber（豊かさに育つ強さ）はどちらも「柔らかいものが強さ・価値に変わる」という同じ構造を持つため、
最終的にはこの2語を軸に比較するのがよさそう。

### ✅ 決定: Amber（2026-09-27）

Willowとの比較の結果、**Amber**に決定。
「豊かさ」まで一語で背負える点、柔らかい響きと固く価値のある宝石という裏の強さのギャップが、
①孤立させない・②選択肢を増やす・③芯のある美しさ・豊かさ、すべてに橋を掛けられる。

### Amberが正しい理由（教育観そのものと一致）

名前を決めたあとに出てきた、もっと大事な話。

> **女性は元々、美しいものを持っている。**
> スクールがやるのは、それを**新しく作る**ことではなく、**磨いて輝かせる**こと。
> 新しく身につける考え方や教養があったとしても、それは
> **自分の元々の特性を活かすための道具**であって、それ自体が目的ではない。

これは琥珀（Amber）の成り立ちと完全に一致する。
琥珀は人工的に作られる宝石ではなく、**木がもともと持っていた樹脂**が、時間をかけて磨かれ、
固まり、輝きを持つ石になったもの。**足すのではなく、磨く。**

これは名前の後付けの理由ではなく、**このスクールの指導方針の核**として置く。

| これはやる | これはやらない |
| --- | --- |
| 元々持っている強さ・美しさを引き出す | ゼロから「稼げる人格」を作らせる |
| スキルや教養は「元々の自分」を活かす道具として教える | スキル習得そのものを目的化する |
| 「あなたらしさ」を軸に個別に伸ばす | 全員に同じテンプレートを当てはめる |
| 「元々あったものが見えるようになった」を成功とする | 「別人になれた」を成功の物語にする |

> カルチャーの一行に足すなら:
> **「新しく生まれ変わるのではなく、元々の自分が輝きだす」**

## 3. カルチャー：何を大事にするか（大義から逆算）

[13-大義.md](13-大義.md)「やらないことリスト」の裏返しとして、カルチャーの土台はすでにある。

| これはやる | これはやらない |
| --- | --- |
| 稼げていない人にも同じ扱いをする | 成果で人を序列化して発言力に差をつける |
| 「今日はできなかった」を許す | 毎日投稿・毎日発信を強制する |
| 落選者にも次の道を示す | 「不合格」で関係を切る |
| 事実に基づいて話す | 「誰でも稼げる」を匂わせる |
| 個別の事情（手当・生活）を尊重する | 一律のノルマを押しつける |

### カルチャーの言語化（案）

- 「頑張れる日も、頑張れない日も、いていい場所」
- 「稼ぐ前に、比べない」
- 「一人じゃないけど、あなたのペースで」

これは①②の柱をそのまま**日常の運営ルール**に翻訳したもの。
発信のトーン・LINE botの返信文・審査基準（[11-審査制.md](11-審査制.md)）すべてに効いてくる。

### 関わり方の価値観（2026-09-27 追記）

キーワード（感謝・尊敬・心・信じる・許す・器・包む・大事・愛）は、
「何を教えるか」ではなく「**メンバー同士・運営とメンバーがどう関わるか**」の言葉。
上の①②の柱を**内面から支える土台**として、別枠で置く。

| キーワード | カルチャーに翻訳すると |
| --- | --- |
| 信じる | 結果が出ていない人も、まず信じて見守る。監視ではなく信頼で運営する |
| 許す | 挫折・失敗・離脱を「裏切り」として扱わない。戻ってきていい場所にする |
| 感謝・尊敬 | 講師とメンバーが上下関係ではなく、互いの状況に敬意を払う関係でいる |
| 器・包む | 正しさで指導するより、まず受け止める。できなさも含めて受け止める広さ |
| 大事・愛 | 「稼がせるための対象」ではなく、一人ひとりを大事にする対象として扱う |

これらは③**「芯のある美しさ」**（女性の自立・軸・美しい・強い・芯）とセットで、
「**強い芯を持ちながら、他者を信じて包める人**」という、このスクールが育てたい人物像そのものになる。

> 一行にまとめると:
> **「芯は強く、心は柔らかく」**（叩き台。しっくりくる言い回しに変えてよい）
