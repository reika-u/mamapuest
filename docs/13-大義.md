# 大義 — なぜ、この事業がこの世にあるべきか

記録日: 2026-09-25 / 出典: 音声メモ（第9回）「ここの大義を考える」

---

## 1. なぜ今、これを考えるのか

タイミングとして正しいと思います。**ローンチ日が決まった今、大義がないと詰まる場面が6つあります。**

| 場面 | 大義が必要な理由 |
| --- | --- |
| **発信（Instagram）** | A層に振り切った言葉の、芯になるもの |
| **コンサルを売る** | 「なぜ**あなたから**買うのか」への答え |
| **スポンサー・助成金**（[05](05-スポンサー型モデル.md)） | 大義がないと通らない。審査で最初に見られる |
| **弁護士・税理士を口説く**（[03](03-専門家の探し方.md)） | 条件ではなく大義で人は動く |
| **自分が折れそうなとき** | ひとりで回す事業の、戻る場所 |
| **判断に迷ったとき** | ← **これが一番実務的** |

最後のものが重要です。
これまで何度も「**理念と衝突する**」という理由で設計を変えてきました。
連鎖販売取引を避けたのも、高額バックエンドを置かないのも、落選者の扱いを丁寧にしたのも、全部そうです。

> **その「理念」の正体が、大義です。**
> 言語化されていないまま、すでに全ての判断を動かしている。

## 2. すでに答えは出ている（決定から逆算する）

大義はゼロから考えるものではありません。
**これまでの決定の中に、もう表れています。** ここまでの12のドキュメントから抽出すると——

### あなたが「やらない」と決めたこと

| やらないと決めたこと | そこに表れている価値観 |
| --- | --- |
| 講座紹介を報酬源にしない（連鎖販売取引） | **人間関係を壊してまで稼がせない** |
| シンママをさらに孤立させる形にしない | **孤立させない** |
| 高額バックエンドを置かない | **払えない人に払わせない** |
| 借金をして参加費を払わせない | 同上 |
| 手当・生活費を切り崩させない | **子供の生活を削らせない** |
| 稼げていない人に上位商品を案内しない | **成果が出てから、次を出す** |

**これだけ一貫している事業は珍しいです。** 大義はもう存在していて、
あとは**肯定形で言葉にするだけ**です。

## 3. 大義の候補（たたき台）

あなた自身の言葉から組み立てました。**選ぶ・混ぜる・書き換える**ために使ってください。

### 案A — 選択肢に寄せる

> **シングルマザーが、「これしかない」から「これを選ぶ」に変わる社会をつくる。**

- 強み: お金を目的にしていないことが明確。精神的自立まで射程に入る
- 使える場面: 発信、スポンサー提案

### 案B — 孤立に寄せる

> **ひとりで抱えなくていい。稼ぐことも、育てることも、生きることも。**

- 強み: 深夜にひとりでスマホを見ている人（[06](06-シンママbot.md)）に直接届く
- 使える場面: Instagram、bot、コミュニティ

### 案C — 連鎖に寄せる

> **自立した母親が増えれば、その子どもが見る未来が変わる。**

- 強み: 受益者が「母親」だけでなく「子ども」に広がる。**助成金・企業スポンサーに最も効く**
- 使える場面: スポンサー提案、助成金申請、専門家への説明

### 組み合わせ例

> **ひとりで抱えなくていい環境をつくり、
> シングルマザーが「これしかない」から「これを選ぶ」に変わる。
> その先で、子どもが見る未来が変わる。**

## 4. 言語化を詰めるための問い（少数精鋭）

たくさん問いを立てても消耗するだけなので、**効くものだけ**に絞りました。

1. **なぜ「あなた」がやるのか。**
   管理栄養士であること、シングルマザーであること、過去の自分——
   ここに嘘のない一行があると、大義は一気に強くなります。
   （※どこまで公にするかは別問題。決めるのは自分です）

2. **10年後、この事業があったから変わったものは何か。**
   「◯人が稼げるようになった」ではなく、その先。

3. **絶対に譲らない一線は何か。**
   → すでに上の表に9個あります。**この中で最後まで残るのはどれか。**

4. **お金がすべて解決したとして、それでも足りないものは何か。**
   → あなたはすでに「本当の豊かさとは言えない」と答えています。その中身は何か。

## 5. 大義は「未決の判断」を解く道具になる

抽象論で終わらせないために。**大義が決まると、残っている判断が自動的に決まります。**

| 未決事項 | 大義で解ける |
| --- | --- |
| **生活保護の人を除外するか**（[11](11-審査制.md)） | 「誰も置いていかない」が大義なら、除外はしない。別の形で守る |
| コンサルの価格をいくらにするか（[12](12-ローンチ計画.md)） | 「子供の生活を削らせない」が基準になる |
| 12/16 に何を出すか | 「嘘をつかない」なら、間に合わないものは出さない |
| B層とA層のどちらを優先するか | 大義が「孤立」なら A層、「自立」なら B層 |

> **大義を決める＝これから何百回も発生する判断を、先にまとめて決めること。**

## 6. ⚠️ 注意：大義を「飾り」にしない

シンママ支援は、**やさしい言葉が溢れている領域**です。
美しい理念を掲げている事業は山ほどあり、言葉だけでは差別化になりません。

### 大義を本物にするもの

**掲げた言葉ではなく、実際に何を断ったか。**

- 「孤立させない」と言いながら紹介報酬を付ける事業はいくらでもある
- あなたは**それを断った**（[02](02-法務リスク.md)）
- 「寄り添う」と言いながら高額商品を売る事業もいくらでもある
- あなたは**それも断った**（[10](10-価格設計.md)）

> **「やらないことリスト」を、大義とセットで公開することを勧めます。**
> 言葉は誰でも真似できますが、断った実績は真似できません。
> これはそのまま、怪しさを突き抜けるための差別化（[01](01-構想メモ.md)）にもなります。
