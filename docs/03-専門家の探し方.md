# 弁護士・税理士の探し方（調査結果）

依頼事項「一緒にビジネスをやっていける弁護士・税理士の探し方を調べてほしい」への回答。

---

## 0. まず決めること：どの関係で組むか

探す前に、**どの関係性を求めているか**を決めると相手選びがぶれません。

| 形態 | 内容 | 向き不向き |
| --- | --- | --- |
| **スポット相談** | 規約レビュー・報酬設計の適法性チェックを都度依頼 | 立ち上げ初期はまずこれで十分 |
| **顧問契約** | 月額で継続相談。事業を理解した状態で即答が得られる | 受講生が増え、法務論点が日常化してから |
| **監修・登壇パートナー** | 講座に「弁護士監修」「税理士講師」として関わってもらう | 金融教育フェーズの本命。信頼性の担保にも直結 |
| **共同事業者** | 事業に踏み込んで一緒にやる | 相性と実績が確認できてから。いきなりは危険 |

> 推奨ルート: **スポット相談 → 監修・登壇 → 顧問**。
> 一度仕事を発注して仕事ぶりを見てから関係を深めるのが安全。

## 1. 弁護士の探し方

### A. 弁護士会の公的ルート（中立・安心）

| ルート | 内容 |
| --- | --- |
| **ひまわりほっとダイヤル**（日弁連） | 中小企業・個人事業主向けの弁護士予約サービス。JETRO・東京商工会議所・日本政策金融公庫等と連携 |
| **ひまわりサーチ**（日弁連 弁護士情報提供サービス） | 取扱業務が69項目に分類され、分野から検索できる |
| **各地の弁護士会の顧問弁護士紹介制度** | 例: 埼玉弁護士会は**弁護士経験5年以上の候補者を3名**紹介。第二東京弁護士会にも同様の制度あり |

### B. 分野特化で探す（この事業では重要）

一般的な「企業法務」ではなく、**次の分野を扱っている弁護士**を指名で探すのが有効です。

- 特定商取引法（連鎖販売取引・通信販売）
- 景品表示法・ステマ規制・広告法務
- 薬機法（健康食品・化粧品の表示）
- IT法務・オンラインサービス法務

> 探し方: 上記キーワードで記事を書いている弁護士・法律事務所を検索し、著書や解説記事の質で判断する。
> 実際、02-法務リスク.md の参考リンク先は、まさにこの領域を専門にしている事務所です。**記事から直接問い合わせるのは最も精度の高い探し方**。

### C. 人づて・コミュニティ

- 経営者仲間・先輩起業家からの紹介
- 商工会議所の相談会
- インターネット検索 + 初回相談

### D. 女性・ひとり親支援に理解のある弁護士

事業の性質上、受講生から離婚・養育費・DV の相談が持ち込まれる可能性があります。
自分で対応すると **弁護士法72条（非弁行為）** の問題になるため、**繋ぎ先としての弁護士**も別途確保しておくと安全です。

- 法テラス（受講生への案内先として）
- ひとり親支援NPOと連携している弁護士

## 2. 税理士の探し方

### A. 公的・無料ルート

- **税理士会の検索サイト**（各地の税理士会HPに設置）
- **商工会議所の無料税務相談**（定期開催）
- 税務署の相談窓口（一般的な申告相談）

### B. 税理士紹介サービス（無料・マッチング型）

利用者は基本無料。面談設定・価格交渉・お断りまで専門スタッフが代行してくれるのが利点。

| サービス | 特徴 |
| --- | --- |
| 税理士ドットコム | 総合力 |
| 弥生の税理士紹介ナビ | 会計ソフトとの親和性 |
| ビスカス | 老舗・実績重視 |
| 税理士紹介エージェント | 人柄・相性重視 |

> 複数サービスを併用して候補を集め、**必ず2〜3名と面談して比較**する。

### C. この事業で税理士に求める要件

- [ ] **個人事業主・小規模事業の実績**（受講生の開業届・確定申告をサポートできるか）
- [ ] **アフィリエイト／ネット収入の申告に慣れているか**
- [ ] **ひとり親の税制（寡婦控除・ひとり親控除）、児童扶養手当と所得の関係を説明できるか** ← 金融教育コンテンツの監修に直結
- [ ] 将来の法人化の相談に乗れるか
- [ ] チャット等でレスが早いか

---

## 3. 面談で必ず聞くこと（共通チェックリスト）

### 弁護士向け

1. アフィリエイトを軸にしたオンライン講座事業の経験はあるか
2. 当方の報酬設計は**連鎖販売取引に該当しないか**（設計書を持参して質問）
3. 特商法表記で**自宅住所を出さない方法**（バーチャルオフィス等）は使えるか
4. 受講生の成功事例・収入実績を広告に載せる際の表現ライン
5. 薬機法まで見られるか（見られないなら、どこを紹介してもらえるか）
6. 顧問料の体系と、対応範囲・スピード
7. 講座内での監修・登壇は可能か（可能なら条件）

### 税理士向け

1. 個人事業主の顧問実績、特にネット収入系
2. ひとり親控除・児童扶養手当の所得基準まで含めた説明ができるか
3. 受講生を紹介した場合の対応可否と料金（受講生向けの入口メニューを作れるか）
4. 使用会計ソフトと、こちらの記帳負担
5. 顧問料の体系（月次/年次、決算料の有無）

### 共通で見るポイント

- **事業の理念に共感してくれるか**（シンママ支援という文脈を理解できるか）
- 専門用語を噛み砕いて説明できるか ← 受講生に向けても話してもらうなら必須
- レスポンスの速さ
- こちらのやりたいことに対し「ダメ」で終わらず**代替案を出せるか**

---

## 4. 進め方の推奨シナリオ

1. **報酬設計・サービス設計を1枚にまとめる**（何を売り、誰が誰から何で報酬を得るか）
2. ひまわりほっとダイヤル or 分野特化の弁護士にスポット相談 → **連鎖販売取引の該当性を潰す**
3. 並行して税理士紹介サービスで2〜3名と面談 → 1名決定
4. 規約・特商法表記・プライバシーポリシーを弁護士レビュー
5. 走り出してから、相性の良かった相手と顧問／監修契約へ
