# 自社講座のアフィリエイト設計とASP比較

記録日: 2026-09-26 / 出典: 音声メモ（第10回）

> 質問: 講座の紹介をアフィリエイトにするには、どういう仕組みを使えるか。

---

## 1. まず結論：最初の懸念は、設計で回避できる

一番最初のメモ（[01-構想メモ.md](01-構想メモ.md)）で、こう言っていました。

> 「講座の紹介にすると、法律上、連鎖販売取引になってしまう」

**調べた結果、これは設計次第で回避できます。**

### 連鎖販売取引の成立には、2つ**とも**必要

| 要素 | 中身 |
| --- | --- |
| **特定利益** | 紹介・あっせんの対価（紹介料・マージン・ボーナス） |
| **特定負担** | 入会金・商品購入費・取引料などの負担 |

**どちらか一方が欠ければ成立しません。** つまり「特定負担」をなくせばいい。

### 🔑 回避のための3つの設計ルール

| # | ルール | なぜ |
| --- | --- | --- |
| **1** | **誰でもアフィリエイターになれる（購入を条件にしない）** | 購入を条件にすると、講座代金が「特定負担」になる |
| **2** | **1段階のみ。多段階にしない** | 紹介者の紹介者にも報酬が流れる形はリスクが上がる |
| **3** | **登録料を取らない／登録料を報酬原資にしない** | 「下位者が払った登録料が上位者に入る」形は明確に該当 |

> ⚠️ **最も危ないのは「講座を買った人だけが紹介できる」設計。**
> 特定負担（講座代金）＋特定利益（紹介報酬）が揃ってしまいます。
> **受講生限定にしない。これが分かれ目です。**

調査結果より: アフィリエイターが他のアフィリエイターを勧誘しても、
勧誘自体で対価が生じず、後順位者の登録料が先順位者に配分されないなら、
連鎖販売取引にはならないとされています。

- [ ] 🔴 **この3ルールを弁護士に確認**（連鎖販売取引・業務提供誘引販売取引とまとめて1回で）

## 2. ⚠️ もう一つの論点：景表法の責任は「あなた」にある

ここは [02-法務リスク.md](02-法務リスク.md) で既出ですが、**自分が広告主になると直撃します。**

> **アフィリエイターが独断で誇張した表現を使っても、
> 原則として広告主（＝あなた）が景品表示法違反の責任を問われます。**

さらにステマ規制で、アフィリエイターに「広告」「PR」表記をさせる責任も広告主側にあります。

### ジレンマと、その解き方

| | 連鎖販売取引の回避 | 景表法の管理 |
| --- | --- | --- |
| 誰でも登録できる | ⭕ 特定負担がない | ❌ 変な訴求をする人が出る |
| 受講生だけに限定 | ❌ 特定負担が発生 | ⭕ 管理しやすい |

**解き方: 登録は誰でも可（購入不要）にしたうえで、承認制にする。**

承認の基準は「購入したか」ではなく「**規約に同意し、表現ルールを守れるか**」。
これなら特定負担は発生せず、管理もできます。

- [ ] 🔴 アフィリエイト規約を作る（禁止表現・PR表記義務・違反時の提携解除）
- [ ] 🔴 **公式の紹介素材を用意する**（自由に書かせない。素材を使ってもらうのが一番安全）
- [ ] 🟡 禁止表現リストを渡す（「必ず稼げる」「◯万円確実」「痩せる」等）
- [ ] 🟡 定期的に紹介ページを見回る体制

## 3. ASPの選択肢（3タイプ）

### タイプA: 情報商材特化ASP（決済込み）

| ASP | 特徴 |
| --- | --- |
| **infotop（インフォトップ）** | 情報商材アフィリエイトの最大手。株式会社ファーストペンギン運営。**アフィリエイター側は登録審査なし・提携審査もなし**のため、紹介者を集めやすい。報酬率は商品により最大85%の設定例もある |
| **infocart（インフォカート）** | 国内最大級の情報コンテンツ。ブログ＋メルマガ導線が組みやすい |
| **Brain** | 知識共有プラットフォーム。紹介機能あり |

- ⭕ **既存のアフィリエイター母集団がいる**。ゼロから紹介者を集めなくていい
- ⭕ 決済もセット
- ⚠️ **「情報商材」の文脈に置かれる**。[01](01-構想メモ.md) の「怪しさを突き抜ける」方針、
  [13-大義.md](13-大義.md) のブランドと衝突しないかは要検討
- ※ 販売者（広告主）側の登録条件・手数料は要確認

### タイプB: 自社ASP構築ツール（オールインワン）★推奨

| ツール | 料金（2026年時点・要確認） | 特徴 |
| --- | --- | --- |
| **MyASP（マイスピー）** | ビギナー 3,300円/月<br>**パーソナル 6,600円/月**<br>スタンダード 11,000円/月<br>マッハ 33,000円/月（初期11万円） | メール配信＋商品販売＋会員サイト＋アフィリエイト機能のオールインワン。**アフィリエイト機能はパーソナルプラン（6,600円/月）から**。自社専用のアフィリエイトプログラムを構築でき、パートナー管理から報酬計算まで自動化 |
| **UTAGE** | 9,700円/月〜 | 「ファネル」を軸にした設計。LP・決済・メール・動画配信を一連で組み立てられる。**オンラインスクール／デジタルコンテンツ販売向き** |

- ⭕ **固定費が軽い**（月数千円〜1万円）
- ⭕ **報酬率・条件・承認基準を自分で設計できる** ← 連鎖販売回避の設計を自分で握れる
- ⭕ **決済・LP・メール・会員サイトも込み**。12/16ローンチに必要なものが一式揃う
- ⚠️ 紹介者は**自分で集める**必要がある

## 4. 💡 推奨：MyASP か UTAGE（自社ASP型）

### 理由

1. **12/16ローンチに必要なものが一式揃う**
   アフィリエイトだけでなく、**決済・LP・メール配信・会員サイト**が同じツールで完結します。
   バラバラに揃えると、残り12週間では間に合いません。

2. **固定費が軽い**
   月6,600円〜9,700円。収益が出る前でも持ちこたえられます（[10-価格設計.md](10-価格設計.md)）。

3. **設計を自分で握れる**
   購入を条件にしない、1段階のみ、承認制——**連鎖販売取引を回避する設計を自分で実装できます。**
   外部ASPだと仕組みが向こうの都合で決まります。

4. **ブランドを守れる**
   情報商材ASPの文脈に置かれずに済みます。[13-大義.md](13-大義.md) と整合します。

### 選び分け

| | 向いている場合 |
| --- | --- |
| **MyASP** | メール配信を軸にしたい。**月6,600円で始めたい**。コストを抑えたい |
| **UTAGE** | LP〜決済〜動画までのファネルを一気通貫で作りたい。オンラインスクール型 |

> **まず両方の無料相談・お試しを見てから決めることを勧めます。**
> ただし**W5（10/23-10/29）までには決める**こと。決済基盤なので後戻りが効きません。

## 5. ⏰ 12/16ローンチとの関係：アフィリエイトは「後」でいい

**ローンチ時点でアフィリエイトは不要です。**

```
12/16  コンサル販売（自分の発信＋リストから売る）
   │
   │  実績・事例がたまる
   ▼
年明け  アフィリエイト開始（紹介者に売ってもらう）
```

理由:
- **実績ゼロの商品は紹介されません。** アフィリエイターは売れるものしか紹介しない
- 完走者・受講生の声が揃ってからの方が、紹介者も集まる
- 12週間で法務・商品・集客を全部やるので、**アフィリエイトまで手が回りません**

### ただし、ツール選定は今やる

MyASP / UTAGE は**決済とLPの基盤でもある**ため、選定はW5までに必要です。
「アフィリエイト機能がある」ツールを最初から選んでおけば、後から有効化するだけで済みます。

- [ ] 🔴 **W5までに MyASP / UTAGE を比較して決める**（決済基盤として）
- [ ] 🟢 アフィリエイト機能の有効化は、ローンチ後（年明け）
