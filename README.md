## AIチーム

`.claude/agents/` に6つのエージェントを定義済み。Claude Code から名前で呼び出せる。

`keiri`（経理） / `bunseki`（分析） / `marketing`（SNS・マーケ） /
`jimu`（事務） / `task`（タスク管理） / `homu`（法務リサーチ）

詳細と線引きは [docs/07-チーム設計.md](docs/07-チーム設計.md)。
